## 親の裁定 (レビューの是正案と食い違う場合は本裁定が勝つ)

### K-1 (S6-02、最重要) 単独性を subwindow 判定にする — arm 合計の絶対 tick をやめる

- **境界サンプル**を入れる。arm 内の **block / pin target / A2 condition の境界**
  (すでに anchor を捨てている点) で、`/proc/stat` (per-CPU) と**自 tree の PID の
  `/proc/<pid>/stat` だけ**を読む。**read と read の間では絶対に読まない**
  (critical window の純度は既存の最重要規律であり、壊してはならない)。
  全 process snapshot (identity 用) は従来どおり arm の前後だけ。
- subwindow ごと・CPU ごとに `residual = max(0, process_attributable_delta − self_attributed_delta)`。
  **CPU 横断の相殺は禁止** (既存規律)。
- 判定は **per subwindow, per CPU**: `residual <= 2` → `incidental`、`>= 3` → `COMPETITOR`。
  **arm 合計では判定しない。** 定数を外出しし (`SUBWINDOW_NONSELF_TICKS_MAX = 2` 等)、
  docstring に根拠を書く: 「A0 で常駐デーモンの居た CPU 22 は 1.558 秒の窓で residual 1 tick、
  かつ 30/30 の読みで帯外化しなかった。subwindow は約 0.3 秒なので同率なら ≪1 tick。
  2 tick は約 10 倍の余裕で、3 tick 以上は 0.3 秒窓の 10% 以上に当たる実負荷とみなす」。
- **per-CPU per-subwindow residual の最大値を必ず結果へ記録する** (次の反復で実測から
  閾値を引き直せるようにするため)。
- 旧 `INCIDENTAL_NONSELF_TICKS_MAX = 5` の arm 合計判定は**削除**する (二重判定を残さない)。

### K-2 (S6-03) migration した subwindow の per-CPU 帰属を捏造しない

ある subwindow 内で自 process の走行 CPU が変わったら、その subwindow の per-CPU 帰属は
信用できない。**`ATTRIBUTION_UNRESOLVED` (VALID 維持・量を記録) とし、residual だけを根拠に
COMPETITOR にしない。** 非自 PID の snapshot 規則は従来どおり効かせる。
endpoint だけから per-CPU 量を推定してはならない。

### K-3 (S6-04) A1 の incidental × 帯外の交差を出す

A1 の各 CPU について「incidental な非自活動があった subwindow」と「その CPU が帯外だった読み」の
交差件数・率を **pinned / control 別**に `causal_metrics` へ保存する。
**validity gate は緩めない** — 交絡を可視化する集計である。

### K-4 (S6-05) α を巡回込みで測る

- **`alpha_with_rotation`** を新設する: A1 の randomized pin 順で**連続する K=5 個の pin target**を
  1 群とし、各 target から primary read を 1 つ取り、位置ごとの累積最小を採る
  (48 target → 9 群、余り 3 は捨て、**捨てた数を記録**)。
- 現行の α (A3 quiet 由来、reader が動かない) は **`alpha_without_rotation`** へ改名し、
  **α として報告しない**。2×3 表の α 列は `alpha_with_rotation` を使う。
- どの read をどの群のどの位置に使ったかを再現できる形で記録する。

### K-5 (S6-06) テストの穴を塞ぐ

- **2 CPU に 3 tick ずつ** (per-CPU では閾値以下、合計では超える) → `VALID` かつ
  `ATTRIBUTION_UNRESOLVED` になること。global-total で判定する変異が赤になる。
- 5/6 相当の境界、`unreadable` / `error` について **`validity_reasons` の完全一致**を assert し、
  `INVALID ⇒ NOT_EVALUATED` も同時に固定する (理由が 1 つに絞れていること)。
- errno は `EACCES` / `EPERM` / `ENOENT` / `EIO` を直接固定する。
- K-1 の subwindow 判定・K-2 の migration・K-3 の交差・K-4 の α 巡回にも、それぞれ
  **単一理由**の合成 fixture を足す。
