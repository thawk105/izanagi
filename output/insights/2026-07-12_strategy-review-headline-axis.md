## 2. 出口 3 択 (いずれも事前登録改訂を伴う設計判断 = ユーザー協議事項)

1. **構文契約のメンバ読取拡張** — D48 決定 2 自身が「段階 B 差し戻し事項」として予約済み。gate 述語空間をコード片級に非列挙化し (c) 構造発火を消す。代償: reward hack 面の拡大、B〜E 再走 (シート改訂 + 3 レンズ再レビュー + 偵察器改修)、D47 決定 5 改訂の併走。
2. **axis-proposer で次軸を引く** — n=1 実績 (提案 3 中適格 2)。ただし同じ「探索補助限定」の壁に当たるため事前登録改訂は結局必要。軸オンボーディング固定費 (B〜E で 3〜4 セッション + 偵察計測) が再発。
3. **headline 主張の系レベル再構成 (検討セッションの推奨・実勢もこちら)** — 比較単位を「LLM 合成 variant vs 機械 sweep」から「**LLM が軸を発見しループで探索する系 vs 軸発見なしの非 LLM 系**」へ改訂する。根拠: (i) P2-5 → P2-4 で確立した「価値の所在は誘導でなく軸発見」の第 3 幕版であり、3 幕構成 (仮説反証と主張の移動) と完全に一貫。(ii) trigger-gating の +61〜99% は「非 LLM 系には**軸自体が存在しなかった**利得」であり、機械 sweep の floor 超はこの主張では失敗条件でなく**発見された軸が本物である証拠** (裏書き) に転化する。(iii) D50 の「最適 gate が workload で入れ替わる」観察が 8b (workload 特化) と直結し、「ワークロード特化 CC の自動合成」の看板に主張が近づく。(iv) 論文レンズの独立分析も「三段の鎖 (誘導の反証 → 軸発見 → ループ内化) が最も証拠の揃った物語、最終環のみ未取得」と収束。改訂の作法: D44 決定 1 (主張を制約する方向のみ) に従い、旧 headline 1 の帰結 ((c) 構造成立 = 軸内探索の LLM 固有価値は主張しない) を正直に併記する形なら選択的報告にならない。追加で必要になる実験要素: axis-proposer の n 増し (現状 n=1 — 統計主張には提案ラウンド数本)、対照設計 (ランダム hole 選定 / attribution 遮断 ablation = P2-5 の「渡す vs 解釈させる」切り分けの合成版)、独立の人間再命名工程 (D47 決定 5 の昇格前提)。
