## R2. `DW-O23` の機械契約移管 (449 bytes) を採るか

経路 B で**唯一予算を空けうる候補**。現行 `DW-O23` は 1,123 bytes、縮約案は 674 bytes、差 449 bytes
(親が独立検算)。代替とされる `orchestrator/tests/test_dev_wave_land.py` は実在し 64 test を持つ。恒真ではない。

| 択 | 内容 | 解放 | リスク |
|---|---|---:|---|
| (a) | 縮約案どおり移管する | 449 | tool と test は同じ変更で一緒に弱められ、互いの独立 oracle にならない。落ちる文言 (fragment 0 件の no-op、dirt と衝突 untracked の区別、handoff / Git admin 束縛 worktree の非接触) は F80 / F81 / F82 / F98 が実際に踏んだ受理集合の境界である |
| **(b) 推奨** | 移管しない | 0 | 集約の空きは 16 bytes のまま。ただし R1・R5 により、入らない候補は「見送りで確定」が既定なので詰まらない |
| (c) | 純粋に記述的な行だけ削る小幅版 | 数十 | [T-127] が明示的に禁じた「3 bytes のために削り続ける」型になる |

**推奨 = (b)。** 理由は 3 つ。(i) 独立 oracle が無い状態での安全義務の移管は、
`tools/check_docs.py:165-167` が記録する `DW-S07` の前科と同型である。
(ii) 449 bytes を解放しても既知需要 ([T-412] の `DW-G05` +274 bytes) を賄って残り 191 bytes であり、
構造問題は解けない。(iii) [T-313] を実装すれば `DW-O23` は L1 として固定上限側に残るので、
この移管は [T-313] 後も価値を失わない — **急ぐ理由がない。**

(a) を採る場合の必要条件: 全 prose 行と実 field の対応表、tool/test の同時弱化に耐える独立 oracle、
`DW-G05` の成果物影響 (台帳・certified 選択・レポートのどこがどう変わるか) を先に揃えること。
