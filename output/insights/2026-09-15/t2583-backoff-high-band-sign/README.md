## 0. 何が分かったか

1. **既存 J1 経路は高域を実行できない。** 事前登録された対照 (`nm-step1` × `nm-step1-u2560`) の
   広窓側は、全 1,170 event の `backoff_before` と `backoff_after` がどちらも **最大 12.0 µs** で、
   高域 (> 50 µs) へ 1 度も入らない。主帯域の辺対は **0** である
   (`feasibility = no_high_band_observation`)。
2. **代替の対照も作れない。** 記録済みの刻み軸 5 セルの**全 10 組**について、
   **両側に非ゼロ符号の観測を持つ高域共通辺は主帯域・感度帯域とも 0 本**である。
   既存 J1 の比較は順序なし辺の**完全一致**を要求し、辺の幅は刻みが決めるため、
   刻みが違うセル同士は高域でほとんど辺を共有しない。
   **ただし「1 本も共有しない」ではない** — `nm-step25` と `nm-step100` は上端の自己辺
   `(1000.0, 1000.0)` を共有する。その辺の符号が**両セルとも全てゼロ**であるため、
   推定に使える共通辺としては数えられない (§3.5)。
3. **高域の符号そのものは測れた。そして、ほぼ完全な五分五分だった。** 高域へ入る 4 セルの
   辺重み平均 `d = 2p(1-p)` は **0.4944 / 0.4970 / 0.4991 / 0.4971**、少数標本の下方偏りを
   補正すると **0.4979 / 0.4993 / 0.4997 / 0.4972** で、いずれも上限 0.5 の近傍にある。
   **今回の 4 セルの辺重み平均では、補正は 0.5 へ近づく向きに動いた。** これは補正式の性質ではない —
   補正値は 0.5 を超えうる (例: `nm-step1` の辺 `(127,128)` は正 2・負 1 で `d = 4/9`、補正後 `2/3`)。
4. **旧 J1 の判定は、少数標本の偏りを補正しても変わらない。** 段 3 が指摘した
   `E[d] = 2q(1-q)(1-1/n)` の下方偏りを補正すると、差は **0.0402 → 0.0380** (n=1 の辺 1 本は
   補正不能なので未補正のまま残した場合) または **0.0376** (その辺を両側から除いた場合) にしか動かない。
   事前登録の支持条件 0.10 には遠く、`not_supported` のままである。
5. **T-2188 の記録に算術誤りが 1 件ある** (§7)。原記録の bytes は書き換えず、ここに追記で訂正する。

**主張しないこと。** 高域で `d` が 0.5 に近いことから「計数ノイズが高域で符号を支配する」へは
**進まない**。同じ辺でも歩行履歴と窓の状態で throughput 差は変わるため、計数ノイズが無くても
符号は混ざる。**低域より不安定であるとも言わない** — 条件間の対照が成立せず (§3.4、§3.5)、
同一セル内の低域との対比 (§4.2) は帯域・歩行履歴・窓の状態が同時に違うからである。

## 1. 問いと、既に分かっていたこと

D1932 は刻み応答の非単調性の機序を「歩行が高い `Backoff_` へ居着く (滞在分布)」と定め、却下枝に
こう書いた。

> **計数ノイズが勾配符号を支配するという説明を主機序に据える** — 事前登録した J1 は不支持だった
> (窓 10 で 0.498、窓 2560 で 0.458、差 +0.040 < 閾値 0.10)。さらに 3 区間で向きが揃わない。
> ただしこれは両条件が重なる低域 (`Backoff_` <= 12 µs の 12 辺) だけの比較であり、
> **計数ノイズの寄与を否定するものではない。**

高域が空白だった。本 wave はそこを埋める。

**「3 区間で向きが揃わない」の中身を正確に書く。** 本 wave の再現で見ると、区間差は
第 1 区間 **+0.0535**、第 2 区間 **+0.0489**、第 3 区間 **`null`** である。
第 3 区間は**向きが逆になったのではなく、共通辺が作れず比較そのものが成立しない**。
事前登録は「3 区間すべてで同方向」を要求するので、`null` は条件不成立として
`direction_unstable` を立てる。**判定は正しいが、「向きが揃わない」は「逆向きが観測された」を
意味しない。**

**本 wave は盲検ではない。** 設計時点で次を知っていた。`nm-step1-u2560` の時間加重
`P(Backoff_ > 50)` は 0.0000、`backoff_before` の event 加重最大値は 12.0、旧 J1 の共通辺 12 本は
すべて `Backoff_` <= 12 µs。**したがって主帯域の共通台不成立は既存報告から予測済みである。**
本 wave が新たに与えるのは (a) その予測の原 trace 上での確認、(b) **未報告だったセル別の高域符号集計**、
(c) 不成立の帰属先の切り分けの 3 つである。事前登録が抑えるのは
**新しい集計を見た後に仕様を動かす余地**だけであり、独立な盲検判定への改善ではない。

**旧 J1 が `not_supported` だった理由を正確に書く。** 旧 J1 は共通辺 12 本で登録閾値 10 を
**満たしており**、不支持の理由は差 0.0402 < 0.10 と 3 区間の向き不一致である。
低域限定はその判定の**射程**であって、不支持の原因ではない。

## 2. 結果を見る前に固定した仕様

`verbatim/s4-adjudication.md` (sha256 `1137f8424f9bf4c310ddea23907e04e8ec021b90336264683df59a3c085f9201`)
の §3 に、帯域・推定量・対照・実行可能性の 5 状態・主張しないことを、**probe を 1 度も走らせる前に**
固定した。結果を見てから閾値・向き・語彙・帯域・対照・推定量を変えていない。

凍結済みの `s4-ruling.md` §6 (T-2188 の J1〜J4 事前登録) は**変更していない**。

- **主帯域:** 直前 event の順序なし辺 `sort(backoff_before, backoff_after)` の**両端が厳密に > 50 µs**。
  `min(edge) > 50` はこれと同一であり、独立な感度ではない。
- **感度帯域:** `max(edge) > 50 µs` (境界をまたぐ辺を含む)。
- **低域:** `max(edge) <= 50 µs`。主帯域と低域は全体の二分割では**ない** — 境界横断辺はどちらにも
  入らない。全セルで `主 + 低域 + 境界横断 = event 数 − 1` が成立することを確認した。
- **推定量:** 既存 J1 と同じ辺別 `d = 2p(1-p)`、`p = n+/(n+ + n-)`、`gradient_sign == 0` は
  推定から除外し除外数は保存する。**event を先に間引かず**、元列で符号・直前辺・区間を作ってから
  辺を帯域で選別する。
- **50 µs の出所:** J2 事前登録の `P(Backoff_ > 50 µs)` と、上限 50 µs の自然実験との接続。

**事前登録の穴を 1 つ記録する。** §3.5 の 5 状態は「広窓側に観測がある / 無い」を軸に書いたため、
**「広窓側に非ゼロ観測があり、狭窓側に無い」場合を定義していない**。今回の入力ではこの状態に
ならない (広窓側の主帯域の辺対が 0 で最初の枝が確定する) が、表は網羅していない。

**この穴は probe にそのまま残っている。** probe は `K = 0` のとき、狭窓側の有無を見ずに
`no_common_high_band_edge` を割り当てる。この語は §3.5 の表では「**両側に**非ゼロ観測があるが
`K = 0`」を指し、帰属先は既存 J1 の共通辺設計である。したがって狭窓側が空の場合には**誤った帰属**に
なる。段 6 の焦点レビューがこれを指摘した。**親はこれを nit として閉じた** — この枝は登録された
入力では発火せず (3 走とも `no_high_band_observation` で確定)、成果物の値を 1 つも変えないため
(`DW-G05`)、かつ結果を見た後に判定語を足すことは凍結の趣旨に反するためである。
セル別の生の計数を全件保存しているので、この状態が起きても帰属は再計算できる。

## 4. 高域の勾配符号 — セル別の記述統計

既存**部品** (`_edge_observations` / `_edge_counts`) を、抽出後に帯域で絞った観測へ適用した。
これは「既存経路の実行」ではなく**既存部品による再解析**である。

### 4.1 主帯域 (両端 > 50 µs)

| cell | 辺対数 | 正 | 負 | ゼロ | 辺種 | 辺別 n (最小/中央/最大) | **辺重み平均 `d`** | 偏り補正後 |
|---|---:|---:|---:|---:|---:|---|---:|---:|
| `nm-step0.5` | 0 | 0 | 0 | 0 | 0 | — | — | — |
| `nm-step1` | 43,148 | 21,629 | 21,518 | 1 | 307 | 1 / 123 / 433 | **0.4944** | 0.4979 |
| `nm-step1-u2560` | 0 | 0 | 0 | 0 | 0 | — | — | — |
| `nm-step2` | 43,083 | 21,599 | 21,483 | 1 | 196 | 6 / 155 / 776 | **0.4970** | 0.4993 |
| `nm-step25` | 28,441 | 14,203 | 14,002 | 236 | 38 | 441 / 813 / 1,012 | **0.4991** | 0.4997 |
| `nm-step100` | 25,719 | 11,997 | 13,111 | 611 | 10 | 2,409 / 2,515 / 4,721 | **0.4971** | 0.4972 |

**高域へ入る 4 セルすべてで、符号の不安定度は上限 0.5 の近傍にある。**

**辺別 n には 1 まで落ちるものがある** (`nm-step1` の主帯域に n=1 の辺が 2 本、
`nm-step2` の最小は 6)。独立 Bernoulli を仮定した相対下方偏り `1/n` は、その辺では 100%・約 16.7% に
なる。**したがって「偏りは小さい」とは辺別には言えない。** ただし辺重み平均は n で重みづけるため
小さい辺の寄与は 43,000 分の 1 程度であり、`d / (1 - 1/n)` を n > 1 の辺すべてへ適用した
「偏り補正後」列は **0.4972〜0.4997** と、補正前より 0.5 へ近づく。
**補正は結論の向きを変えない。**

### 4.3 符号が消える場所 — 端で止まった歩行

ゼロ勾配は特定の**自己辺**に集中していた。

| cell | 帯域 | 辺 | 正 | 負 | ゼロ |
|---|---|---|---:|---:|---:|
| `nm-step25` | 高域 | `(1000.0, 1000.0)` | 0 | 0 | **236** |
| `nm-step25` | 低域 | `(0.0, 0.0)` | 0 | 0 | **1,126** |
| `nm-step100` | 高域 | `(1000.0, 1000.0)` | 0 | 0 | **610** |
| `nm-step100` | 低域 | `(0.0, 0.0)` | 0 | 0 | **5,050** |

**保持された隣接対の範囲では、`Backoff_` が 0 または 1000 で動かなくなった直後の event は、
記録された `gradient_sign` が例外なく 0 である** (対象 9,220 対、正 0・負 0・ゼロ 9,220)。
`nm-step100` の低域は 5,050 対すべてがこれであり、非ゼロ符号が 1 件も無い。
上端 1000 µs は `nm-step25` と `nm-step100` の `backoff_before` 最大値と一致する。

**ここでは因果を主張しない。** 1000 µs が符号化の表現上端である可能性 (F718、[T-2584]) と、
歩行が実際にそこで飽和している可能性を、本 wave の記録だけでは分離できない。
**「符号が 0 である」ことは、物理的な停止や飽和の証明ではない。**

### 4.4 感度帯域 (`max > 50 µs`) — 境界をまたぐ辺を入れた場合

| cell | 辺対数 | 境界横断の対数 | 感度 `d` | 主帯域からの差 |

## 6. B-10 への接続 — 何が言えて、何が言えないか

**言えること。**

- 機序説明を帯域外へ伸ばすとき、**既存 J1 の枠組みは高域で使えない。** 理由は 2 つある。
  (a) 事前登録の対照は広窓側が高域に入らない。(b) 刻み軸のどの組でも、両側に非ゼロ符号の観測を持つ
  高域共通辺が 0 本である。
- 高域の符号は、**それを訪れる 4 セルすべてで上限 0.5 の近傍にある** (0.4944〜0.4991、
  偏り補正後 0.4972〜0.4997)。これは**保持された隣接対の、非ゼロ符号に条件づけた辺別混合度**である。
- 保持された範囲では、`Backoff_` が下端 0 と上端 1000 で止まった直後の符号は**例外なく 0 である**。

**言えないこと。**

- 計数ノイズが高域で符号を支配するか否か。§0 のとおり、この測定は因果を同定しない。
- 高域の `d ≈ 0.5` が、低域より不安定であることの証拠。同一セル内の対比 (§4.2) は帯域・歩行履歴・
  窓の状態が同時に違い、条件間の対照は §3.4・§3.5 のとおり成立しない。
- 全走行の性質。`nm-step0.5` は約 7 割を取りこぼしており (§3.6)、保持分は末尾 slice である。
- 符号の**時間的な**反転率。`2p(1-p)` は辺内の正負の比率だけで決まり、符号列の順序を見ない。
- 観測の独立性。1 rep であり、隣接 event 対は互いに独立でない。
- D1932 の滞在分布説を補強も否定もしない。**本 wave は D1932 を動かさない。**

**高域で条件間の対照を成立させるには何が要るか** (構造として返す。本 wave では実装しない)。

1. **広窓側を高域へ置く走行が要る。** 既存記録の広窓セルは最大 12 µs であり、初期値・上限・
   更新間隔の組み合わせを変えた新しい走行なしには対照が存在しない。
2. **辺の同一性の定義を変えるか、刻みを揃えることが要る見込みである。** 当該 trace では、
   刻みが違うセル同士に推定へ使える共通辺が無かった。完全一致ではなく帯へ束ねる同一性なら
   作れる可能性があるが、**それが必要条件であることを本 wave は示していない** — 示したのは
   この 1 本の記録での不成立だけである。**また、同一性を変えれば既存 J1 の事前登録を変えることになり、
   旧判定との比較可能性を失う。** 本 wave はこれを実装せず、択一として置く。
3. いずれも新しい Pegasus 実測か事前登録の改訂を伴うため、**ユーザーの裁定に属する。**
