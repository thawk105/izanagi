## 判定述語 (実行前に確定)

条件を \(L=\texttt{nm-step1}\)、\(R=\texttt{nm-step1-u2560}\) とする。各セルで次を別々に数える。

- `state_high_event_count`：`backoff_before > 50` の event 数。J2 と対応する。
- `high_edge_pair_count`：直前辺が主定義の高域に属する隣接 event 対数。現在の符号ゼロも含む。
- `high_nonzero_observation_count`：そのうち現在の `gradient_sign != 0` の数。
- `high_unique_edge_count`：非ゼロ観測を持つ高域辺の種類数。
- `common_edge_count = K`：両条件で非ゼロ観測を持つ高域辺の共通数。

**「実行できる」の主述語は、既存処理が正常終了し、主定義で `K >= 10` を満たすこと。** 正常終了しただけでは成立としない。差の大きさや向きは、この実行可能性と分離する。

`common_support_minimum = 10` はそのまま使う。既存 J1 と同じ比較資格を問うためであり、結果に合わせた緩和を避けられる。ただし、**10 は共通辺数であって event 数でも、精度・検出力の保証でもない**。辺別標本数と重みを必ず併記する。

| 実測状態 | 本 wave の結論 |
|---|---|
| R の高域辺対数が 0 | この記録には高域辺への対照観測がない。`K = 0` で実行不可 |
| 高域辺対はあるが非ゼロ符号が 0 | 符号ゼロ除外後の対照観測がない。実行不可 |
| 非ゼロ観測はあるが `K = 0` | 両条件の辺が重ならない。実行不可 |
| `1 <= K < 10` | 数値は計算できるが、既存 J1 の共通台条件を満たさない |
| `K >= 10` | 高域比較を実行可能。次に差と区間方向を報告 |

R の非ゼロ高域観測が 1〜9 件なら `K < 10` が必然だが、10 件以上でも同じ辺への集中や非重複で不成立になりうる。

ゼロの場合は「当該記録に対照がない」、非ゼロで閾値未満の場合は「対照はあるが共通台が不足」と書き分ける。どちらも**計数ノイズの寄与なしとは結論しない**。入力不正・import 失敗・メモリ不足は測定未完了であり、構造的な実行不可とは区別する。

## 高域の辺の定義

元の event 列の添字を \(i\) として、

\[
e_i=\operatorname{sort}
(\mathrm{before}_{i-1},\mathrm{after}_{i-1})
\]

へ現在 event の符号 \(g_i\) を割り当てる。

- **主：両端が厳密に `> 50 µs`。** 高域内部での勾配符号を測るため。
- **感度：`max(edge) > 50`。** 境界をまたぐ辺を含めた場合を示す。
- `min(edge) > 50` は「両端 > 50」と数学的に同一。独立した感度解析とは数えず、主定義の同義表記として出す。
- `min <= 50 < max` の境界横断辺数を別記する。50 ちょうどは主定義に含めない。
- 自己辺 `(b,b)` は既存処理が除外していないため維持し、その数を明示する。

50 µs は J2 事前登録の `P(Backoff_ > 50)` と、そこに記された上限 50 µs の自然実験との接続から取る。D1932 は滞在分布を機序とする根拠であり、50 µs を唯一の物理的境界として定めた文書とは扱わない。

**event を先に間引かない。** 元列で符号・直前辺・区間番号を作ってから辺を選別する。

## 測る量

既存の辺別推定量を維持する。

\[
p_{c,e}=\frac{n^+_{c,e}}{n^+_{c,e}+n^-_{c,e}},\qquad
d_{c,e}=2p_{c,e}(1-p_{c,e})
\]

符号ゼロは推定から除外するが、除外数を保存する。これは同じ辺の符号構成から求める不一致率であり、時系列の隣接符号反転率でも独立な正解に対する誤答率でもない。

共通辺集合 \(C\) では、

\[
w_e=\min(n_{L,e},n_{R,e}),\quad
D_c=\frac{\sum_{e\in C}w_ed_{c,e}}{\sum_{e\in C}w_e},\quad
\Delta=D_L-D_R
\]

とする。同じ重みを両条件に使い、各条件固有の滞在頻度で別々に平均しない。

既存の 3 区間処理も維持する。ただし現物の区間は `min(2, i*3//N)`、すなわち**保持 event 列の添字による三等分**であり、経過時間の三等分ではない。区間ごとに共通台と `min` 重みを計算し、区間間で同一の台・重みとは称さない。

実行可能なら、全体の \(\Delta\ge0.10\) と全 3 区間の \(\Delta_s>0\) を報告する。方向が揃わなければ `direction_unstable`。空区間は差を `null` とし、安定性成立に数えない。

共通台が不足しても、次は有意味な記述統計として出す。

- セル・帯域別の正／負／ゼロ数と割合、辺数、辺別 \(p,d,n\)。
- セル内の非ゼロ event 数で加重した辺別 \(d\) の平均。
- 自己辺・境界横断辺の数、保持数・脱落数・被覆率。

セル内平均は**そのセルが訪れた辺の混合に依存する量**と明記する。共通辺ゼロなら比較差は `null`、1〜9 辺なら参考値に `insufficient_common_support` を付ける。これらで更新間隔効果や「高域から戻れない原因」を認定しない。
