# 段 1 brief への追補 — 親の誤りの訂正と (P1) の言い直し

段 2 の plan 子が親 brief の F-5 の使い方を誤りとして指摘した。親はこれを受け、
一次資料を読み直して次を確定した。**この追補が (P1) の正本であり、brief §3 の (P1) は撤回する。**

## 1. 親の誤り (確定)

brief §3 は「帯の両端の差は 0.66% 以内」と書いた。**これは誤りである。**
−0.22% / −0.27% / −0.66% は **999 対 1000** の差であって、帯を挟む **900 対 999/1000** の差ではない。

## 3. 言い直した (P1') — 親の provisional 裁定・攻撃対象

**拡張格子 `EXTENDED_SWEEP_US` はこの領域で刻み幅 100 マイクロ秒を採っている
(… 500, 560, 600, 700, 800, 900, 1000)。したがって「帯 901〜998」は、格子が設計どおり採らなかった
1 区間の内部にすぎず、同じ性質の未測区間 701〜799 や 801〜899 と区別がつかない。
後者は残件として一度も挙げられていない。**

親の読みでは、901〜998 だけが残件として名指された理由は測定上の必要ではなく **F718 の符号化事故**である。
要求点 1000 が無効になり 999 が代替枠として使われたため、「要求した点を測っていない」という帳尻が残り、
その帳尻が「901〜998 の帯」という形で台帳に写された。1000 が正式に測れた時点 (2026-09-10) で
帳尻は消えており、残っているのは**区間の内部を細分する理由**だけである。資料にその理由は無い。

**(P1') を倒すには次のどれかを示せばよい。**

- (a) この区間の内部で、隣接区間から予測される滑らかな挙動から外れる現象が起こりうる機序。
- (b) 901〜998 の測定値を入力として要求する、既存の論文主張・図表・model・事前登録。
- (c) 701〜799 や 801〜899 と 901〜998 を区別する、測定上または符号化上の非対称。
- (d) 依頼者が帯を literal に要求しており、研究前進の有無にかかわらず測るべきだとする根拠。
