## 恒真化と偽の緑

### 3. 案Bそのものによる inert 比較の恒真化

- **real / refuted：refuted。ただし control のコピー元変更は実在する危険箇所。**

  一方、B-M5 のように patch 後の木を control にコピーすると、patch:12 の既定値も -1 なので、control も同じ patch の既定枝を使う。G:834–838 が拒否するのは同じ root path であり、別 path へコピーした patch 木を素の木とは保証しない。これを同等の control として扱うことはできない。

### 4. 案Bの緑は永続 cache の生成物に依存する

これは誤った binary の認定を直ちに証明する所見ではなく、**残留状態に依存した成功を修復一般へ拡張する問題**である。
