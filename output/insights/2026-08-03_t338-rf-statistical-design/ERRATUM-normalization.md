## 正規化の内容と復元法

- **正規化:** 各行の末尾から半角空白とタブだけを除去 (`line.rstrip(" \t")`)。
  改行コード・文字順・可視文字はいずれも不変。除去された空白は markdown の hard line break
  記法 (行末 2 空白) であり、描画上は強制改行が通常の改行になる。
- **不変性の検査:** 正規化前後で「空白とタブを全除去した文字列」が byte 一致することを
  機械的に assert した (上記スクリプトで OK)。
- **復元法:** 原文は `git diff --check` 以前の生成物であり、本 repo には残っていない。
  復元が必要な場合は、上表の原文 sha256 と byte 数を満たす形で、下表の行へ行末 2 空白を戻す。
  対象行は `s2-plan.md` が 1 行、`s3-lensA.md` が 3 行、`s3-lensB.md` が 18 行で、
  いずれも「箇条書き項目または段落の末尾」である (行番号は正規化後も不変)。
