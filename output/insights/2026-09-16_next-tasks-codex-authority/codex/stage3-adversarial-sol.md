## 所見

1. **「実測で示せる」が、判断変更の必要条件として機能しない。**

   **対象:** plan「scope 1」「判断が割れる点 (P1-a)」。

   **何が破れるか:** 実測結果と覆す判断との関係が本文にない。「その判断を覆せる事実」という plan の説明も、覆してよい条件を定義していない。厳密な恒真ではないが、任意の実測を口実にできる。

   **具体的な筋書き:**
   - 入力: codex が論文への寄与から研究候補を先に置く。claude が土台候補の対象ファイルの実在を確認する。
   - 誤った結論: 「実測した根拠がある」と土台候補を先頭へ移す。件数合わせではないので scope 3 でも止まらない。
   - 逆方向: codex が事実を全て認めながら、土台整備への選好で研究側下限を破る。事実誤認がないため、「実測だけ」を厳格に読む claude は既存規定違反を是正できない。なお、**既存規定内の純粋な選好を claude が覆せないこと自体は、今回の権威移譲の意図に合う。**

   **是正案の逐語:** scope 1 の第3行を置換する。

   ```markdown
     claude が判断を覆せるのは、判断の前提事実の誤りを実測で示すか、既存規定との矛盾を示す場合だけ。
   ```

   同節の末行を、義務を保って縮約する。

   ```markdown
     採用候補の事実は claude が実測し、相手の断定で代替しない。
   ```

   **byte 収支:** 第3行は 127 → 142（+15）。末行は 101 → 86（−15）。**差引 0 bytes**。

2. **権威分担の列挙が閉じず、既存規定との上下関係も不明。**

   **対象:** plan「scope 1」冒頭2行、対象 file:113–133、169–175、211、224–230、237–257。

   **何が破れるか:** 四つずつの限定列挙では、以下が明示的に収まらない。
   - 系統 blocker の認定と、その根拠事実。
   - ユーザー手番か AI 作業かの判定。
   - 追加実装の必要性・過剰性の評価。
   - A/B 群の出所明記、投げ文の書式・必須事項。

   採否への影響があることと、その前段の評価まで codex の権威であることは同義ではない。また現行211行の「読み手の判断」が、claude の独自分類権として残る。

   **具体的な筋書き:** codex が回収候補を研究側と判定 → claude が「私は読み手なので土台側と判断する」と研究枠から除く。逆に codex が系統 blocker を無視して N 件を返す → claude が「件数は codex の権威」と既存の1件限定を適用しない。

   **是正案の逐語:** scope 1 の冒頭2行を次の3行へ置換する。

   ```markdown
   - **既存規定の下で、事実確認・出力は claude、選定判断は codex が担う。**
     裁定状態・機構実在・着地・稼働重複・系統 blocker・ユーザー手番の事実は claude が確かめる。
     順位・採否・件数・研究/土台などの選定判断は codex、出所明記・投げ文は claude が担う。
   ```

   「など」で選定判断の列挙を閉鎖集合にせず、「既存規定の下で」により blocker 等の義務を維持する。

   **byte 収支:** 248 → 352（+104）。相殺として、plan の39–44行置換案をさらに次へ縮める。

   ```markdown
      回答を出す直前にもう一度 main を取り直す。**
   ```

   229 → 66（−163）。再取得義務と45行の助言直前の裏取り義務は残る。**差引 −59 bytes**。このうち49 bytesを所見3に充当する。

3. **不足確定の時点が曖昧で、2巡目の新規候補にも終端がない。**

   **対象:** plan「scope 2」「scope 3」、対象 file:108–109、190、222。

   **何が破れるか:** scope 2・3は論理的には両立するが、「相手の結論」が初回か再評価後か指定されていない。初回不足で終える読みと、実測結果を返してから不足を確定する読みが残る。また「実測して該当すれば枠へ入れる」は、実測担当による採用決定を残す。

   **具体的な筋書き:** N=10、codex が確定7件と未確認B-1を返す → B-1の機構不在を実測 → 「7件のみ」と終了して再評価を省く。一方、2巡目で別の未確認B-2が出れば、同じ返送義務を再適用して3巡目へ進める。

   **是正案の逐語:** scope 2 の置換後全文を次へ置換する。

   ```markdown
     母集合外の追加候補や相手が「未確認」と書いた候補は、実測せずに外さない。
     claude が結果をまとめて 2 巡目へ返し、再評価後に不足件数を確定する。
     2 巡目で追加・未確認の候補も実測し、着手不能なら除外して不足を明記する。
   ```

   scope 3 の復活禁止と、相談失敗時の既存規則は維持する。

   **byte 収支:** 272 → 321（+49）。所見2の純減59から充当し、**所見2・3合計 −10 bytes**。相殺の二重計上はない。

4. **「往復に数えない」に総回数の明示的上限がない。**

   **対象:** plan「scope 4」第1行。

   **何が破れるか:** 通常は「2巡目」で一度と読めるが、「原則」「往復に数えない」を例外の反復許可とも読める。

   **具体的な筋書き:** B-1の実測を返す → 次にB-2を実測 → 各回を「新事実による再評価だから往復数の対象外」と扱い、相談を続ける。

   **是正案の逐語:** 第1行だけを置換する。

   ```markdown
      - **相談は 1 往復。事実追加による再評価だけ、全候補をまとめた 2 巡目を 1 回認める。**
   ```

   **byte 収支:** 124 → 124。**差引 0 bytes**。新しい gate や台帳は不要。

## 親 brief への反証

- **(P1-a): 「実測した事実でだけ覆せる、と書けば足りる」は不十分。** 実測と判断の因果関係、および既存規定の優先が必要。文責と判断権の分離自体は可能だが、現案では所見1・2の抜け道が残る。
- **(P1-b): 反証なし。** main 更新の逸話を縮めれば、再取得・裏取り義務を維持して相殺できる。
- **(P1-c): 再帰止めについて反証なし。** 現行105–107行は受信回数を限定しておらず、毎巡 `CONSULT-MODE` が付けば2巡目にも適用される。ただし、これは受信側の再帰を止める規定であり、送信側の無限再相談は止めない。
