## 3. trigger-gating の headline 昇格条件 (D47 決定 5 の改訂)

D47 決定 5 の「命名固定と非両立」の原目的分析 (レビュー支持済み): 系レベルでは sweep grid が
構文契約から機械導出されるため post-coder 命名が C3 の設計を歪める経路は実在せず、写経リスクは
二層射影 + provenance + B レビュー転写検査 (D48 で PASS 実績) が既に担う。形式要件として:

**独立再命名工程 (canary、恒真化の自認込み):**
- 手続き: (i) 再命名者 = tools:[] の fresh コンテキストに、**識別子・コメントを機械的に匿名化
  した骨格 patch hunk** (rename + コメント除去。匿名化の等価性は preprocess 同値で機械検証) と
  偵察の生死二値のみを inline 前渡し (リポジトリ アクセスなし・シート・D 番号・軸名は渡さない)。
  (ii) 出力 = 構造化 3 項 (制御対象の状態変数 / 発火条件 / 作用点) + 中立命名。(iii) 一致判定 =
  両命名の由来を伏せた第三コンテキストが構造 3 項の対応で二値判定、曖昧は不一致に倒す
  (fails-closed)。(iv) **最終裁定者は人間** (D47 決定 5 の「人間再命名」の充足)。不一致時の
  帰結 = headline 使用停止 + 人間 gate 差し戻し。
- **限界の自認:** 匿名化しても骨格構造自体が意味を運ぶため一致はほぼ確実 (circular)。一致は
  「写経なし」の肯定的証拠として**報告に使わない** (その検査は provenance 三点セット + B
  レビュー転写検査が担う)。本工程は**不一致時のみ発火する canary**である。

この 3 点 (原目的の非該当 + 既存の転写検査 + canary) を満たす 8a 由来軸に限り主張 S の対象と
する。軸内探索主張 (旧 headline) の対象軸には引き続きしない。

## 6. 統計計画

- **提案ラウンド系 (S-2/S-3/C4/C5):** 単位 = ラウンドの二値 (「そのラウンドに適格提案 ≥1 あり」)。
  Fisher exact。**検定力概算 (レビュー実計算): n=5〜10 は完全分離級でしか有意にならない — 想定
  効果量 (本アーム 0.6 vs 対照 0.1) を Holm 初段 α=0.0125・検定力 80% で分離するには
  n≈20〜25/アーム。**提案ラウンドは計測ゼロ (LLM 呼び出し + 採点のみ) で限界費用が低いため
  **n = 20/アームを基準**とし、採点工数の上限とともに着手時に最終確定して本節に追記する
  (n<20 なら判定不能の確率が高いことを明記)。成功閾値 (適格率の下限) も n 確定と同時に事前固定。
- **入力の凍結:** 全ラウンド・全アームの射影入力 (地図・stock 抜粋・diagnostics) は pinned
  HEAD で 1 回凍結し (C4/C5 は同一凍結物の派生)、凍結物の hash を provenance に記録。
- **独立性の操作的定義:** 全アーム同一モデル・同一 sampling 設定を固定し provenance に記録。
  実質同一出力 (hole 位置・骨格が一致) はまとめて 1 件と数える縮約規則。適格率 (主指標) と
  相異なる適格軸数 (多様性、副指標) は別の観測量として登録。
- **「既存軸」(出口基準 (1)) の凍結:** §2.1 の 3 本 + 8a 由来の採用済み軸全部 (trigger-gating
  含む) + 過去ラウンドの適格提案 — ラウンドごとに単調増加 (provenance 記録付き) で閉じる。
- **多重比較:** Holm 族 = S-1〜S-3 の検定のみ ((c') は検定が存在しない宣言事項ゆえ族に入れない)。
- **S-1:** §2.1 の二段階判定 (スクリーニング = 偵察の型 / headline = 検証相の分布比較)。
