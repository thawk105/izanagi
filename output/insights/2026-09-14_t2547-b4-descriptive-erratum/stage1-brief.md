## 割れうる前提 (親の provisional 裁定。攻撃対象)

- **(P1)** 追補の置き場所は §5.1 内、「n と検定単位」bullet の直後。この bullet は
  `**予算上 n を確保できないなら「記述統計に留め有意性を主張しない」と本書に先に宣言してから実走する。**`
  と、分岐を §5.1 側で既に宣言している。§10「本書が閉じないこと」でも新節でも別 erratum file でもない。
  根拠は §0 の「本書が定める規範は §5.1 と §7 に置き、§5 の値セルへは書かない」。
- **(P2)** 適格な赤 precursor の在庫は 0 件 (別紙 `census-and-pin-closure.md`)。
- **(P3)** 記述統計分岐を宣言しても実走は許可されない。§5.1.1 の選択関数が独立に
  `design_not_feasible` を課すため。追補はこの点を明記する。
- **(P4)** §5.1 の分岐文言は「**予算上** n を確保できないなら」であり、§5.1.1 は
  「**適格な block を 201 件確保できない場合**」である。今回の事実は後者 (適格行 0 件) であって
  前者 (予算) ではない。追補はどちらの条件で分岐したのかを取り違えずに書く。

## DW-G05 成果物影響

放置すると B-4 材料レポートは「n = 201 の有意差実験」を前提にしたまま、実際には適格行 0 件で
永久に発効しない。追補で報告の型を「記述統計・有意性主張なし」へ結果前に確定させることで、
材料レポートの B-4 節が主張できる強さが決まる。
