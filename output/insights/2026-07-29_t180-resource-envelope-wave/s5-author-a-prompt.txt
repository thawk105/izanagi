- wall-clock だけが hard cap。`model_calls` と token は observable proxy であり、
  receipt に `model_calls_semantics` と `possible_unobserved_overshoot` を出す (R1, R3)。

  rollout と stdout の最終累積が矛盾しても非採用 (R2)。

- `--max-attempts > 1` は `--sandbox read-only` のときだけ許す。workspace-write では引数エラー rc=2 (R7)。
  失敗型の分類は**実装しない**。`retry_classification: "none"` を記録する。
- receipt は temp + fsync + `os.replace` で原子的に書く。最終 path は不在か完全のみ (R12)。
- manifest は `CodexWorkerSessionManifest`。create-only header (`wave_id`/`repo_root`/`base_commit`) を
  持ち、`--wave-id` が header と異なる append は rc=2 (R9)。追記は lock + whole-document replace。
- token 上限の量は `input_tokens - cached_input_tokens + output_tokens` (`cli_reported`)。
  `cached_input_tokens > input_tokens` は malformed として扱う (R4 と同義の検査を launcher 側にも置く)。
