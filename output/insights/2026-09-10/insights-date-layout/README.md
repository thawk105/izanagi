## 配置変更

- 588ディレクトリを `YYYY-MM-DD/topic/` へ移動した。
- 変更直後の直下件数は1,077から534、日付フォルダは43、同日への移動は最大39件。
- 基準の17,328ファイルは内容とGit modeを保持した。再圧縮・本文置換・実験結果の再生成はしていない。
- 既存の単独ファイル、実行資材、固定参照や移動で壊れるリンクを持つ資料は旧位置に残した。
- 旧名からの入口は [日付別一覧](../../README.md)。旧URLの自動転送ではない。
- 1,422件と1,424件のrawログは配置を維持し、各500件以下の6ページから全ファイルへ直接リンクした。

移動表と保留理由は [移動計画](migration-plan.json.gz) に保存する。
この表は上記基準に対する一回限りの記録であり、以降に追加された資料の索引ではない。

## 保留判定の区別

現在のconsumerやmanifestによる参照と、過去に観測した名前を区別した。
T2298/T2273のcopytree呼出し計測ログ2本は歴史的観測であり、名前が載るだけでは固定参照に数えない。
除外はその2パスだけで、ログ本体の保存照合と親ディレクトリの旧位置保持は維持した。
