`localflock` ではなく `flock` である。

=== 主張の限界 (重要) ===

**この probe は単一 host でしか走らせていない。**
mount option が `flock` であることは cluster 全体で効くことの強い状況証拠だが、**実測ではない**。
「Lustre の flock は cluster 全体で効く」と断定するには二 host probe が要る。本 wave では行っていない。

また、一時領域が担う正しさ契約は flock と O_EXCL だけではない。
`os.replace`、file と directory の `fsync`、`os.link`、別 client からの即時可視性も
load-bearing であり (段 3 レンズ A の指摘)、**いずれも本 probe では検査していない。**
