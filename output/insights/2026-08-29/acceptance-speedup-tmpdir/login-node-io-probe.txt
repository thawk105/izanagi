=== 比・差を引くときの注意 ===

本表は wall / median / max の 3 column を持つ。**比・差・throughput は同じ column から採ること。**
本 wave の親は当初これを混ぜ、表 (median) と本文 (wall) が食い違う値を書いた。

  n=32 の Lustre 対 /tmp:  median 29.061/0.081 = 358.8 倍   wall 29.746/0.124 = 239.9 倍
  小 file の絶対差:        median 0.930-0.022 = 0.908 秒    wall 1.493-0.084 = 1.409 秒
  /tmp の総処理量:         median 3200/29.061 = 110.1 /s    wall 3200/29.746 = 107.6 /s

=== 交絡についての限界 ===

pegasus02 は共有ログインノードで、測定中 loadavg は 7.4 から 19.1 へ動いた。
root 順・n 順は固定で、randomize も同時刻 paired も quiescence gate も行っていない。
`/tmp` は node-local、Lustre は cluster 共有で、利用者集合が異なる。
**この値は「この host、この時刻、この probe 形の観測」であり、受入への転写量は示さない。**
