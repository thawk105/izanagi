## 敵対検証が land 前に止めたもの (主なもの)

- **有意水準の事後選択。**候補数上限と累積 spending の締切が「本走の verdict の直前」になっており、
  本走の生データを見てから判定基準を選べた。締切を本走の**投入前**へ移し、さらに主系列の
  有意水準は pilot より前に固定する追補側へ移した。
- **承認済み bytes を束縛しない gate。**同じ path を後から書き換えた blob を事前登録として
  申告できた。決定を canonical 台帳へ追記した commit における同 path の blob を承認済みとし、
  その digest との一致を要求して閉じた。
- **状態表の網羅性の破れ。**「回復は見えたが劣化が閾値に届かない」領域がどの適格性状態にも
  入らなかった。また劣化版の方が速い場合を「浅い劣化」と誤分類していた。両軸を first-match の
  順序表へ組み替え、専用の状態を 2 つ新設して閉じた。
- **gate を満たしたまま規律を破れる投入。**待機 0 秒・常に成功する環境復帰指標・失敗分類の
  付け替えで、外乱を含む割当てを合格にできた。追補が越えてはならない線を明記し、
  追補の項目を全件必須・余剰禁止にして閉じた。
- **過大主張。**先行 commit の message と roadmap が D134 の要求を「履行する」と断定していた。
  台帳の仕組み上、最厳格解釈は満たせない。表現を限定し、差はユーザー裁定へ返した。
