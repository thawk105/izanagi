### B-1 — S0/S30 の救済は事前登録の解釈ではなく、解析規則の事後変更になる

**判定：must-fix**

**根拠：** `s4-ruling.md` §4.2 は「数値を分類する前に全部満たす」として `child-exit` を要求し、§5 は「早期死亡・**記録不足**」を機序表へ割り当てない。死亡が未確認でも、終端記録不足は該当する。§4.3 の E 後 heartbeat は即時 kill を否定する証拠であり、適格性の免除を定めていない。

親の科学的な読みには価値がある。子が会計終了後も生きていた以上、短い E−J を「会計終了時に子が死亡しただけ」で説明することはできない。しかし、それで事前登録の全条件を満たしたことにはならない。規律3に関しては、結果を見てからの受入条件変更を明示し、事前解析と分ける必要がある。

さらに §3.3(6) は**終端記録不足で追加投入停止**を要求する。M3 は S0 の t0+125 まで欠落を確認した後、M4 の G0 を投入している。S30 後も同様である。適格性だけでなく、進行規則からの逸脱も記録すべきである。

**推奨する書き換え文：**

> S0/S30 は `child-exit` 欠落により事前登録 §4.2・§5 の適格性を満たさず、主解析では打切りとして機序表への割当てを保留する。一方、E より明確に後の生存記録があるため、E 時点の子の即時死亡による説明を除いた事後解析を併記する。この解析は結果確認後の適格性緩和であり、事前登録どおりの判定とは区別する。終端記録不足後も追加投入した点は §3.3(6) からの逸脱として記録する。

原文を保存した erratum／逸脱記録と、後退した主結論の両方が必要。T-2676 へは候補を渡せるが、「事前登録により A 類確定」を設計前提にはできない。

### B-4 — 記録途絶を死亡・消失へ変換している

**判定：must-fix**

**根拠：** README §5 見出し、§0 引渡し文、§5 含意、§8 の「消えた」「何かに消される」「消失」は、同節の「死亡と記録障害を分けられない」と矛盾する。

生データでは S0 の最終記録が t0+40.001、S30 が t0+65.001。両方とも最終記録時点で子は `state=R`、fd 3 は初期と同じ device/inode の evidence を参照する。

| 説明 | 判定 |
|---|---|
| E 時点で子が即時に死亡した | 明確な E 後 heartbeat と両立しない |
| 設定された120秒 alarm が t0+40/65 の途絶を直接起こした | 設定・時刻と整合しない |
| 最終記録以前に fd 3 が閉じられた／別対象へ変わった | 採取した fd 状態に反する |
| 最終記録後の kill、停止、I/O 停止、記録失敗 | 区別できない |
| NQSV の後処理が kill した | 主体・signal・実終了を観測しておらず未支持 |

`recording_errors=[]` は保存済み行までの事実であり、最後の書込み失敗や停止を排除しない。fd 3 が開いていることも次の write の成功を保証しない。

**推奨する書き換え文：**

> session 離脱の2走では、会計終了の約35秒後まで heartbeat が保存され、その次の予定 heartbeat（約40秒後）以降は回収時点まで記録されなかった。これは記録列の途絶であり、死亡時刻の区間や残存子の回収成功を示さない。原因と主体は未同定である。

「t0+75 の `child-exit` に達しなかった」も「`child-exit` が記録されなかった」へ変更する。

### B-5 — T-2676 の設計入力が session 単位の回収を確定事項にしている

**判定：must-fix**

**根拠：** README §8 の「回収は session 単位が NQSV の判定と同じ粒度」は、内部判定未確定という限定を越える。元 session の列挙だけでは、既に別 session に移った子を拾えない。原票 T-2676 は遅延対策を求め、subreaper は採らないとしているが、session 離脱を完成した対策として承認していない。

付随観測は離脱案を否定しないが、「離脱後は既存機構が回収してくれる」という期待を根拠にできなくする。回収案にも対象範囲・残存子終了の独立検証が必要である。

**推奨する書き換え文：**

> pgid 離脱だけでは短縮せず、打切り走の事後解析では session 離脱と短縮が対応した。session 離脱・session を基準とする回収を検証候補とし、会計終了と残存子の終了を別々に評価する。離脱後の記録途絶は回収成功の証拠にしない。

評価項目として、会計遅延に加え、残存子の実終了・残存資源・別 session の子の扱いを渡す。対策選択はこの実験だけでは決まらない。
