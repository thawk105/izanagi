- blocker は、既知の赤の誤期待、宣言表と本文手順の非結合、lexical coverage を空集合化できる点。

- docs は grandfather と `local-ok` 定義、「全 heavy は compute」「機械強制は subtree だけ」の各主張を修正すべき。
- 24 行投影、collector の unbounded 根拠、正本所在、exact-path import には静的な不一致は見つからなかった。
