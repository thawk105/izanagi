### 現行→新制御流

- 旧: argv正規化 → deletion/ruleops/submodule → xdist/pip → pytest → task-run。
- 新: exact wrapper `--help` / `--version` → canonical site観測 → loginは即同期dispatcher → computeはhash-bound authorization消費 → local runner。
- login snapshotはqueue/budget/quota/free-space/size確認後、source外のcreate-only領域へclone。cached patchは `git apply --index`、unstaged patchはworktree-onlyで適用します。
- argvはrepo-relative表現でmanifestへ固定。外部target、response file、plugin/rootdir/path注入、symlink escapeは明示拒否します。
- qsub前にfsync済みjournalとpre-submit authorizationを作成。raw qsub ID、PBS raw ID、normalized IDを分離しました。
- schedulerはvisibility、queued、held、pre-running、running、disappeared、log grace、accountingを別状態・timeoutとして扱います。
- child rcは検証済みrunner-resultのみから採用。task-runはattempt/event有無だけをreceiptへ記録します。
- computeではPython 3.10以上と同interpreterのpytest/xdistを検証し、pip/network installを行いません。
