■ 目的
論文の必須経路から外れた 8b 正式系列 (凍結・批准・受領証・予算承認の手続き) 専用のツールと、実施済みの一回限りツールを、専用 test と一緒に削除し、git から引けるよう記録する。
速度の効果は小さい見込み (整理が主目的)。

■ 候補 (調査役の機械集計。削除許可ではない。対象ごとに D1989・D2179 を現物で確かめる)

■ やること
1. 各候補の参照を D1989 の 4 分類で判定する (import・subprocess・hooks・.claude・.codex・docs・manifest・hash・glob・動的ロード・admission registry)。専用 test に現役コードを検査する関数が混ざっていないか中身を読む (D2179)。権威 D を grep する。
2. 条件を満たすものだけを削除し、それを説明するだけの docs を墓標付きで git-history-only にする。runbook 等の言及行は削除または「削除済み、git log --grep='^prune' で引ける」へ置き換える。
3. 残したものは理由を一次資料に書く。
4. orchestrator/tests/README.md の allowlist、test_plain_runner_coverage、REAL_REPO_SERIAL_NODES、growth_test_holds、FLAKY_TEST_HOLDS など nodeid・file 名を固定する台帳に、消した test の行が残っていないか確かめて更新する。
