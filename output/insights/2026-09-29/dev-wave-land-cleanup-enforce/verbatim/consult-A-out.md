## 総括

**must-fix は 4 件**です。最重要点は、① plan の bundle 対象では子木固有の ref が漏れること、② manifest の exact path だけでは作成世代や land 完了を証明できないこと、③ branch tip の照合後に別の tip を `-D` できる競合が残ることです。P2 の main 前進は、proof 時の tip を main が保持する限り、統合証明を壊しません。今回は指定資料の静的検査のみで、テストは実行していません。
