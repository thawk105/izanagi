# 逐語の可逆な最小正規化 (DW-S07)

`git diff --check` に抵触する行末空白 (Markdown の改行用の 2 空白) だけを削った。可視文字は変えていない。

| file | 原文 sha256 | 原文 bytes | 行末空白を削った行 (1 始まり) と削った空白の数 |
|---|---|---|---|
| s6r1-out.md | 70bbf730b2000f2e5c465cf65e03b32634d5d257447bb8b6238e7c9382540e50 | 5069 | 3:2, 6:2, 9:2, 12:2 |
| s6r2-out.md | f8f49ef8333bce0084d6526c0d45c505781cfc185327f1448e1d1b985114f3f8 | 4401 | 3:2, 4:2, 5:2, 6:2, 9:2, 10:2, 11:2, 12:2, 15:2, 16:2, 17:2, 18:2 |

復元法: 表の各行番号の行末に、表の数だけ半角空白を足すと原文 bytes に戻り、sha256 が一致する。
