## 論拠

(1) を採る最も強い理由は、**land 判定量 W_0 が測る shard-0 では、A/B の共通 node 4,302 件が完全に一致している**ことです。新設 8 node はすべて B の shard-1 にあり、E1 不成立は shard-1 と shard-2 の共通 node の再分割によるものです。この再分割は、台帳にない新設 node を含めて決定的に割り付ける仕組みから生じます。現行 E1 は W_0 の比較に必要な範囲より広く、今回の land 判定量については過剰な失格条件になっています。

ただし、系列全体が A/B で実装だけ異なる実験になった、と言い切る根拠にはなりません。主張を **同じ shard-0 の同じ test 集合についての W_0 対比較**に限定することが、(1) の成立条件です。

## erratum 文面案

> **E1 erratum（計測結果の閲覧前に確定）**
> E1 の「A/B 共通 node の 3 shard への割付が完全一致」を、「各隣接対について、**shard-0 に選択された A/B 共通 node の multiset が完全一致**」に限定する。login collection の差が B の事前固定済み新設 node だけである条件は維持する。各走の緑、collection・実行 node の照合、HEAD・clean、系列順序、skipped node 一致など、他の有効性条件は維持する。
> この改訂 E1 を 01-A / 02-B にも同じように適用し、成立すれば対 1 として系列を続ける。残る対にも同じ条件を適用し、対ごとの例外は認めない。W_0 の Δ・対率、land の三対判定と 10% 境界、B の W_max 中央値による 5 分判定は変更しない。
> W_1・W_2 は A/B で shard の test 集合が異なるため、各走の値と構成を報告するだけとし、対差を「同じ test の比較」として解釈・提示しない。pre も各走の値を補助情報として示すだけで、差を実装効果と解釈しない。いずれも判定には使わない。
> この erratum の時刻、理由、旧 E1 と新 E1 の判定式、適用対象が既存の 01-A / 02-B を含む全対であること、**現系列の W と判定結果を未閲覧であること**を、結果ファイルを開く前に事前登録の追記として固定する。追記と改訂集計器の内容・ハッシュを記録し、その後に同一集計器で全系列を評価する。旧 E1 では不成立だった事実も最終記録に残す。

## 保たれる性質と失われる性質

login collection の差を事前固定した新設 node に限定する条件と、**W_0 を担う shard-0 で同じ test を同じ shard で比べる条件**は保たれます。判定量と閾値も変わりません。結果を見る前に明記して全対へ一律適用すれば、規律 3 と「事前登録は erratum でしか直さない」規則にも沿えます。

失われるのは、3 shard 全体で共通 node の割付が同じという保証です。したがって W_1・W_2 の A/B 差を同一 workload の効果とは呼べません。B の W_max は従来どおり実受入全体の 5 分判定には使えますが、その変化を shard-0 の実装効果だけに帰属させることはできません。

## 弱点

- E1 の緩和は、W を未閲覧でも **01-A / 02-B の有効性不成立を知った後**に行う。厳密な意味で当初から固定された設計ではなく、選択的な基準変更を疑われる余地が残る。
- shard-0 の test 集合が同じでも、A/B の collection と他 shard の構成は異なる。全体の実行環境まで同一という保証はない。
- 現行 `e1_pair_check` は全 shard の一致を要求し、`pair_metrics` は W_1・W_2・pre の対差を生成する。文書だけの erratum では足りず、結果閲覧前に集計器と表示も上記の解釈に合わせて固定する必要がある。

## 総括

(1) は、W_0 の判定に必要な同一 test・同一 shard の条件を保ったまま、過剰な全 shard 一致条件を限定できる。
採用するなら、結果閲覧前の erratum と集計器を固定し、01-A / 02-B を含む全対へ一律適用する。
結論の射程は W_0 の対比較と既定の全体 5 分判定までに限り、W_1・W_2・pre の因果的な対差は主張しない。
