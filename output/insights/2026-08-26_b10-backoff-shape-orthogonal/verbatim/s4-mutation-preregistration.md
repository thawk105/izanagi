# 段 4 変異事前登録 — B-10 待ち方 / 待ち量の直交切り分け

DW-M01 に従い、実装前に登録する。各変異は位置に加え、同じ入力を拒否する層が前後に無いこと、
無効化したときの赤理由が 1 つに絞れることを、段 5 実装後・段 6 変異本走前にコードで確認する。
確認できない変異は登録から落とし、実効 gate へ再照準する。

本 wave は**受理集合を縮小する** (新しい実行時 preflight を足す) ので、
承認外の過剰拒否を検出する正例も登録する。

## 変異 (期待 = KILLED)

| ID | 位置 | 変異内容 | 単一の赤理由 |
|---|---|---|---|
| M01 | driver preflight: patch 変更先の集合検査 | 許可集合を任意ファイルへ広げる | 骨格外ファイルを変えた patch を受理する |
| M02 | driver preflight: patch SHA 照合 | 照合を無条件 true にする | 事前登録と違う patch で campaign が始まる |
| M03 | driver preflight: マーカー個数検査 | 「各 1 個」を「1 個以上」へ緩める | 重複マーカー入りソースを受理する |
| M04 | driver preflight: hole の byte 一致 | 完全一致を部分文字列一致へ緩める | hole に追記のあるソースを受理する |
| M05 | driver preflight: stock 枝・待機ループの byte 一致 | 検査を削除する | 待機ループを変えたソースを受理する |
| M06 | driver preflight: inert 証拠 | `src_token == "stock"` の要求を落とす | 参照 genome が stock と別ソースでも通る |
| M07 | driver preflight: inert 証拠 | patch 未適用時に成功で return する経路を足す | 未適用を緑と報告する (既存テストの穴の再現) |
| M08 | driver preflight: 事前登録束縛 | 束縛を任意扱いにする | 束縛の無い WAL へ resume できる |
| M09 | 符号化・復号 | grid 外の形コードを許す | 3000 以上が黙って一定形へ落ちる |
| M10 | report: 曝露 gate | 最小曝露を下回るセルを成功数へ入れる | 経路未観測を無差の証拠にする |
| M11 | report: 多重比較補正 | Holm 補正を外し素の p を使う | 族全体の偽陽性率が制御されない |
| M12 | report: permutation 検定 | 符号反転を片側固定にする | 帰無分布が対称でなくなる |
| M13 | C++ 式 (hole 1 行) | 半幅族の下限を μ/2 から 0 へ戻す | Python 厳密モデルとの一致検査が落ちる |
| M14 | C++ 式 (hole 1 行) | 2 つの乱数形で別々の撹拌器を使う | 同一撹拌器を要求する検査が落ちる |

- M13 / M14 は tracked file の一時変異になるので `DW-O19` の復元規律に従う。
- hang しうる変異は無い。全件を dispatch 本走に載せる。
