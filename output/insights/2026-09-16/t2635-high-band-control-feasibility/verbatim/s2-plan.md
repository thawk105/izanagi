## 前提と読んだもの

指定された必読ファイル 15 本をすべて読んだ。解析器は全文を確認した。本段では trace の集計、probe の実行、ファイルの書き込み、commit は行っていない。以下の既知数値は必読資料に記録された値であり、本段の再実測値ではない。

プランの結論は、**既存 J1 をそのまま使えることと、別の双子候補が模擬上有望であることを分けて判定する**、である。親の P1 は支持する。ただし、次の二点は修正する。

- 同じ登録集合の再走も、既存 J1 を変えない唯一の候補として表に残す。一度の不到達から再走の不到達を確定しない。
- 「先頭 1,170 update」と「高域格子辺の上限」には適用条件がある。欠落した先頭を保持列で代用せず、理想格子の本数を保存 trace の無条件な上限へ昇格させない。

## P1 の読みと帰結

D2044 項 13 は「既存の事前登録を変えずに対照が作れると分かれば」と条件を付けている。一方、J1 の逐語は対象を **`nm-step1` と `nm-step1-u2560`** と名指しし、格子の説明も「6 セル、増やさない」「更新間隔だけが違う」としている。したがって、刻み、上限、extime などを変えた対照を、旧 J1 の登録済み対照として扱う読みは支持できない。

別の読みとして、「辺の完全一致、非ゼロ符号、固定重み、閾値を保てば、別セル対にも J1 の方法を適用できる」は成立する。しかし、これは**解析方法の継承**であり、登録された対照の継承ではない。新しい双子対は旧登録を保存した別登録 J1′ の候補で、その採否は「改めて諮る」側に属する。起草案と相談 A は、この区別を取り払う許可にはならない。

同じ登録集合の再走は、**設定変更なしの基準候補**として数える。現物 driver が受理する集合の再走であり、広窓セルだけの単独投入という意味ではない。これは登録条件を保存するが、記録済み広窓側の最大 12 µs は「次も届かない」という確率的保証を与えない。

従って、本 wave では次を別々に答える。

1. **登録・現物への適合:** 基準候補だけが適合する。
2. **到達・共通台の予測:** 記録済みデータを使う条件付き模擬として出す。
3. **裁定の分岐:** 模擬上有望な登録外候補があっても、自動的に「新走行」へ進まない。既存 J1 の成立を確認できなければ裁定パッケージを返す。

「旧登録下で成立を確認できない」と「将来のどの走行でも作れない」は区別する。

## P2 予測法 (各予測子の仮定と破れ)

**共通定義。** 到達は候補広窓列の `backoff_before` または `backoff_after` に厳密な `> 50` があること。共通辺は現在 event の非ゼロ符号を直前 event の順序なし辺へ帰属させ、両側の辺集合の完全一致で数える。主帯域は両端 `> 50`、感度帯域は `max(edge) > 50` とする。

**(a) 広窓 walk の刻み単位外挿**

記録済み広窓列の各端点 \(b\) を \(S b\) へ写し、event 順序と `gradient_sign` を保存する。これは stock を再実行するシミュレータではなく、**記録された歩行と符号の転写モデル**である。

到達のほか、写像後の列から既存部品で辺集合 \(E_{a,S}\) を作り、同じ刻みの記録済み u10 保持列の辺集合 \(E_{L,S}\) と交差させる。これにより、単なる訪問辺数ではなく模擬共通辺数を得る。

仮定は、刻みを変えても刻み単位の歩行、符号、1,170 update という予算を転用できること。破れは次のとおり。

- 刻みが変われば、一歩に対する throughput 差も変わる。
- 到達水準が変われば更新の実効間隔と窓内 commit 数も変わる。
- stock の `last_backoff_` は整数型であり、特に S=0.5 は単純な相似変換と同じ内部計算にならない。
- 符号を保存する操作は、変更後の throughput から符号を再計算したことにはならない。

既知最大値から転写最大値は S=0.5/1/2/25/100 に対して **6/12/24/300/1200 µs**。S=100 は上限 1000 を越えるため、**無断で clip して有効な stock walk と扱わない**。生の外挿値は残すが、候補の到達・K を決める有効な (a) には数えない。clip により自己辺が生まれ、その次の非ゼロ符号を保存してしまう問題も避けられる。

**(b) 同じ刻みの u10 の開始 1,170 update**

開始からの 1,170 event が保存されているセルに限り、その列を広窓側の代理列とする。辺集合 \(E_{b,S}\) と \(E_{L,S}\) の交差を数える。

ただし T-2583 §3.6 により、`nm-step0.5` は 152,205 update、`nm-step1` は 355 update を落としている。**この二つの開始 prefix は復元できない。** 保持列の先頭 1,170 件は参考集計として出せるが、(b) の成立票にはしない。欠落分をゼロ開始で補わない。

仮定は、更新間隔が違っても同 update 数で歩行が似ること。破れは次のとおり。

- 窓幅の違いが commit 数、符号の雑音、commit parity の分布を変える。
- `1170 × 10 µs = 11.7 ms` は**名目時間**である。実際の prefix 時間は `sum(window_us)` で出し、11.7 ms と断定しない。それでも約 3 秒の広窓列との状態差は残る。
- \(E_{b,S}\) は同じ記録の \(E_{L,S}\) の部分集合なので、交差は独立した双子間の再現を示さない。K を楽観的に見せうる。

**(c) 理想格子の構造上限**

固定刻み S、初期値 0、上限 1000、通常の隣接遷移だけを仮定すると、主帯域の非自己辺数は

\[
U_{\mathrm{transition}}(S)
=1000/S-\lfloor 50/S\rfloor-1
\]

であり、S=0.5/1/2/25/100 では **1899/949/474/37/9 本**となる。

ただし、既存 J1 は自己辺を一律除外しない。T-2583 の高域「辺種」307/196/38/10 も、非ゼロ符号を持つ辺数と区別して再現する必要がある。S=25/100 の上端自己辺は記録上ゼロ符号のみであり、38/10 をそのまま K の上限判定に使うことも、逆に 37/9 だけを保存辺の無条件な上限とすることも避ける。

出力では次を分ける。

- 理想格子の非自己遷移辺数。
- 上端自己辺を含む理想格子の辺数。
- 記録された全符号の辺集合、非ゼロ符号の辺集合。
- 理想格子外の保存辺と自己辺の生の計数。

S=100 の「9 本なので不可能」は、**非ゼロ自己辺が発生せず、保存辺がこの格子を忠実に表すというモデル内の結論**として残す。T-2583 が留保した表現上端の問題を本 wave で解消したことにはしない。

**追加する記述証拠**

全 6 セルについて、次の小さな集計を取る。

- 水準 `backoff_before=b` ごとの上昇・下降・据置数と `P(up|level)=up/(up+down+stay)`、平均変位。境界の据置を隠さない。
- 広窓符号列の lag 1〜10 自己相関。ゼロも含め、分散ゼロなら `null`。非ゼロだけに間引いて時間間隔を変えない。
- `window_commits` と `window_us` の件数、平均、分散、最小、p50、p90、p99、最大、および prefix の窓時間総和。

これらは外挿仮定への反証材料を増やす。水準依存の移動傾向があっても、1 rep の依存列から平均回帰の機序や未観測広窓の到達確率を同定しない。新しい確率モデルの fitting や到達確率の bootstrap は入れない。

結論には必ず次を付ける。

> 候補設定の到達・共通辺は記録済み走行を転用した条件付き模擬予測であり、候補設定で実測した結果ではない。二つの予測子は独立な証拠ではなく、未観測走行の成立確率を示さない。

## P3 判定語 (実行前に確定)

各予測子は数値とともに `applicable` と理由を持つ。欠落、上限超過、適用不能を 0 として処理しない。

| 対象 | 判定語 | 固定条件 |
|---|---|---|
| 到達 | `reach_predicted` | 有効な (a)(b) の両方で最大値 `> 50` |
| 到達 | `reach_not_predicted` | 有効な (a)(b) の両方で最大値 `<= 50` |
| 到達 | `reach_undetermined` | 二者が割れる、または一方以上が適用不能 |
| 共通辺 | `K_predicted_ge_10` | 有効な (a)(b) の両方で共通辺数 `>= 10` |
| 共通辺 | `K_predicted_lt_10` | 有効な (a)(b) の両方で共通辺数 `< 10` |
| 共通辺 | `K_undetermined` | 二者が割れる、または一方以上が適用不能 |

K は**全帯域と主帯域で別々に**この規則を適用する。主判断は `K_high`、全帯域の `K_total` は代用しない。感度帯域は数値だけ併記する。各辺では両側に一件以上の非ゼロ符号が必要だが、正負両方を要求する追加条件は置かない。

有効な \(K_a,K_b\) の最小・最大を `predictor_range` として保存する。これは信頼区間でも真値を挟む保証でもない。一方が無効なら範囲は `null` とする。

**(c) による優先判定は、実際に対象とする辺全体を覆う上限が証明できる場合に限る。** その上限が `< 10` なら他の予測子によらず `K_predicted_lt_10` とできる。ただし、本プランの理想非自己格子の 9 本だけでは、この優先判定を発動しない。S=100 は `ideal_model_K_high_lt_10=true` を別記する。

T-2583 の既存五状態語は、記録済み主対照の再現欄でそのまま使う。模擬候補を `executable` と呼ばない。既知の五状態表の未定義枝も、凍結表を拡張して埋めない。

また、`K_predicted_ge_10` は J1 の支持を意味しない。差 `>= 0.10` と三分区間の方向条件は旧 J1 に残り、本 wave は模擬候補の機序採否を計算しない。
