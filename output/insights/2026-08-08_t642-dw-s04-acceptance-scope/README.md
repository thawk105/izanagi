## 本 wave で最も重い出来事 — 義務形で書くと 2 方向へ誤読される

裁定文をそのまま義務形へ写した最初の案は、段 6 の焦点再レビュー 3 巡で**毎回別の誤読**が見つかった。
親はそのたびに文面を作り直し、3 巡目の指摘だけは `DW-O16` の 3 巡上限に従い親裁定で閉じた。

| 巡 | 文の形 | 指摘された誤読 |
|---|---|---|
| 1 | 2 文構成。1 文目に条件、2 文目に受入義務 | 2 文目に経路限定がなく、**通常経路の受入再走まで**「実 repo を読むテストがある場合だけ」に弱まる |
| 2 | 1 文へ統合し「実装差分ゼロの**ときだけ**」で束縛 | 今度は受入全走が**この経路限定の義務**に見え、通常経路の義務を反対解釈で打ち消す読みが立つ |
| 3 | 「実装差分ゼロ**でも**、免除は変異 matrix だけ。受入全走は免除せず」 | 譲歩の「でも」は必要条件を作らない。限定辞「だけ」が被免除物にしか係らず、**matrix 免除が通常経路へ漏れて**読める |

決着した形は、**義務を与える文ではなく免除の範囲を述べる文**である。
「免除は〈実装差分ゼロの『実装しない』裁定の変異 matrix〉だけ」と限定辞を条件込みの名詞句へ係らせ、
「受入全走は免除せず」で免除の否定だけを述べる。この形はどちらの反対解釈も生まない。

**教訓として一般化できるのは次の 1 点である。** 既存の一般義務がある検査について例外を書くときは、
例外側を義務形で書いてはならない。義務形は「その条件でだけ義務がある」という反対解釈を必ず生む。
免除集合の限定として書けば、一般義務は文法的に触れられない。

## 予算 — 増分は入口との重複削除で自弁した

`docs/dev-wave/**` の合計 byte 予算は着手時 25196 / 25200 で、**余白は 4 bytes** しかなかった。
裁定を満たす文はどれも 227 bytes の現行 2 行より長く、素直な改訂は上限超過 (25209) で実現不能だった。

支払い方として採ったのは、入口 `.claude/commands/dev-wave.md` が逐語で持つ重複散文
(「段 5・6 を飛ばして `4→7→8→9` とする」) の削除である。規範は入口 9 段状態機械に残っており、
焦点再レビューが入口の該当行を引いて規範喪失なしを確認した。結果は **25185 / 25200**、
余白は 4 → 15 bytes に増えた。

これは無害な節約ではなく、**並行 wave のための資源解放**でもあった。段 3 のレンズ B が、
本 wave の着手後に同じ 4 bytes を必要とする wave が 2 本発生した新事実を検出している
(それぞれ 13〜16 bytes と `DW-S03` の model 置換を要求)。余白に依存する設計を避け、
正味マイナスに収める判断はこの実測に基づく。

## 射程 — 機械が保証しないもの

`tools/check_docs.py` が `DW-S04` について検査するのは**節の実在だけ**である。本文の literal pin は
`DW-S09` にしかなく、**改訂後の文言が将来また旧射程へ戻っても機械は通す。**
また新契約は「実 repo を読むテストがあれば」という条件付き規則であり、
**その条件の否定側 — 誰がどの手順で不存在を判定し、証拠をどこへ残すか — は未定義のままである。**
段 3・段 6 の 4 本すべてがこの穴を独立に指摘した。本 wave は裁定範囲外として実装せず、
推奨案付きでユーザー裁定へ返した (下記)。

したがって書けるのは「契約文が改訂され、受入全走の免除が文面上は否定された」までである。
「これで docs 起因の赤を見逃さなくなった」とは書けない。

## 段 8 の改善候補 — reference 編集はしなかった

候補は 3 件出たが、いずれも既存 reference の是正には送らなかった。
(1)「例外を義務形で書かない」は手順ではなく採用理由なので decisions へ、
(2)「予算逼迫時は重複削除で自弁する」も同じく decisions へ routing した。
(3) `DW-O16` の 3 巡上限との噛み合わせは記録に留める — 同上限は「同じ NO-GO が続く場合」を
想定した文だが、本 wave は**各巡が前巡の所見を閉じたうえで別の real な所見を見つけた**。
この形では上限が「まだ塞げる欠陥を残して打ち切る」向きに働きうる。今回は 3 巡目の指摘が
文法的係り受けという現物で検証可能な性質だったため、親が fix を当てて 4 巡目を回さずに閉じた。
上限の文面変更は段構成・裁定境界に触れるため実装せず、実測としてここに残す。
