## 2. 形式の裁定 — 新しい日付の版ではなく stale 注記

`docs/paper-story/README.md` の契約は「新しい日付の版は、その日付時点の**正典全体**からの導出で
なければならない」「一項目の決着を届けたいだけなら、版を足さずに本 README の同節で指す」である。

- 契約が版に課すのは「版を作るなら全面再導出」であって、「複数項目が腐ったら版を作れ」ではない。
- 同節は現に「前版に対して積んでいた **2 項目**」と書いている。複数項目を積むのはこの節の既定の
  使い方であり、項目数は版を強制しない。
- 本体論文の最新版は 202 KB ある。本 wave の証拠水準で全面再導出すれば、かえって
  「その日付時点でそう主張した」という新しい嘘を作る。

段 6 のレンズ B もこの裁定を独立に closed と判定した。
