### 必要 block 数

統計モデル: block は母集合から独立同分布に引かれ、各 block は on 上位を確率 `a`、tie を
確率 `t`、off 上位を確率 `1 - a - t` で取る。対立は真の `A = a + t/2 = 0.60`。
非 tie 上の on 勝率は `p(t) = (0.60 - t/2) / (1 - t)`。`p(t) <= 1` から `t <= 0.8`。
検定は非 tie block 上の厳密符号検定、方向ごとの有意水準 `0.025`、目標検出力 `0.80`。

- 正規近似 (片側 `0.05`) の値は `154.56` で `155`。しかし `n = 155` の厳密検定は
  棄却境界 `89`、実 alpha `0.038438`、検出力 `0.770390` にとどまる。
- 方向ごと `0.025` に直すと、tie 率 0 での最小値は `199` (境界 `114`、実 alpha `0.023443`、
  検出力 `0.803714`)。
- **「tie 率 0 が最悪」は誤り。** 棄却境界が整数で離散に動くため、`n = 199` は tie 率
  `0.009` 付近で検出力 `0.794831` まで落ちる。`n = 200` は tie 率 0 で `0.786848`。
- tie 率を `0` から `0.8` まで `0.001` 刻みで走査した最悪値が `0.80` 以上になる最小の
  block 数は **`201`** (最悪は tie 率 `0.009`、検出力 `0.801748`)。
- `n = 201` について tie 率 `0` から `0.30` を `0.0001` 刻みで細かく取り直した最悪は
  tie 率 `0.0086`、検出力 `0.801743`。参考値は tie 率 `0` で `0.810382`、
  `0.1` で `0.835390`、`0.5` で `0.980309`。

`power(t)` は棄却境界が `t` に依存しないため `t` の連続関数であり、密な格子の最小値で
最悪ケースを近似できる。
