## 受理・拒否差分

変更前:

- `read_blob_at` は末尾 CR を prefix path へ alias し得た。
- LF/CRLF は batch request を分割し、別 path の blob を採用し得た。
- CR/LF を含まない非文字列は f-string の文字列化を経て受理された。
- `_safe_path` は先頭・末尾の CR/LF/tab を `_nonempty_string.strip()` の付随効果で拒否。
- canonical な埋め込み CR/LF、NUL、tab は受理された。

変更後:

- `read_blob_at` は `str(path)` 相当の値に CR/LF があれば明示拒否。
- `_safe_path` は位置を問わず CR/LF を明示 reason で拒否。
- CR/LF を含まない非文字列、通常 relative path は従来どおり受理。
- NUL、tab、その他制御文字、`./` 正規化、非文字列拒否は追加していません。
- `_nonempty_string` と path 以外の field の受理集合は不変です。
