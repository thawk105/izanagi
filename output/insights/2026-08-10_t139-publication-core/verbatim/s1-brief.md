## 3. 親の provisional 裁定 (P1〜P7 — 攻撃対象。段 3・段 6 で倒してよい)

- **(P1)** 新 study は「**同一の本走測定を入力とする公表専用 study**」とし、新しい割当てを 1 本も
  要求しない (追加費用 0)。新 core は測定プロトコルを再定義せず、現 core の cluster 適格条件へ
  外から従属する。
- **(P2)** 未調整 p 値は、追補 A `a10` が既に逐語で定義した `T_k = √J · μ̂_k / s_k`
  (`k = 1..6`、`s_k` は不偏標本共分散の対角平方根) の**片側 t 検定 (自由度 `J−1`)** を既定とする。
  新しい統計量を発明しない。
- **(P3)** 多重調整は **Holm** (Q7 の閉じた 2 択のうち、closed testing の shortcut であり検出力で劣らない)。
- **(P4)** 同時区間は `α_pub` を 6 成分へ **Bonferroni 配分した片側同時下限**とし、
  **Holm の棄却集合と一致しないことを明記する** (compatibility を主張しない)。
- **(P5)** `α_pub` は追補 B 草案 `b02` の値 (`0.05/(k(k+1))`、`k=1` で **0.025**) を
  **値として**引き継ぐ (文書としては引き継がない)。
- **(P6)** 非正規性の限界 (`J ≤ 13` で `t` が名目水準を守らない構成が存在する) は**解消しない**。
  `a12` と同型の**事前固定 stress check** を公表統計量へも課し、限界は明記する。
- **(P7)** 新 core の追補 field id は `p01`… とし、`a` / `b` 名前空間と分離する。
