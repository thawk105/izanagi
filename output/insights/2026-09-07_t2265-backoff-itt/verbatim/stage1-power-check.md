# 親による検出力の独立検算 (段 3 と並行、結果を見る前)

段 2 のプランが出した「cluster SD 0.032、R=12、TOST の等価判定力が約 82%」を、親が独立に
模擬で計算し直した。等価域は `±ln(1.03) = ±0.0295588`、片側 5% の TOST、
`t(0.95, 11) = 1.7958848` を使い、真値 0 の正規な run 差を 200,000 回引いた。

| cluster SD (log) | TOST の等価判定力 |
| ---: | ---: |
| 0.020 | 0.998 |
| 0.025 | 0.972 |
| 0.028 | 0.924 |
| 0.030 | 0.878 |
| **0.032** | **0.823** |
| 0.035 | 0.726 |
| 0.040 | 0.550 |

**プランの 82% は再現した。**

信頼区間の半幅の期待値 (R=12):

| cluster SD (log) | 95% 区間の半幅 | 90% 区間の半幅 |
| ---: | ---: | ---: |
| 0.0082 (段 1 の run 内 SE の最小値) | 0.52% | 0.43% |
| 0.0200 | 1.27% | 1.04% |
| 0.0282 (段 1 の窓 SD 上限からの見積り) | 1.79% | 1.46% |
| 0.0320 (計画値) | 2.03% | 1.66% |

**判定力は cluster SD に対して急に落ちる。** 0.032 で 82%、0.035 で 73%、0.040 で 55% になる。
したがって事前登録は「実測した cluster SD がいくつを超えたら等価と呼ばない」を先に書く必要がある。
本 wave では **実測 cluster SD が 0.035 を超えたら、等価判定を出さず「解像できなかった」と書く**
ことを事前に固定する (0.035 は判定力が 80% を割る点である)。

この検算に使った量は run 間の散らばりの**仮定値**だけであり、反実仮想の腕の outcome は使っていない。
