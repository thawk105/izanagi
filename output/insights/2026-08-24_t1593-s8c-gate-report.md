# T-1593 — 8c 事前登録関門の構造化報告

## 結論

`python3 -m orchestrator.campaign.s8c_gate_report --repo-root <repo> --commit <commit>` で、既存の
`activation_report_at(repo_root, commit)` を 1 回だけ再利用し、8c 事前登録の全体状態、§5 の各欄、
C01〜C12 の各状態・理由・証拠 path/hash を schema v1 JSON として報告できる。

- source が effective なら `PREREGISTRATION_EFFECTIVE` / exit 0。
- source が non-effective なら `PREREGISTRATION_NOT_EFFECTIVE` / exit 1。
- 評価不能・serialization・引数不正は canonical error JSON / exit 2。
- 認可境界は常に `authority=USER`、`report_effect=DOES_NOT_AUTHORIZE`、
  `decision_in_report=NOT_REPRESENTED`。report は正式測定を認可しない。
