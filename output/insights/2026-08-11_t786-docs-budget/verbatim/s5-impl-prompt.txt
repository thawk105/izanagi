### 検査契約 (段 4 で確定済み。勝手に緩めない)

**literal が「どこかに 1 件ある」だけでは通してはならない。**段 3 の両レンズが独立に、
「参照名として置くだけで実行しない」と書けば通る恒真性を指摘した (F170 と同型)。
したがって次の 4 つを **normative line の全文一致**で pin する。行は可視 top-level に
exact 1 件だけ存在すること。

| consumer | pin する行 (現行逐語をそのまま定数化する) |
|---|---|
| command 段 6 | `   受入直前に runbook の受入 lease を `tools/dev_wave_wait.py acceptance` で `claim` し、` を含む項 6 の全文 |
| command 段 9 | `   受入・land の終端で必ず `tools/dev_wave_wait.py acceptance` で `release` し、` を含む項 9 の全文 |

| `DW-O01` | `待機は `tools/dev_wave_wait.py producer` を使い、`--pid-file` は producer script 自身が `echo $$` で書く。` |

**逐語は必ず現行ファイルから読み取って定数化せよ。**この prompt の表は要約なので、
実ファイルと 1 byte でも違えば実ファイルを正とする。

### 恒真性を殺す negative test (必須)

`orchestrator/tests/test_check_docs.py` に positive 1 本と negative を最低 8 本足す。
**うち 3 本は decoy** — literal を残したまま義務を壊す形で、これが赤にならなければ検査は無価値である。

| id | 変異 | 期待 |
|---|---|---|
| stage6-relocated | 段 6 の normative line を段 5 へ移す | 赤 |
| stage9-deleted | 段 9 の normative line を削除 | 赤 |
| dw-c00-fenced | `DW-C00` の normative line を fence 内へ移す | 赤 |
| dw-o01-wrong-pid-source | `DW-O01` の `--pid-file` を `--pid` へ置換 | 赤 |
| target-symlinked | `tools/dev_wave_wait.py` を symlink 化 | 赤 |
| decoy-optional | normative line を残したまま同節へ「参考例であり急ぐ場合は手動投入してよい」を足す | 赤 |
| decoy-negated | 段 6 の normative line を否定形 (「…は使わない」) へ書き換える | 赤 |
| decoy-blockquoted | 段 6 の normative line を `> ` で blockquote 化する | 赤 |
| pre-wave-form | 段 6 を wave 前の逐語 (waiter literal なし、lease の `claim`/`acquired` だけ) へ戻す | 赤 |

`decoy-optional` は「normative line は exact 1 件あるが、同じ節に無効化する文が併記される」形である。
これを赤にするには、行の存在だけでなく**同節に義務を打ち消す語 (参考例・任意・手動投入・してよい 等) が
無いこと**まで見る必要がある。設計はあなたに任せるが、恒真にならない形にすること。
どうしても `decoy-optional` を機械的に殺せないなら、**殺せない事実と理由を報告に明記せよ**
(嘘の緑より遥かに価値がある)。
