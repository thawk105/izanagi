## 1. 定量所見 (確定)

### 1.1 hole 分布 — main と c5 は同じ穴に収斂し、c5 だけ epoch に張る

提案が指した hole の正規化分類 × アーム (提案数。分類は位置文字列の機械分類、境界誤差ありうる):

| hole class | main | c4 | c5 |
|---|---|---|---|
| read_internal スピン (読み取り相のロック解除待ち) | 18 | 0 | 20 |
| wal() flush 発火閾値 | 20 | 0 | 5 |
| epoch 管理 | 0 | 8 | 22 |
| lockWriteSet 競合分岐 | 6 | 0 | 3 |
| abort 後 backoff の発火 gate | 5 | 2 | 0 |
| read set 検証 | 0 | 1 | 4 |
| ハーネス/テスト/その他 (bomb_silo, tpcc_silo, replayTest, tuple.hh, silo_op_element.hh, gc) | 0 | 22 | 1 |
| 計 | 49 | 33 | 55 |

- **main∩c5 の重複 3 クラス** (read_internal スピン / wal flush 閾値 / lockWriteSet) — 帰属遮断の c5 が stock ソース読みだけで main と同じ「目立つ穴」に到達している。3 アーム共通の hole class はゼロ。

- **c4 の分散がそのまま適格率 17/20 の構造** — 選定無作為の帰結として CC 本体外 (ベンチハーネス・テストコード) への提案が 22/33 を占める。

### 1.2 main の hole 分布は診断の attribution と 1:1 対応する — 帰属の寄与は hole 選択に現れる

材料 1 の診断 (`frozen/scoring_user_prefix.txt` の diagnostics 節) は silo-backoff-magnitude の attribution 3 件 + silo-writeset-sort (dead) のみを含み、**epoch は診断に一切登場しない**。main の hole 4 クラスはこの 3 attribution で完全に説明できる:

| 診断 attribution | 対応する main の hole class (提案数) |
|---|---|
| (1) abort 後 backoff 待機 — IPC 崩壊 1.4-1.6→0.4-0.5 | abort-backoff-gate (5) + read_internal スピン (18。「同型の占有機構を別位置で踏む」という機序類推 — main-01 reason 等) |
| (2) validation ロック競合の no-wait 政策 | lockWriteSet 競合分岐 (6) |

main 49 提案が全て診断由来領域に載り、診断外領域はゼロ。対して c5 は診断外領域 (epoch 22 + gc 1 + read set 4) に 27/55 を張る。**帰属の寄与は適格率次元ではなく hole 選択の分布 (探索の方向付け) に現れている** — これが本分析の中核所見。

## 2. 凍結採点基準 (2') の設計事実 — 解釈の第一の鍵 (確定)

`frozen/scoring_system_prompt.txt` の基準 (2) は次を明記する:

> 診断 (attribution) への言及の有無それ自体は判定材料ではない。診断を参照しない機序仮説を、参照しないという理由で減点してはならない。stock 構造の観察だけから書かれた仮説でも、実在構造に繋がり反証可能な観測を指定していれば yes。
> 同様に、診断に言及していることを加点材料にもしない

これは D52 レビュー (C5 が旧基準 (2) の定義から恒真化する → 全アーム共通基準 (2') に置換) の帰結であり、**適格率次元での帰属寄与の中立化は設計に織り込み済み**。したがって c5 = 20/20 それ自体は採点の失敗を意味しない — 基準が「診断なしでも満たせる」よう意図的に定義されている。S-3 (main vs c5) の適格率比較が p=1.0 になるのは、**帰属の寄与がこの指標の測定範囲の外にある** (弁別力不足というより測定対象外) ことの表れ、が第一解釈。

(採点の甘さが混在していないかは独立の問い — §3 の質的所見と敵対検証で点検。)

## 3. 質的所見 (6 レンズ + 敵対検証)

### 3.1 レンズ C (c4 全数精査) — 基準に「CC 本体への作用」を要求する項が無い (最重要所見)

- **ハーネス入口ファイル (bomb_silo.cc / sbomb_silo.cc / tpcc_silo.cc) への提案 14 件中 10 件が適格**。WAL の open フラグ (O_CREAT|O_TRUNC|O_WRONLY)・ftruncate・thread affinity (setThreadAffinity の写像差し替え) といった**計測環境チューニングが変異軸として基準 3 項を素通り**した。「CC 本体でない」ことを理由に落ちた提案はゼロ — 凍結基準に並行性制御本体への作用を要求する項が存在しないため。
- **6 ラウンド (c4-04/13/15/02/14/12) はハーネス提案のみで round 適格** — これを除外した CC 本体換算では c4 は 17→**11/20 相当**。**探索的感度分析 (反実仮想):** main 20/20 vs c4 11/20 の片側 Fisher は **p=0.0006** (凍結の p=0.115 から 3 桁) — 基準の設計漏れ (CC 本体作用の要求なし) が S-2 の判定を支配していた。**この反実仮想は凍結判定には使えない** (事後の基準変更 = HARKing 境界の向こう側)。凍結集計 (17/20、p=0.115) は基準どおりの正しい適用であり変更しない — 本件は採点ミスではなく**指標定義の弁別力の問題**として報告し、次の実験設計 (基準への「CC 本体への作用」項の追加を事前登録してから再走するか否か) は人間判断に委ねる。
- **c1 (既存性) は無作為アームに構造的に有利** — c4 の c1 落ちはゼロ (無作為選定は診断既出軸と被らない)、main はサンプル中 2 提案が c1 落ち (score-038 prop0 / score-050 prop2 — 診断 attribution と同一作用点)。
- **採点の甘さは局所的**: 迷いを reason に自己文書化しながら yes に倒した判定が 2 件 (score-014 (c4-17) prop1 = high 疑義: 同型の自己申告を no に倒した score-036 と非一貫 / score-054 (c4-14) prop2 = medium)。**いずれも同ラウンドに別の適格提案があり round 適格 (=集計値) は動かない** (score-014 は prop0 も適格と確認済み)。曖昧→no の厳格運用の実例もある (score-036 (c4-03): 観測量の存在自体が未確定として no)。
- c4 の CC 本体側の適格は tuple.hh false-sharing / Tidword ビット分割軸に 6 ラウンド収斂 — ラウンド間 dedup は指標外のため適格率に映らない (アーム内多様性は S-2 が測っていない次元)。
- 採点者の誘導非追従は一貫 (全 18 score の overall_notes が束内の運用ラベルを「判定に影響させない」と明記) — 信頼境界の観点で異常なし。

### 3.2 レンズ B (main 全数精査) — c2 は main に弁別力ゼロ、round 反転級の疑義 1 件

- main 49 提案の判定分布: c1 no 4 / c3 no 16 / **c2 no 0 (全数 yes)**。reason は「診断 3 軸列挙 → 別処理段・別作用点」(c1) と「stock 実在 + 診断数値接続 + 反証可能観測」(c2) の定型で事後検証可能性は高い。中立化 (診断言及を加点しない) はおおむね遵守 — 「診断に言及しているから yes」の判定形は皆無。
- score-015 (main-05) prop2 (レンズ B は round 反転級 = main 19/20 の可能性と評価): abort 原因分類による backoff 発火 gating が診断 design_choice「待機の有効化 (on/off)」の軸内変異でないか、という疑義。この束は prop0 c1-no / prop1 c3-no のため prop2 が唯一の適格提案。**→ 敵対検証で棄却 (§3.7)** — 基準 (1) の no 条件に該当せず判定は正当。ただし「1 束の適格が単一判定に懸かる」構造自体は監査の参考情報として残る。
- 同型判定の非一貫 (high): score-045 (main-00) prop0 の lockWriteSet 有界スピン挿入は、score-038 が同型骨格を「曖昧側は no に倒す」で c1-no とした判定と非一貫 (yes 側に倒れた)。round には影響しない (prop2 適格) が distinct_eligible_axes に影響。score-002 (main-01) prop2 も迷い明記の上での yes (round 影響なし)。
- **c3 は提案側の宣言ラベルに脆弱**: 同じ wal-flush hole への提案が mutation_type 宣言だけで scalar 16 no / code_fragment 4 yes に分かれる — c3 の実効性は提案者のラベル選択に依存。
- c1 の検出力は部位依存: lockWriteSet 系では軸内言い換え検出が機能 (5 件中 4 no)、backoff 系は「量 vs 発火/形態」の細分化論法で全通し。
- **感度分析: 凍結判定は監査に頑健** — score-015 が監査で覆り main 19/20 になっても S-2 は p=0.115→0.30 (非有意のまま)、S-3 は p=1.0 (不変)。監査が動かしうるのは副指標 (distinct_eligible_axes) と解釈テキストのみで、有意性の結論は変わらない。

### 3.3 レンズ A (c5 全数精査) — 「診断なしでも基準 (2) は満たせる」は本物の実証、甘さは c2 の受理下限に局所混在

- c5 55 提案の reason が名指しする構造は**全て材料 1 に実在し、幻覚接続の見逃しゼロ**。c1 照合は厳格 (提案束の「diagnostics 空」自己申告に流されず材料 1 と照合、lockWriteSet 政策の再掲 3 件を no)。
- **c2 は c5 でも 55/55 全通し** (main と合わせ 104/104 — c2 の実効弁別力はゼロ)。実効弁別は c1 (3 件) と c3 (scalar 22 件) のみ。
- c2 認定の多数派 (34/55) は「実在ループ逐語名指し + ipc/latency/extra_reads/throughput の非感応で否定」という適正型 — **基準 (2') の帰属中立化は意図どおり機能し、「診断なしでも基準は満たせる」は採点の甘さではなく本物の実証**。
- 採点の甘さの局所混在 (c2 の受理下限): (i) 観測量ゼロの構造存在型反証 (「同ループの有無で反証可能」等) の受理 6 件 — **c5-11 / c5-01 の 2 束は round 適格がこの疑義提案のみに依存**、(ii) 準恒真形 (「計測不変なら棄却」) 3 件 (c5-19)、(iii) スコープ片側検査 (「効かない構成では差が出ない」) 6 件。厳格読みの幅: c5 20/20 → 18/20 (構造反証型のみ no) 〜 13/20 (スコープ型まで no)。
- **天井の主構造**: 全 20 束が stock で最も目立つ read_internal busy-spin を再発見して各束最低 1 件が適格化 — 「適格 1 件以上」というラウンド適格の定義は**単一 hole の 20 回再発見で天井に到達する**。

### 3.4 レンズ F (main vs c5 の同一 hole 対比較) — 帰属の寄与は機序の深さでなく「反証観測の条件付き具体性」と「損への集中」に現れる

- read_internal-spin 提案 38 件 (main 18 / c5 20) が全項 yes で全ラウンドの適格を単独担保 — 適格率はこの「確実な一手」で両アームとも飽和。
- 質次元の差は対ごとに非対称:
  - **wal-flush 対は main 明確優位** — 診断の書込比率単調帰属 (-1.9/-6.8/-13.4%・abort 不変) を引いた write-heavy 条件付き反証観測 + scalar→発火構造 code_fragment への昇格 4/20。c5 は 5/5 scalar 止まりで反証形が活性条件 (「WAL 無効なら効かない」) に退行。
  - lockWriteSet 対は骨格が両アーム同型 (差は main の workload 条件付き予測のみ)。
  - **read-spin 対は c5 が構造演繹で main に匹敵する機序具体性** (VAL_SIZE 比例のロック保持窓・storeRelease と同一キャッシュラインの奪い合い・_mm_pause 欠如) — 帰属なしでも機序の深さは補償可能。main 固有の優位は実測数値の移送と限界の自己認識。
- **結論: 帰属の寄与は「反証観測の条件付き具体性」「診断が名指した損への提案集中 (wal 20 vs 5)」「scalar→構造骨格への昇格」に現れ、機序の深さそのものには現れない。S-1 (性能次元) への判定重心移動を支持する予備観測**。

### 3.5 レンズ E (58 件全横断の監査重点スクリーン) — 疑義を全部厳格化しても天井はほぼ崩れない

- 58/58 通読 (137 提案 × 3 判定 = 411 判定)。**幻覚受理 0 件**。c4 のハーネスファイル「実在」認定も材料 1 の抜粋と突き合わせ済み (引き写し疑い棄却)。
- 「曖昧を yes に倒した」系統は 3 つ: (i) c2 反証観測の質検査の形骸化 (構造存在型・名目型の受理、c5 に集中 8 件)、(ii) 迷い記録 + yes が 6 件 (最直接の抵触例 = score-054 (c4-14) prop2「恒真接近を懸念しているが…最低限の実質性は満たす。yes」)、(iii) c1 の同型非一貫 1 件 (score-045 vs score-038 — 同型 no 判定は計 7 件で score-045 のみ yes)。
- **疑義を全部 no に厳格化しても round 適格が落ちるのは c5-11 / c5-07 の 2 束のみ (c5 20/20→18/20)** — read_internal スピンの主要受理は基準に照らし妥当な yes であるため。レンズ A の広い見積もり (〜13/20) との差はスコープ片側検査の扱いで、敵対検証と人間監査が裁く。

### 3.6 レンズ D (帰属遮断の破れ検査 + epoch 解剖) — 遮断は完全、盲検は本文から実質破れ (判定への影響は記録上なし)

- **帰属遮断は保たれたと確定**: c5 全 55 提案の本文数値 (111 出現) はすべて stock 抜粋のコード定数 (ReclamationEpoch=cur_epoch−2、LOGSET_SIZE/2、batch_max_ope 1000 等) か全アーム共通の生成プロンプト運用語彙に帰着。診断固有数値 (50.8→21.0、1.62、1.4-1.6→0.4-0.5、5.7→25、-77/-61/-22.5) との一致ゼロ、診断固有フレーズ (相反二効果・政策反転・単調比例) もゼロ。
- **由来盲検は提案本文から実質破れていた**: c5 束 19/20 が「diagnostics 空」を本文で自己申告し、main は診断数値を逐語引用する — 採点者は由来を識別可能だった。採点者は毎回「判定に影響させず」と記録し基準 (2') の言及中立化が機能した形跡だが、score-013 (c5-16) の overall_notes は「虚偽」認定で生成構成の推定に踏み込んでおり (基準は推定を禁止)、盲検破れの一次証拠として監査確認対象。
- **epoch 解剖**: c5 の epoch/GC 系 23 提案は (a) reclamation lag 定数の scalar 14 件 (全て c3 で機械落ち、c1/c2 は全 yes) / (b) siloLeaderWork 前進ゲートの構造変異 7 件 (適格 5) / (c) gc_records カデンス 2 件、に類型化。**診断 3 軸は epoch を一切指さず、「main が epoch を指さないのは診断が epoch を指していないから」仮説はデータと整合** (hole 無作為の c4 が epoch 8 件を出すことも補強)。
- read_internal スピンへの 20/20 到達は構造の目立ちやすさで説明可能: transaction.cc は編集面地図で opened=true の唯一の本体実装で、当該スピンは「spinning until the lock is clear」コメント 2 回付きの read フェーズ唯一の待機点。
- **副指標 distinct_eligible_axes もアーム間差を生まない (メインセッションで実測)**: 適格ラウンドの平均は main 1.45 / c4 1.47 / c5 1.50。ラウンド内多様性でも帰属の寄与は見えない — 帰属の寄与は「多様性」でなく「集中」(診断が名指した損への方向付け) であり、適格軸の数・多様性を測るどの指標もこれを捉えない。

### 3.7 敵対検証 (2 票制) の結果 — 疑義 42 件中、生き残りは 2 件のみ

6 レンズが挙げた疑義 (dedup 後 42 件) を、疑義ごとに独立 2 票 (票 1 = 凍結基準の文言との整合、票 2 = 引用・前提の事実確認) で敵対検証した。**両票通過は 2 件のみ、40 件は反証された**:

## 4. 解釈の二分への答え

**主因は (b) 適格率という指標の弁別力不足。(a) 採点の甘さは局所的に実在するが天井をほぼ動かさない。** 6 レンズ中 5 レンズ (C/B/A/F/E) が独立にこの結論に収束した。弁別力不足は 4 つの機構に分解できる (いずれも採点ミスではなく指標定義の性質):

1. **基準 (2') の帰属中立化 (意図された設計)** — 診断言及を判定材料にも加点材料にもしない (D52 レビューの C5 恒真化対策)。帰結として c2 は 104/104 全通し (main 49 + c5 55) で実効弁別力ゼロ。「診断なしでも基準は満たせる」は c5 の 34/55 の適正型受理が実証 — これは基準が意図どおり機能した結果。
2. **「CC 本体への作用」を要求する項の欠落 (意図されていない設計漏れ)** — ハーネスファイルへの計測環境チューニング 10 件が適格素通り。c4 の 17/20 のうち 6 束はハーネス提案のみで適格。反実仮想 (CC 本体換算 c4=11/20) では S-2 p=0.0006 — **S-2 の非有意はこの設計漏れが支配**。
3. **「適格 1 件以上」というラウンド適格の定義** — stock で最も目立つ read_internal busy-spin の再発見だけで各束が適格化する (c5 は 20/20 束すべてがこの hole を再発見)。単一の確実な一手で天井に到達する定義。
4. **c3 の宣言ラベル依存** — 同一 hole が mutation_type の自己申告だけで scalar 16 no / code_fragment 4 yes に割れる。

(a) の実例は敵対検証 (§3.7) を経て 2 件に絞られた (score-056 の c2 受理 / score-045 の c1 非一貫 — いずれも集計値を動かさない)。レンズ段階で round 反転級とされた疑義 (score-015、c5-11 等) はすべて「基準文言上、判定は正当」で棄却。感度分析のとおり、仮にこれらが人間監査で覆っても S-2/S-3 の有意性の結論 (非有意) は変わらない。

## 6. 主張 S の判定への含意 (すべて探索的 — 凍結判定は不変)
