# 保存資料の復元

原本は元job dirに保持する。保存時の末尾空白・末尾空行・改行欠落だけを正規化し、可視文字は変えていない。
`whitespace-errata.json` は変更したfileごとの原本SHA-256・byte数・行数・行末空白・最終改行有無である。
復元は保存文を改行で分割し、原本行数まで空行を末尾へ補い、`trailing` の1始まり行番号へ文字列を追加し、
改行で連結する。`final_newline=true` の場合だけ最終改行を付け、記録SHAとbyte数に照合する。
patch/source/runnerは実行・適用用ではなく逐語資料として `.txt` で保存した。製品実装へ取り込まない。
