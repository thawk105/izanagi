## 3. node 交絡の裁定 — 1.84 倍は node 差では説明できない

並列化前は `bnode003` (job `963545.nqsv`)、現行は `bnode015` (job `974207.nqsv`) である。
sol の交絡指摘は real だが、**この cluster のノード間の相対 SD は 1-2% 台**である
(`docs/pegasus-node-variance-protocol.md:19` の第 1/第 2 世代差 1.774%、
同 `:224` の within-node CV 1.2479% と材料閾値 `τ*` 0.6%)。1.84 倍を説明する大きさではない。

**ただしこの protocol が測ったのは throughput であって検査器の実時間ではない。**
本裁定は「node 差では説明できない」までとし、「並列化が原因である」とは断定しない。
断定には worker 数を記録する配線が要るが、それは実装面であり本 wave の scope 外である。

## 5. 数字の出し方 — 上限でなく感度で書く

`R` を変数のまま残し、`J+F=33 秒` (未分離) と `g=3 秒` を実測から固定して、
`J` と `F` の分け方の**両端点**で倍率を出す。

    (a)  = J + 33(F + R)
    (b)  = J + F + 32R + D + 31g       (literal な §11 (b)。duplicate skip で 32 物理行)
    (b*) = J + F + 33R + 32g           (33 行すべてを物理実行できると仮定した反実仮想)

実測 R 2 点での値 (`D=0`、終端費は未算入):

| R (実測) | (a)/(b) | (a)/(b*) |
|---|---|---|
| 908.908 秒 | 1.028 - 1.064 | 0.997 - 1.032 |
| 374.728 秒 | 1.023 - 1.110 | 0.992 - 1.077 |

**感度 (上限でなく、いつ大きくなるかで書く):**

- **33 秒がすべて job / process の共通費なら (`F=0, J=33`)、`R` がいくつでも
  `(a)/(b)` は `33/32 = 1.031` を超えない。**分母も分子も同じ 33 回の物理行を含み、
  差は行 1 本分だけになるからである。
- **33 秒がすべて run ごとの固定費なら (`F=33, J=0`)**、倍率は `R` について単調減少し、
  `R → 無限大` で同じ `1.031` へ収束する。`R = 908.9` 秒で 1.064、`R = 374.7` 秒で 1.110、
  観測から組める最小の行 (build 50 + legacy 8 + S2 1 パス 63 = 121 秒) でも **1.27** である。
- **`(a)/(b) = 33` はこの模型では `R = 0` でも到達しない。** `R = 0` でも 8.6 である
  (分母が 33 秒 + 31 x 3 秒の行間費を残すため)。
  **倍率がちょうど 33 になるのは、分母が物理行を 1 本しか実行しないときだけである。**
  そのとき `(a)/(1 行) = 33(F+R)/(F+R) = 33` になる。
