## 結論 (先に読むこと)

- **凍結事前登録 core §14 の追補 B (`b01`〜`b03`) の草案を起草した。**閉集合を exact-key で
  過不足なく満たし、field key の解決が `{b01, b02, b03}` に一意であることを親が機械的に確認した
  (fields 範囲内の fenced block に見出し行 0 件)。
- **草案が提案する値。いずれも未承認である。**
  - `b01` 候補数上限 = **1**。承認済み資源上限 26 割当てが、追補 A の `a10` が確定した内訳
    `検証 1 + pilot 8 + pilot 予備 2 + 本走 13 + 本走 予備 2` でちょうど候補 1 本分であるため。
    **導出ではなく governance の提案値**と明記した。上限の変更は本追補を書き換えず、
    同じ根・同じ配分表を継承する新 study の新追補で行う。
  - `b02` 個別公表系列の spending = **`0.05 / (k(k+1))`**、本 study は `k = 1` で **`0.025`**。
    総和がちょうど `0.05` なので**候補数上限に依存せず**、後から上限を上げても配分の総和は
    `0.05` を超えない。未使用 tail は回収も再配分もしない。
  - `b03` 正規の根 = `(fold_commit = 88d68f91…, ledger_kind = individual_publication)`。
    primary とは別台帳で、根は呼び手が選べず、予約は作成のみ・失敗しても番号を解放しない。
- **`q` を変えない。**本書は臨界値 `q` の導出規則 (`a11`) にも primary の有意水準 `α₁` (`a13`) にも
  値を与えず、`alpha_pub_k` を primary の入力にしない。本文は両者を**参照はする**が固定し直さない。
- **3 field はいずれも測定値を入力に取らない。**候補の通し番号と固定定数だけの関数である。
  **ただし「実際に pilot の生データを見る前に凍結された」という時点の独立性は、文面からは
  検証できない。**草案はこれを主張しないと明記した。
- **段 6 の敵対レビュー 2 本がどちらも NO-GO を返し、初稿の中心設計を倒した。**
  初稿の `b02` は公表用の `p` 値の式・Holm の閾値列・同時区間の使い方まで書いており、
  これは「配分の数値」を越えて新しい推論規則を足す閉集合違反だった。
  `b03` の「primary 予約 entry への必須参照」も、裁定 U8 の別台帳の範囲を越えうる新しい拘束であり、
  かつ**その参照が無くてもリセット経路は閉じる**ことを示された。
  **両方とも受け入れて草案を縮めた。**現在の `b02` は配分の数値だけを持ち、公表手続きを
  定めないと明記する。`b03` から親参照を外した。
- **レビューが見つけた事実誤りを 2 件直した。**
  1. 資源内訳を `8 + 2 + 13 + 3` と書いていた。追補 A の確定値は `検証 1 + 8 + 2 + 13 + 2` である。

     `pilot_admission: requires_addendum_a` を狭めるので、追補 B には書けない。
- **段 2 プランの中心的結論を 1 つ倒し、1 つは倒しすぎた。**
  「公表 6 セルの正体は決まらない」は**誤り** — 追補 A の `a10` が
  `(N_W1, H_W1, G_W1, N_W2, H_W2, G_W2)` と逐語で列挙している。一方、親が段 4 で下した
  「公表用の統計量も固定済み」は**行き過ぎ**だった — `a10` の `T_k` は標本数設計のための定義であり、
  公表用の帰無分布・`p` 値・多重調整はどの凍結文書にも一意には定まっていない (段 6 で是正)。
- **段 2 プランの「第 1 候補へ 0.05 全額」は採らなかった。**全額を使い切ると次候補は必ず新しい根を
  立て、そこで `0.05` を再取得できる (独立 2 候補で `1 − 0.95² = 0.0975`)。

  裁定 R2 (a) で 2026-08-09 に置換済みである。ただし親が確認したところ、その erratum 文書は
  未発行であり、実効上の欠落は消えていない。**追補 B の閉集合の外なので本 wave では書かず、

  さらに cluster 代表値が非正規なら `t` に基づく手続きは名目水準を守らない
