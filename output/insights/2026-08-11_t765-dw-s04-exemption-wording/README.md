## 本 wave で最も重い出来事 — 3 巡の焦点レビューが 3 つの別々の誤読を潰した

候補文はすべて予算内 (L1 余白 19 bytes) に収まったが、**3 案が 3 通りの別の理由で破れた**。

| 巡 | 文面 (bytes) | 破れ方 |
|---|---|---|
| 1 | `免除は「実装しない」と裁定され実装面差分ゼロの wave の変異 matrix だけ。` (101) | 連用形 `裁定され` の**省略主語**が当該 wave に固定されず、別対象の裁定を拾う `E∧Z` が成立 |
| 2 | `免除は「実装しない」裁定済みで実装差分ゼロの wave の変異 matrix だけ。` (98) | `で` の**原因理由読み**が「裁定ゆえに差分ゼロ」という因果条件 `R` を作り `C∧Z∧R` へ縮小 |
| 3 | `免除は「実装しない」裁定済み・実装差分ゼロの wave の変異 matrix だけ。` (98) | **中黒が選択列挙にも使われる**ため `C∨Z` が成立し、旧文より免除が**拡大** |

3 巡目の指摘は親が独立に裏を取った。同じ文書群で中黒は連言
(`範囲・言語・起動手順`、`台帳・test・trust root`) にも選択
(`指定 reference が不在・読めない`、`process の非 0 終了・timeout`、`反転・緩和・skip・削除を禁じ`) にも
使われており、連言演算子に固定されていない。

`DW-O16` の 3 巡上限に従い、4 巡目の fix を重ねず親裁定で `かつ` へ確定した。
**根拠は最悪ケースの非対称性** — `かつ` は選択読みを構造的に持たない (選択は `または`) ため、
どの読みを採っても免除集合は `C∧Z` 以下にしかならず、旧文の意図した集合を超えない。
本 repo でも `docs/decisions.md` に 60 例あり、すべて連言として使われている。
**確定文は第 4 巡の敵対レビューを受けていない**ことを残余リスクとして記録する (撤回は 1 行の置換)。

なお 1 巡目で入れた `実装面` (入口の凍結境界が定義する語) は撤回した。`core.md` 単体からは定義へ
到達できず、新しい曖昧さと引き換えになるためである。射程は独立の裁定へ分離した。
