  dev-wave の作法の穴 2 件を `DW-S01` へ入れたいが、L1 の空きが 1 byte しかなく入らない。
  (1) 承認済み検査を置換・粗化する案を出すとき、その文書自身の「既知穴 / 改版差分」節を先に読む
  規律がない。本 wave の親は §6/§7 を読んで案を作り、同じ穴を逐語で記録している §0.2 を
  読んでいなかった。(2) 「既存機構で満たせる」という判定を、要件の逐語と実装の逐語を
  突き合わせずに brief へ書ける。本 wave で 2 件とも誤りだった。
  自己改善契約の「予算に収まらなければ変更を止めてユーザー裁定へ返す」に従い入口も
  reference も編集していない。圧縮での捻出は exact pin を壊すため採らない。
