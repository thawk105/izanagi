**構成の裁定 (段 4):** 段 2 プランは新規 3 文書、段 3 レンズ B は新規 4 文書 +
`tools/check_docs.py` への `LIVING_DOCS` 登録 (実装面 1 件) を推した。親はどちらも採らず、

**親の実測の誤りを段 3 レンズ A が反証した。** 親は brief に「論文主張としての不在断定は
repo に 0 件」と書いたが、これは grep の hit を読まずに分類した誤りだった。実際には
