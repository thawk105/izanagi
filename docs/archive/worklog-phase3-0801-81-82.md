## 2026-08-01 (82) — [T-229] conftest の /dev/shm 誘導を撤去し 16 GiB のユーザーメモリ枠を守る — tmpfs 消費 7.39 GiB → 0 (コード + docs、branch worktree-dev-wave-devshm-avoid、受入 = Pegasus gen_S 計算ノード)

  `dispatch_compute` 変更) は段 3 敵対レンズが (a) 全経路で評価されない装飾であること、
