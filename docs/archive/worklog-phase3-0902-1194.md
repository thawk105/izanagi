  protocol を 1 workload 分だけ回す」。出所は `docs/paper-story/2026-09-02.md` §8 の A-6 (台帳 ID 未起票)。
- **投入は行い、判定は `indeterminate` で確定した。** attempt `a6-20260902a`、request

  既に定めているが、A-2 / A-6 の certification 経路はこれに従っていない。
