## 2026-08-23 (856) — land 成功後に wave が自分の worktree と branch を撤去する経路を新設した。掃除が滞っていたのは怠慢ではなく、占有検査が zombie 1 本で恒久的に通れなかったためだった (コード+テスト+docs、branch worktree-dev-wave-stage9-self-cleanup、変異matrix = baseline PASSED・MUT-1〜8 8/8 KILLED・SURVIVED 0・MISMATCH 0)
