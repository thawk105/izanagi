  そのもので、2026-09-03 に実データで発火した。**索引が頁境界で同じ work ID を 2 回返しつつ

  OpenAlex の非 shard 枝を諦める。(a)(b) は完走述語の変更なので意味的 amendment に当たり、
  新 epoch・新 query ID・全枝の再実行を要する。**着手前に裁定が要る。**
