## 1. 理由

- block 1 (2026-09-23 投入、cohort `t2850-trial-v1`) は 6 job のうち 3 系列が欠測した。random・sweep は系列開始 stock の bench 前の静定待ち
  (1 分 load average ≤ 4.0、上限 20 秒) の時間切れで品質欠測、LLM は親 session が LLM の週次上限 (HTTP 429) で止まった。
- 評価 1 回の約 91 % が正しさの検証 (legacy 1 回と、性能の動作点の 3 秒の trace 5 本の直列性検査) だった。試走の見積りは 40.8〜58.2 node 時間で、
  ユーザーは費用を問題にして block 2・3 の投入を止めた (2026-09-26)。
- 費用を削る案をユーザーの委任で codex に相談し、案 (b) 「trace は直列に取得し、取得済みの 5 本を同じ node の別 process で同時に検査する」を
  採った (a: LLM の待ちを node の外へ、は後回し、c: 系列数・B・N_eval の縮小、は不採用)。記録は
  `output/insights/2026-09-26/t2850-trial-pause-cost-options/README.md` と `output/insights/2026-09-26/t2850-trace-concurrent-verify/README.md`。
- 2026-09-26 のユーザー裁定 (D2249 の追加項) により、実験設計に時間帯の区切りを入れない。

## 2. 検査の順序と全件検査 (本登録 §3.1 の「実装の修正」)

- 性能の検証 pass (trace 5 本) は、5 本を**直列に取得してから**、5 本の検査を同じ node の 5 process で同時に行う。legacy の 1 回は従来どおり直列。
- **全 trace を検査する。** 各 process の検査は直列の経路と同じ verifier・同じ引数 (commit 数の照合を含む) で、判定・閾値・検査の対象は変えない。
  検査の結果は親の process が受領証 (HMAC 付き、一回限り) を確かめてから rep の順に記録へ反映する。
- **不認証・異常の扱い:** ある rep が不認証・異常・取得失敗なら、その rep より後の検査を止めて結果を使わず、その rep までを rep 順に記録して
  評価を reject する。各 rep の結果が直列と同じなら、記録の段の並びと reject の理由は直列の経路と一致する。
- 検査 process 自体の故障 (異常終了・結果の欠落・受領証の不一致・process の消滅を確かめられない) は `verify-local-unavailable` として reject する。
  比較 harness はこれを機械故障ではなく候補の `aborted` に数える (機械故障の再試行の対象にならない)。これは既知の限界で、試走で起きたら
  件数と理由を失敗の内訳 (本登録 §5) に書く。
- この実行方法は比較 harness の write-heavy の全 slot (系列開始 stock・初期点・探索・endpoint の測り直し・block job の stock と参照点) に掛かる。
  read-heavy・balanced には掛けない (検査の同時化の記憶量と静定の実測が無い)。

## 3. 静定待ちの上限と品質欠測

- bench 前の静定待ちの**閾値 4.0 と `settled=true` の要求は変えない。** 上限だけを、上の同時検査の後の初回の待ちに限って 20 秒 → **120 秒**にする。
  bench の測り直し round の前の待ちは 20 秒のまま。
- 根拠 (計算ノードの実測、node は開始時に空き): 本番と同じ順序 (5 本の連続取得の直後に同時検査) で、load が 4.0 以下に戻るまで
  stock 67 秒、候補の代理 (B0-L-W0) 77 秒。上限は最大 77 秒の約 1.5 倍。当初の 60 秒 (別の順序の実測 3〜39 秒から決めた値) では、
  smoke の stock が上限を使い切って品質欠測になった。
- 上限の 120 秒を使い切った評価は従来どおり品質欠測で、本登録 §5 の「欠測は系列の結果として残し、系列を差し替えない」を変えない。
- **未解決:** block 1 の直列の経路での静定の時間切れ (stock 12 session 中 5 件) の原因は確定していない (直列の検査の直後の load は 1.6〜3.0 で、
  検査の余熱だけでは説明できない)。LLM の週次上限による欠測も解消していない。どちらも試走の失敗の種類として記録する。
