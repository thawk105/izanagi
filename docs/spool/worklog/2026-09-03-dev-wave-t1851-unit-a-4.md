## 本文

- **単位 A の後半 A2' も 1 wave に収まらず、A2α と A2β へ割った。** 段 2 plan と段 3 の 2 レンズが
  独立に測り、A2' 全体は 1,380-1,900 changed LOC / 新設 110-145 node / 既存回帰 487 node と一致した。
  本 wave は A2α (E3 = `_assert_profile` の schema 別 exact validator 化 + E4 の構造面) を積んだ。
  一次資料は `output/insights/2026-09-03_t1851-a2alpha-generation-open/`。
- **分割の向きを plan とは逆にした。** plan は `E1+E2+carrier` を前半に置いたが、blocker が
  すべて前半に集中し、前半はユーザー裁定なしに着手できない。**裁定待ちの部分を先に置く分割は
  wave を空回りさせる。** 親が段 1 で立てた候補 (`E1+E2+E3` / `E4`) も plan が現物で反証した —
  E3 を path 分岐より先に開くと v2 が誤った 1 段 destination へ進む。
- **前 wave が固定した境界 signature は、前 wave 自身が承認した要求を実装できない。**
  3 者 (plan、レンズ A、レンズ B) が独立に同じ結論へ達した。2 つの封印 terminal API は
  観測・封印記録・終了時刻しか受けず、生の事実は起動層の token open 後にしか揃わない。
  {{D:v2-terminal-stays-closed-until-sealed-api}} で暫定拒否を置き、境界の補正は裁定へ返した。
- **`repetition_evidence` は production 起動層から到達不能だった。** 許可引数に無く、内部 sink も
  作られず、既存 test はむしろ明示指定を拒否する。`DW-O13` に従い、到達不能な入力を要求する
  validator は実装しなかった。到達化は起動層 (単位 C) の所有面である。
- **変異走が、静的レビュー 4 本が見落とした「消しても誰も気づかない防壁」を 3 つ暴いた。**
  詳細は {{F:static-review-kill-verdict-contradicts-mutation-run}}。うち 1 件はレビューの 1 本が
  kill する nodeid まで名指しして「殺される」と判定していた箇所で、実走ではその node は
  赤にならなかった。3 件とも実装は正しく、足りないのは検査だった。
- **親自身の段 6 裁定 2 件も実測が覆した。** fix が入れた直接検査によって、SURVIVED と裁定した
  2 変異が実走では単層で殺されていた。fix 後の状態を静的に再評価しないまま登録すると、
  変異台帳が事実と食い違う。
- **resume の回復序数 gate は冗長 gate だった。** 受理集合が変わる負例を作らせようとしたところ、
  fix 子が「予約側の同じ gate が先に拒否するため公開経路でその状態を作れない」と報告して
  実装を変えずに停止した。`DW-M03` に従い診断感度の pin として別枠に記録し、kill に数えない。
- **capability 束縛の範囲を広げず、明記する形を採った** ({{D:v2-marker-binding-scope-is-declared-not-widened}})。
  分類 claim・分類行・回復行は marker 経路を通らない。境界が要求しておらず既存と同じ形なので
  防壁は足さず、束縛される側とされない側を exact に pin して非束縛の集合を成果物へ明記した。
- **工数:** codex 子 12 本 (plan 1、consult 2、author 1、review 2、fix 6。いずれも `gpt-5.6-sol` /
  xhigh)。plan・consult・review は read-only、author・fix は workspace-write。receipt が一次資料。
  **12 本すべてが `qstat -Q preflight rc=1` により pytest を 1 度も実走できなかった。**
  親からの同じ投入は D612 の opt-in 上書き (queue-wait 3600 / overall-grace 600) で通る。
  検査はすべて親が実走した。
- **検査:** 焦点走 606 node 緑 (変更 test file 2 本の単独走 86 + 89、consumer 閉包 431)、
