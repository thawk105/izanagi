## 本文

- **除外した格子点は捨てていない。** 並行セッションの指摘で、当該点の実体が 0 µs の
  独立な反復であることに気づいた。3 workload すべてで 0 µs 点と 3 指標が走間ばらつきの
  内側で一致し (9 件の比較すべて)、**コード読解による符号化の解釈を、独立な走行の数値が
  別経路で裏づけた。** 同時に read-heavy のピークが端点であることの反復再現にもなっている。
  詳細は F718 の supersede 追記。
- **相互照会の実績。** 本 wave が並行セッションへ渡したもの: fold の再帰上限赤が越えた窓
  (fold 4 件・実装は無改変) と、顕在化する node 集合がスタック消費で変わること。
  受け取ったもの: 要求した build define が黙って無視される型の実例、hold が資源上限型には
  原理的に使えないこと、批准機構の閉包と競合 6 面の対応表、そして上記の反復の指摘。
  **双方の警告が相手の無駄走行を実際に止めている。**
- **本 wave の残作業は計測機外での作図だけである。** `.dat` と `.plt` は生成済みで、
  PNG 未生成の事実も判定 JSON へ記録済み。作図は計測機で走らせない規約に従う。
