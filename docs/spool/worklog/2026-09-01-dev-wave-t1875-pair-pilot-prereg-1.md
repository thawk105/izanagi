## 本文

- **事前登録を発行しなかった。** 段 2 の計画子と段 3 の敵対相談 2 本がいずれも NO-GO を返し、
  親が real / refuted を裁定した結果、独立に十分な停止理由が 3 件あった。裁定パッケージの全文は
  `output/insights/2026-09-01_t1875-pair-pilot-prereg-ruling/README.md`。
- **停止理由 1: 対象の不一致。** 計画は固定候補集合の順序対を測る pilot を設計したが、8c の
  1 アームの結果は `G=2` の最終世代の生成 variant である (D1066)。固定候補のばらつきは
  生成 variant のばらつきの推定になっていない。
- **停止理由 2: `delta_min` の独立な根拠が無い。** judge は毎秒トランザクション数の絶対値を
  要求するが、床値 (0.22% / 0.67% / 1.07%)、A-3 利得 (+38.3288% / +11.2682% / -6.6430%)、
  A-1 方針の 3% と ±6% はすべて相対値だった。絶対値を持つ既存実測はいずれも閲覧済みの結果であり
  独立な根拠にならない。値を作らずユーザー裁定へ返した。
- **停止理由 3: 判定パラメータの表現が分断している。** §5 parser は `H1` / `H2` の 2 根 key に
  それぞれ `n` / `delta_min` / `sd_max` を要求するが、judge は単一の `_ContrastParams` を
  6 cell 全体へ適用する。H 別の値を渡す経路が無い。この欠陥は T-1874 の完了条件に属する。
- **計画の層の数え方も誤りだった。** 「`H1/H2` × 2 holdout = 4 contrast」としていたが、
  `H1` と `H2` がその 2 holdout そのものである。manifest はちょうど 6 cell (2 holdout × 3 arm)。
- **既知結果台帳の欠落を敵対相談が挙げ、親が現物で 1 件を確かめた。**
  `output/insights/2026-08-24_paper-story-a1-paired/result.json` に A-1 探索走の対差平均
  -5698.0 と標本 SD 43649.05535060295 が絶対値で存在する。計画はこの結果から作られた A-1 方針を
  導出式の手本にしていた。台帳を T-1142 だけにすると HARKing 境界の宣言が偽になる。
- **親の当初根拠を 1 件撤回した。** 着手順序の根拠に挙げた D229 決定 (6) の援用を撤回する。
  D229 は別系列の個別裁定で 8b §10.2 の再凍結より古く、本件を支配するのは後発かつ主題固有の
  §10.2 である。ただし着手自体は止まらない — §10.2 の 5 条件は「値を記入してよい」条件の連言で、
  条件 2 (pilot 完全 block 成立) と条件 4 (結果を見る前に決定) は pilot の事前登録が pilot に
  先立つ順序を前提にしている。T-1874 の保留は T-1875 の着手を禁じない。
- **論文側の対応づけが依頼の枠組みと食い違った。** 依頼は §8 の A-1 と B-4 を要求として
  挙げていたが、B-4 は `A_min = 0.60` と符号検定から `n = 201` を確定済みで「pilot を持たない」と
  自ら凍結しており、A-1 は `formal=false` の別方針・別対比である。この pilot が完走しても
  A-1 と B-4 の未取得状態は動かない。ユーザーの確認を要する。
- **T-1777 との重複はゼロだった。** 起動時と段 3 時点の 2 回、稼働中の T-1777 作業ツリーの
  未 commit まで走査した。未 commit は T-1777 自身の spool 断片と insight のみ、branch の
  commit は 0 件。所有の裁定として、A-1 の pilot 事前登録・反復数決定・sized 方針は
  T-1777 が所有し、T-1875 は 8b/8c 専用に限定する。
- 実装面の差分はゼロ。既存の凍結成果物の bytes を 1 つも変えていない。性能測定・build・
