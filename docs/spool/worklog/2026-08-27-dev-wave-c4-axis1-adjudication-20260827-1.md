- **3 索引 (arXiv / OpenAlex / DBLP) の生死と構文をこの計算ノードから直接実測した。**
  3 索引とも総件数フィールドを持ち、解釈後クエリを応答に含める。**しかし語の意味論も cutoff の
  粒度も違う** — arXiv はフィールド指定の語・句、OpenAlex はステミング、DBLP は前方一致で
  引用符を剥がす。cutoff は arXiv が投稿日時範囲、OpenAlex が出版日範囲、DBLP は年 facet だけである。
- **既存記述の誤りを 1 件実測した。** `docs/related-work/literature-map/README.md` は
  「OpenAlex は API キー未設定のため今回未使用」と書くが、**OpenAlex はキー無しで 200 と
  `meta.count` を返す。** litmap は監査前の生データなので書き換えず、訂正は事前登録が持つ。
- **偽陰性の罠を 3 つ実測した。** (1) DBLP は要求 `h` の超過を黙って 100 件へ切り詰め、
  エラーを出さない。(2) DBLP は要旨を索引していない — DCDS の要旨にある `recency-sorted` で
  0 件を返す。(3) DOI の表記が索引で違う (DBLP は `10.48550/ARXIV.…`、OpenAlex は
  `https://doi.org/10.48550/arxiv.…`) ため、正規化せずに突き合わせると 0 件になり
  「片方の索引に無い」と誤読する。
- **OpenAlex には従量の面がある。** 応答ヘッダが `x-ratelimit-limit-usd: 0.1` /
  `x-ratelimit-cost-usd: 0.001` / `x-ratelimit-prepaid-remaining-usd: 0` を返す。
  キーを送っていないので課金は発生しないが、**無償枠は 1 窓 (約 7.76 時間) あたり
  100 リクエスト相当**である。**キーの追加も前払いもしない**と契約に明記した。
  polite pool の `mailto=` も使わない (ユーザーの email を無関係なサービスへ送らないため)。
- **`要裁定` 3 件の判定。**
  - `2404.13359` (Declarative Concurrent Data Structures, EPFL, cs.DB, 2024-04) = **`直接接地` /
    極性 `競合`**。逐次仕様から thread-safe なデータ構造を生成する枠組みで、**CC を注入する。**
    実行時に transaction manager があり `begin_txn` / `end_txn` / commit / abort / rollback を持ち、
    評価は MTPS で in-memory OLTP DBMS (Proteus) と比較し最大 2 倍。**勝因を論文自身が
    "it specializes concurrency control to the target workload" と書いている。**
    **LLM も学習も進化探索も一切無い** (`llm` の 1 件は著者名 Ballman の一部)。
  - `2512.18746` (MemEvolve) = **`部分接地` / 極性 `方法論的祖先`**。
    LLM エージェントの記憶機構を 4 部品へ分解し、軌跡の診断から**部品の実装コード**を
    書き換える。ShinkaEvolve / EvoLattice に B✓ を与えたのと同じ基準である。
  - `2605.22721` (DecentMem) = **`除外`**。生成物は自然言語の記憶片と行動であって設計空間の
    生成ではない。7.4 の既存採録 (`外部補強`) は動かさない。
  - 件数保存則: 直接接地 5 + 要裁定 0 + 部分接地 18 + 除外 6 = 29。
- **`2404.13359` の A は規則の文言だけでは一意に決まらなかった。**「論文の対象が並行性制御である」
  は主題領域とも成果物の種類とも読める。**親は主題領域の読みを採った** — pilot が
  `1905.08406` (成果物は判定手続きであって CC 機構ではない) を `直接接地` と裁定した時点で
  既にその読みが採られているからである。**段 3 の敵対相談が構成した反対の読み (成果物で判定 →
  `部分接地`) は逐語で記録し、その場合の件数も併記した。**
  **足りなかったのは一次資料ではなく規則の解像度だった。**
- **同じ読みを一様に当てると、`除外` された第 25・26 行 (`2208.00315` / `1710.04839`) の A が
  疑わしくなる。本 wave では再判定せず、ユーザー裁定へ送った。**

  系譜」で、DCDS に LLM が無いからである。見解相違は裁定記録に残した。
