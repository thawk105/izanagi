## 本文

seq 1 ([T-338]) に続き、`/rulings all` 索引の残りのうちユーザーがルールへ実体化できる 8 件に
「推奨通りで」の裁定を得た (ユーザー発話「推奨通りで。main land までやってほしい」)。

**T-1387 と T-1352 の整合:** 提示時の推奨に内在する緊張 (T-1387=現状維持のため凍結世代を
消費しない/T-1352=実行のため凍結世代を要する) を、T-1387 が凍結世代を消費しないなら
「まとめて 1 回で」という当初の理由づけ自体が不要になる、と整理して解いた。結果として
T-1387 は単独の現状維持、T-1352 は単独で実行、と扱う。

索引の項目 3・4・13 (`s8c-reservation-gate-dominance` / `s8c-crash-policy-cell-partial-semantics` /
`s8c-evaluator-reject-started-edge`) は branch `worktree-dev-wave-s8c-c12-c04-c11` の未 land
fragment にしかない未採番項目であり、本 wave の namespace からは placeholder を解決できない
(spool README「他 wave の slug は参照できない」)。裁定内容は repo 外 inbox 控えへ記録した
(`/work/1/SFC/tanab/dev-wave-jobs/rulings-inbox/2026-08-19-s8c-c12-c04-c11-3rulings.md`)。
その wave が着地し T 番号が確定した時点で、次の /rulings 総ざらいまたは当該 wave 自身が
canonical へ反映する。
