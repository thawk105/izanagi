  61 + 1 bytes だった。裁定の実体 (新規 L2 節・意味等価な捻出・義務を弱めない) は変えず、
  数値は本 wave の実測を優先した。
- **親 brief の byte 予測は誤りで、段 2 と段 3 の両方が独立に訂正した。** 親は 9,475 と予測したが
  条件行を 84 bytes と置いた誤りで、実逐語は 98 bytes。確定値は入口 **9,497 / 9,500 (余白 3)**。
  親が `measure_final.py` で独立計数して確認した。self doc は **5,964 / 6,000 (余白 36)**、

  閉じた主なものは (i) 条件 25 の trigger が親から観測できない形だった
  (`locked_main != tested_tip` は land 内部の状態) → 「main を進める land を起動する直前」へ、
  (ii) routing 3 の縮約案が削除側から「L2 のうち」と「義務代替済み」を落としていた、
  (iii) 入口の重複一本化案が「全走」を「受入全走」へ狭め「統合 commit」を分解していた
  (D227 条件 2 違反)。**捻出は −71 から −61 へ減ったが予算内に収まった。**

  - fix 1 巡目: 規範逐語を合成 fixture へ焼いた結果、参照先の `D254` / `D271` /
    `docs/failures.md` が合成 repo に無く **222 件が連鎖赤**になった。参照検査を緩めず

    末尾注入が新 pin にも当たり finding が 2 件になった。`DW-M03` に従い注入点を
    pin 済み節の外へ移して単一理由へ戻した (期待値の緩和はしていない)。222 → 5 → 0。
  - fix 3 巡目: 順序 pin の heading 探索が題込みの前方一致で、題を消すと
    **finding を出さずに通っていた** (恒真と同型)。fail-closed にした。
- **敵対レビューの blocker 1 件を実測が反証した。** 「pin 済み節の内側へ raw HTML block を置けば
  可視 slice を変えずに例外文を仕込める」という所見は成立しない。raw HTML block は次の空行まで
  続くため直後の本文行を巻き込んで空行化し、可視 slice が変わって既存の節 exact pin が単独で
  検出する。fix 3 巡目が「可視 slice は変わらない」と主張する中間 assert を書いたテストが
  **その assert で赤になり**、それが反証になった。追加した raw/可視一致検査は多層防御として残した。
- **変異は 2 件が過剰決定で、実効 gate へ再照準できなかった。**

  **冗長 gate として単独変異の証拠から外した**。初回台帳と探索台帳は erratum として残す。
  wave 前の実コード形の変異要件は、docs 側を wave 前へ戻す 3 件と checker の順序探索を
  修正前へ戻す 1 件が満たしている。
