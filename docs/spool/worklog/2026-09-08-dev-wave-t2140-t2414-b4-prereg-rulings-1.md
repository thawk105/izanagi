  渡していたが、同じ拘束は **2026-09-05 の D1649 決定 2 で既に撤廃されていた**。同決定は
  「事前登録本文の改訂は同文書の改訂契約に従って別 wave が行い、`p3_b4_admission_record.py` の
  行 label 集合は変えない」と明記しており、**その別 wave が本 wave である**。段 1 brief に出し、
  段 4 で反映を確定した。D1649 は実測された新事実ではなく、本文へ未反映のまま運ばれていた既裁定である。
- **段 2 プランは未授権の値を発明していた。** 「発効版では `開始時刻 = 予定日時の事前指定なし` と
  記す」という案で、`p3_b4_admission_record.py` の sentinel 拒否を避けるためのものだった。
  D1649 の逐語は「欄は `未記入` のままでよく」である。**段 3 の 2 レンズが独立に real と判定し、捨てた。**

  D1649 の逐語だけを反映し、§0 の sentinel 規則との矛盾は「本追記では決めない」と明記して
  ユーザー裁定へ返した。

  D1641 決定 3 が確定した具体値とは別物なので、書き分けた。混同すると floor 成果物の採用主体が

  現プランが primary outcome の出現だけを対象にしていたので破れ無しと判定した (境界は本文へ明文化した)。
  同所見 8 の「7,440 秒は根拠の無い派生値」も、driver が測定ごとに `reps` を渡し成果物 header へ

  ただし**根拠が本文に無い**という指摘の側は real として採用し、根拠を明記した。
