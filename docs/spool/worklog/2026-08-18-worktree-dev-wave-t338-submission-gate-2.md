## 本文

- **ユーザー裁定 (T-338 Q1 = 択 (a)) が付けた着手条件を実行し、条件が発動した。** 裁定は
  「投入 gate を 1 単位で完成」を命じつつ「着手前に規模の見積りを実測で出し、D205 / D220 の
  水準に触れるなら同 wave 内で範囲を切り直すこと」を条件に付けていた。実測 = production
  2,570〜6,200 行。D220 が過大と判定した 645〜816 行の **3.2〜7.6 倍**である。
- **切り直しの 2 案を独立 3 本 (段 2 プラン子・段 3 敵対レンズ 2 本) が全員「承認済み受理述語の
  緩和」と判定した。** 起動命令は「規律 2 を緩める方向の変更は採らない」と明示しているので
  親は採れない。結果として本 wave は実装しない。詳細は {{D:t338-gate-sizing}}。
- **親の実測誤りを 4 件撤回した。** (1) 「全履歴検査を粗い機構へ置換しても述語は保存される」は
  不成立 — 台帳を truncate して同じ予約を再作成すれば累積有意水準がリセットできる。しかも
  **承認済み記録項目 §0.2 が同じ穴を既知として逐語で記録していた**のに親はそれを読まずに案を書いた。
  (2) 検査の階級分けを 4 か所で誤った。(3) 「symlink 対策は既存実装で無料」は誤りで、既存実装は
  最終 component しか守らない。(4) 「duplicate key 拒否は既存実装で無料」も誤りで、その実装は
  承認外の canonical bytes 制約を一緒に強制するため流用すると受理集合を無承認で狭める。
  (3)(4) は段 3 レンズ A が指摘し、親が一次資料で裏取りした。
- **段 3 レンズ A の blocker 1 件を refuted と裁定した。** 「申告値の拒否専用化は 3 者一致を
  2 者一致へ弱める」という指摘は、§6.3 の逐語自身が第 3 脚を「`cmake_cache` の**申告値**」と
  定義していること、およびレンズが挙げた反例が凍結 schema に raw pointer 0 件である以上
  どの実装でも検出できないことから、拒否専用化に固有の弱化ではないと判断した。
  schema 自身の限界として保証境界へ書く。
- **T-139 裁定パッケージ V1 の「回避経路が無いことの実証」を反証した。** これが本 wave の
  最大の前進である。CCBench の cmake が解析/trace フラグを compile definition として吐くため、
  CMakeCache の 2 値は `compile_commands.json` に必ず現れ、凍結 schema はその
  `compile_commands` を `fileRecord` として既に持っている。**B1 は凍結 bytes を 1 bit も
  変えずに閉じられる**ので、V1 が要求した新 exact-byte approval payload は不要になり、
  D320 との衝突が消える。D500 が同定した閂の直接の解除である。
- **D500 決定 (6) が次 wave の段 1 要件と定めた再利用先の棚卸しを完了した。**
  attempt 台帳の hash 連鎖 replay と opaque write capability と祖先検査は採る。
  T-126 固定の series FSM と identity module、および holdout admission の台帳本体は採らない
  (最後のものは同 file 自身が耐性を保証範囲外と明記している)。
- **エージェント工数**: codex 子 3 本 (plan 1・consult 2)、いずれも `gpt-5.6-sol` / `gpt-5.6-luna`。
  段 2 は 12:35〜13:03:08 (約 28 分)。段 3 の 2 レンズは 13:05 起動で 13:13 / 13:16 完了。
  段 2 子の stderr に codex models 更新の 401 が出たが本走は完走した (別セッションの周知どおり
  12:56〜13:04 に枠の取り合いがあった。本 wave の子はいずれも即死パターンに当たっていない)。
- **変異 matrix は免除** (`DW-S04`: 実装しないと裁定済みで実装差分ゼロ)。**受入全走は実走した。**
- **段 8: 候補 2 件は docs 予算に入らず、自己改善契約に従い編集を止めて裁定へ返した**
  ({{T:dev-wave-approved-check-premise}})。予算の実測 = `docs/dev-wave/**` の **L1 unique
  footprint は現在 10,624 bytes で上限 10,625 bytes、空きは 1 byte** である
  (候補の追記は 178 bytes を要した)。圧縮での捻出は exact pin を壊すため採らない。
