## 本文

- **ユーザー裁定 D1770 の実施であり、新しい設計判断はしていない。** D1770 は D1653 を追認して
  D1563 を supersede し、あわせて D1653 の「再発行は規律 7 に反する」の射程を狭めよと命じた。
  本 wave はその記述修正だけを行った。実装は既に着地しており 1 行も触っていない。
- **訂正は新規 D ({{D:d1653-reissue-claim-scope}}) の追記で表した。D1653 本体の bytes は変えていない。**
  canonical 3 台帳の既存 bytes は fold 以外が変更せず、fold も既存 D エントリ本体への挿入経路を
  持たない。同型の訂正を新規エントリで表した D548 を先例として踏んだ。
- **広すぎる表現は D1653 の 2 箇所にあった。親の初回実測は 1 箇所と誤っていた。** 親は
  `git grep` に「規律 7 に反する」を当てて理由欄 第 2 項の 1 件だけを見つけたが、却下した選択肢
  第 1 項には活用形「規律 7 に反し」で同じ主張が書かれており、**検索語が活用形を落としていた。**
  敵対レビューがこれを real 所見 (重大度 高) として指摘し、親が語幹「規律 7 に反」で引き直して
  2 箇所であることを確認した。新規 D は 2 文とも名指しして撤回している。
- **敵対レビューは 1 レンズ・read-only。real 5 件 (高 1 / 中 1 / 低 3)、refuted 0 件、全件採用した。**
  最重要は上記の取りこぼし。次に重いのは、親が却下欄へ書いた「どの成果物を再発行してよいかは
  時間付き束縛と下流 digest 鎖の有無で個別に決まる」という一文で、**scope 外の一般規則を新設し、
  凍結・事前登録・較正・correctness gate といった既存の前提条件を十分条件から落として読める**と
  判定された。この文は削除した。逐語は
  `output/insights/2026-09-08_t2410-d1653-scope-narrow/verbatim/review-1.md`。
- **境界の一次資料は `output/insights/2026-09-07_t2254-old-grammar-cause/README.md` §5.2。**
  同節は、測定後に時間付きの事実を復元できないこと、後日作った派生記録と明示した新 artifact の
  発行自体は禁止されないこと、その新 lock は当時の測定時 lock の代替にならないことを記録している。
  **新規 D の文はこれらを統合した記述であって、一次資料からの逐語引用ではない。**
- **セッション異常 (2 件、いずれも高負荷起因)。** 起動時の負荷平均が 60 を超えており、
  (a) `git worktree add` が 3 分以上かかった。完了前に別の git を当てて `index.lock` 衝突
  (rc=128) を起こし、本体 pid を `tail --pid` で待ち直して回復した。
  (b) `tools/dev_wave_submodule_init.py` が 30 秒の内部 timeout で `update-no-fetch` 失敗。
  同じ argv を長い timeout で温めてから再実行して通した。どちらも既知の型で、新しい失敗ではない。
