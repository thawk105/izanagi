### 新規

- {{T:acceptance-lease-self-renew}} **P2・新規 (ユーザー裁定済み 2026-08-11、推奨 3 点セット採用)**:
  受入 lease に自己保持の更新経路を実装する。(1) `claim` が自己保持を検出したら TTL を更新し
  `held-self` を返す (生存証拠のある holder の renew は lease の標準形、ハングした wave は
  呼べない) / (2) 正本待ち手 (`dev_wave_wait.py acceptance`) の受理集合を `{acquired, held-self}`
  へ広げる (`claim` 出力の `holder_self` を使う) / (3) 自己保持を検出したのに進めない場合は
  黙って polling せず fail-closed で理由を出す。**却下済みの代替 = release して取り直す**
  (飽和時に待ち行列の最後尾へ戻り、解放窓で他 wave が飛行中の木と並行受入を始める)。
  共有調整機構なので専用 wave (テスト + 変異つき、wave 前の実コードの形 = 自己保持で `held` を
  返し待ち手が進まない形を変異 1 件に含める) で実装し、runbook §7.3・`DW-O23`・
  memory の「2 走目前に取り直す」記述を同時に整合させる。
  正本 = t756 handoff の「land 後に起票する裁定候補」節と inbox §96
