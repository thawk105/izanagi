## 本文

- ユーザーが全件を「推奨どおり」で裁定した。**ただし親の初版推奨のうち 4 件は、別系統モデルへの
  相談で覆ったあとの版である。** 裁定されたのは覆った後の推奨であり、初版ではない。
  覆った 4 件は {{D:floor-budget-counted-by-cross-generation-replay}} (専用 ledger を作る →
  作らない)、{{D:hold-evidence-is-provisional-fragment-bound-before-land}} (非帰属判定を証拠に
  受理する → 規律 2 を緩めるため撤回)、{{D:mocc-trace-oid-remedy-chosen-after-graph-probe}}
  (択 (a) を推奨 → 優位性の根拠が出せず比較先行へ)、{{D:s8b-a6-proof-is-approved-g1-successor}}
  の owner 分け (主体単位 → 工程単位) である。
- **推奨を保留していた 3 件は、相談が根拠を出したため推奨付きで裁定できた。**
  {{D:b4-proposal-binding-closes-in-the-loop}} と
  {{D:campaign-flock-covers-authorization-through-checkpoint}} は相談が実在の正しさ欠陥と判定し、
  {{D:reference-tps-domain-measured-before-ruling}} と
  {{D:raw-producer-authentication-layer-chosen-by-rejection-power}} は「実測すれば択一が消える」と
  判定した。親は一次資料が推奨を添えていないことだけを理由に保留していた。
- **索引に載せた 25 件のうち 10 件が既に裁定済みだった。** 相談が主題で照合して見つけた。
  内訳は Web 検索禁止文言 (D1149)、certified sink 一般化 (D1256、実装も着地済み)、
  R33 事前登録の identifier 撤去 (D1254)、B-4 分析契約の文面不整合 (D1247)、凍結 pin の絞り込み
  (D1152)、凍結表への注記の残余 (D1208)、archive 免除路 (D1158)、`output/runs` の ignore 判定
  (D1063、F665 で実装済み)、変異 nodeid の正規化 (実装待ちとして既指定)、占有検査の不在 path 拒否
  (D795、実装済み) である。**いずれも T-ID を持たず台帳側にしか実体が無い項で、
  親は台帳から拾ったが後続の裁定を主題で前方照合していなかった。**
- **収集は F668 と F669 の型を両方とも実際に踏み、どちらも索引確定前に回収した。**
  詳細は該当 F の再発追記に記す。
- エージェント工数: Codex 相談子 2 本 (`consult` / `read-only` / `xhigh`、レンズは推奨の当否と
  索引漏れ)。いずれも rc=0。実装子・レビュー子は起動していない。実装面の差分はゼロ。
