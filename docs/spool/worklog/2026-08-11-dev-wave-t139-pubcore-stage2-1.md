- **裁定時点で未見だった事実を 4 件、`DW-S04` に従ってユーザー再裁定へ戻した** (`package.md` の Q1〜Q4)。
  1. **`b03` の縮小には 3 つの副作用がある。**(i) 同じ根のまま台帳実体を取り替えて ordinal を
     再取得する経路を追補 B 側で塞げなくなる。追補 B は新 core の追補を参照できないため
     B 側に手段が無い。(ii)「一意性が成立しないまま本走を投入してはならない」という
     **投入前 admission が 1 つ消える** — 受理集合が広がる方向の変更であり親が独断で通せない。
     (iii) `b01` に予約規範が残るため「予約の正本を 1 箇所へ一本化」は文言どおりには成立しない。
     親の推奨は (a) 裁定どおり外す。
  2. **追補 P は新 core と同一 land では凍結できない。**先行 2 追補は `core_ref.commit` を
     「承認決定を canonical 台帳へ fold した commit」と逐語で定義し、凍結 core の resolver 契約も
     それに限定する。承認より前の内容 commit を書けば、既存意味では永続的に解決失敗し、
     内容 commit 意味へ緩めれば未承認 bytes を受理する集合が開く。
     → **追補 P は草案のまま置き、承認 fold の後の別 land で凍結する。**
  3. **本 land 単独では成果物が 1 つも動かない。**引数の「凍結承認は返す」を優先した結果であり、
     C-4 (a) の「同一 land で承認し段階 2 へ進める」とは両立しない。この齟齬自体を返した。
  4. **`p03` は「pilot 前に凍結」と「実装は producer wave」を同時に満たせない。**
