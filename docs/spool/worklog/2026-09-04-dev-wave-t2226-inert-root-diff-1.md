## 本文

- D1523 の条件 (正例と負例の両方を登録してから入れる) を満たして着地した。正例 2 件
  (`BACKOFF_FIXED=-1` / `BACKOFF_NOINLINE=0`)、負例 4 件。設計の確定形は
  {{D:inert-root-location-classification}}。
- **段 3 の 2 本と段 6 の 2 本が、独立に同じ 1 点へ収束した。** 「置換したものが本当に `__FILE__` の
  展開だったかを証明していない」。親は real と裁定したが、**影響の主張は成立しない**と判断して
  fix を採らなかった。両レビューの反例はいずれも requested 側が `<自分の root>/X`、control 側が
  `<相手の root>/X` で X が同一という形であり、これは置き場所を揃えれば消える差である。
  本物の意味差にするには素の木 (stock 側) にも対応するリテラルが要り、patch を書ける側からは作れない。
- **レビューの対案 (`-fmacro-prefix-map` で compiler に正規化させる) を却下した理由は費用ではない。**
  生成の時点で畳む形であり、D1523 が却下した「比較の前に情報を捨てる」形そのものだからである。
  精度としては明確に上なので、裁定パッケージ候補として残した。
- 親が repo 外で実測した 2 点が裁定を決めた。(1) `g++-12 -E -P` の `__FILE__` は相対 include 経由で
  `<root>/cc/silo/../../include/backoff.hh` と正規化されずに出る。(2) `__FILE__` は「その語を含む file」
  ではなく「その語が展開された file」の path になる。この 2 点により、レビューが提案した
  「root 依存 builtin の一覧へ束縛する」形と「`..` を禁止する」形はどちらも実物では成立しない。
- 段 2 の計画は差分アルゴリズムを使う形だった。段 3 の検査が実 CCBench 規模で最悪二乗になると指摘し、
  行数一致を先に要求して 1 対 1 で突き合わせる線形の形へ裁定で置き換えた。判定は弱まっていない。
- brief の前提を 2 件訂正した。(1) 前処理出力に行番号の目印が残るという前提は誤りで、実装は `-E -P` を
  使う。(2) A-2 の inert arm は 1 本でなく **6 本** (2 workload x stock 2 arm + adopted 1 arm)。
  正例を 2 macro で回す形にしたのはこの訂正による。
- brief の「理由コードを exact 一致で読む consumer は 3 件」は不正確で、実際は 7 箇所 4 file だった。
  ただし挙動が変わる既存テストは 0 件である (いずれも `__FILE__` を持たない fixture のため旧理由のまま)。
- **build root を置換対象から外した** (brief の当初方針を反転)。発火条件を満たす実在の成果物を
  名指しできないため。副次効果として「対応が競合したときの順序」という未検査分岐が消えた。
- 変異は実装前に 6 件登録し、段 6 で 1 件足して 7 件にした。**probe を全件 SURVIVED 期待で先に回し、
  観測した落ち先をそのまま本走の期待に固定した** (予測を書いて後から辻褄を合わせていない)。
  7 件中 4 件はその条件のためだけに作った負例 1 件だけに落ちており、対照として機能している。
- 変異 1 件 (`__FILE__` 保有の要求) は判定器と記録検査の**二層に同じ条件**があったため、
  両層同時変異として登録し直した。片層だけでは冗長 gate が代わりに赤を出し、単一理由が立たない。
- **計算資源:** dispatch が `queue-wait-timeout` で 2 度落ちた。D612 の上書き (5400 秒) で通った。
  1 度目の取り消しで **orphan hold が 2 か所に作られ**、下位だけ消して上位を残したため、
  次の投入が `orphan-hold` で起動そのものを拒否された。2 ファイルとも消す必要がある。
- **手順の抜け:** 再投入の前に前回の完了マーカーを消し忘れたまま投げた。job が既に受理されていたため
  止めず、マーカーだけ先に消して待ち手を張り直した。DW-O01 の「既存 `.done` を消去・再利用せず
  再投入を止める」に対する違反であり、段 8 の改善候補として扱った。
