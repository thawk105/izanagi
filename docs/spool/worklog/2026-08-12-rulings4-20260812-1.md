- **ユーザー裁定 (authority: user、2026-08-12 rulings 第 4 束)。** 発話:
  「まず、凍結チェーン？凍結記録？ってこの実装でこの性能測定しましたよって厳格なチェック機構？
  はしばらく不要です。そのせいで開発が遅延したり、テストの時間が必要になったりする。そのくせ
  研究開発がゴールに対して全然進まない。roadmap 忘れるなよ。ファイル数比例とかコード数比例する
  テストはおかしい。メジャー OSS でそういうテストはありますか？あるいはそういうことをしないと
  やりたいことが実現できませんか？他は推奨通りで」。一次控えは
  `rulings-inbox/2026-08-12-rulings4-freeze-hold-and-batch.md`。
- **凍結チェーン検証 (実装と測定を bytes/pin の完全一致で束縛する機械検証) はしばらく保留**
  ({{D:freeze-verification-hold}})。棚卸しと保留の執行は {{T:freeze-chain-hold}}。凍結記録の
  bytes 自体は書き換えず残す。**この裁定により、凍結チェーン再発行の択一 (一次控え
  `rulings-inbox/2026-08-12-t816-step4-freeze-chain-blocks-pin-advance.md` の (a)〜(d)) は
  いずれも採らずに supersede される** — 検証を保留すれば凍結証拠を書き換える必要も、
  再測定する必要も無い。
- **ファイル数比例・コード数比例のテストは不可** — 第 3 束で方針化した成長比例テストの恒久保留
  (branch `worktree-rulings3-20260812` の decisions fragment が正本) の適用範囲の明確化であり、
  新しい決定は立てない。稼働中の growth-tests wave の mandate を裏書きする。
- **「他は推奨通りで」が確定させた 9 件:** [T-184] 本体 (測定先行) と §17 ((c) 文書地図へ)、
  [T-905] (bytes pin を入れる — 防壁の自己完全性は測定束縛でなく信頼境界であり、凍結チェーン
  保留の対象外)、[T-906] (scope 外宣言 + 再訪条件)、[T-899] (見送り)、[T-903] (3 案とも見送り)、
  [T-904] (バグとして是正、敵対検証つき)、未採番 3 件 (揺れる木 = DW-M03 へ 1 文 /
  solo 高速化率の外挿禁止 = decisions へ追補 / 計測解析 script の親起草可否 = 既裁定の
  「repo 外の運転 script・probe は親可」の適用で終端、新裁定不要)。
- **[T-902] は前提が変わった。** 凍結検証の保留により freeze 再発行の閂が消え、ファイル数比例の
  live scan は保留対象そのものになった。除去の形は {{T:freeze-chain-hold}} と調整して 1 回で行う。
- roadmap のゴール前進を優先せよとの明示指示を受け、provenance 系機構の新設・維持は
  今後も既定で見送り側 (2026-08-12 粗い provenance 基準の強化継続)。
