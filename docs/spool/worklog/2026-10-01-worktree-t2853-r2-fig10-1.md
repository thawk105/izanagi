## 本文

- 依頼: next-tasks 2026-10-01 md_5 (D2305 項 9 で承認済みの fig10 の R2)。記録は `output/insights/2026-10-01/t2853-r2-fig10/README.md`。
- 計算の超過と承認: 投入後 20 分で経過が原 attempt の Elapse を大きく超えたので、land 調整役へ超過見込みを示した。調整役の依頼で診断し (stock bench は完了済みで計測は進んでいた)、見込み約 6.7 node 時間で継続の承認を得た。実消費は 6.39 node 時間。
- 超過の原因 (推定、PID では未確認): certification の job body が `IZANAGI_BENCH_LOCK` を設定せず、bench lock が全 node 共有の `~/.izanagi/bench.lock` になっていた。全規模の性能検証も bench_lock の中で回るため、R2 自身の 3 job の性能検証と bench が 1 列に並んだ。修正は範囲外として実装せず、land 調整役が直す dev-wave の投げ文を用意した。
- 段 6 のレビューで、親が調整役へ送った「node ローカル化で約 2.2 node 時間」の試算の算式の誤りが見つかった。約 3.3 (試算) に訂正して調整役へ送り、投げ文の値も差し替えられた。
- 実行時の作法: 隔離 worktree の guard は、worktree 外での版管理操作と、防護 path を含む heredoc を拒否する。投入・検査・描画は Write で作った sh 経由で行った。login から計算ノードへの ssh は鍵で拒否された。
- 子: Codex 5 本 (実装子・read-only レビュー 2・fix 子・焦点再レビュー)、Claude の read-only 調査子 1 本。
