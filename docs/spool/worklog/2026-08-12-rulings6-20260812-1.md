## 本文

- **ユーザー裁定 (authority: user、2026-08-12 rulings 第 5 束)。** 発話:
  「perf, 動かせる時は使うし、動かせない時は使わない。保留したテストを素の pytest 直叩きが
  実行できるのは許さない。それは izanagi として保留ではなく、あなたが回避してるだけ。
  そのようなごまかしは認めない。他は推奨通りで」。一次控えは
  `rulings-inbox/2026-08-12-rulings5-batch.md`。
- **perf は測定の前提にしない** ({{D:perf-optional-measurement}})。動く環境では使い、動かない
  環境では perf なしで測定を進める。perf の有無は環境タグへ記録し、比較は同条件内で行う
  (測定の公正は不変)。これにより [T-920] (linux-tools の管理者依頼) は**測定の閂ではなくなり**、
  [T-748] W-2 の「環境手番待ち停止」は解除される。
- **保留テストの runner 迂回は認めない** ({{D:hold-no-bypass}})。rulings が第 6 回で出した
  「plain runner 直叩きは opt-in と同義として容認」の推奨は**ユーザーが棄却した**。保留は
  素の pytest を含む全実行経路で効いて初めて保留であり、解除は明示 opt-in 機構のみ。
- **「他は推奨通りで」が確定させた 9 件:** [T-840] Q1〜Q5 (Q1 = red / kickoff は実行可能だが
  認証されない lane として残す、Q2 = 単独で決めず [T-841] のパッケージで同時裁定、Q3 = 対象外
  維持、Q4 = 既存 cache の再発行はしない、Q5 = host-security 系の別裁定へ回送)、
  [T-921] (preflight を置く — 止めるためでなく、perf 有無を検出・記録して使う/使わないを
  分岐するため)、[T-925] (L1.5 棚卸し wave を認可 = {{T:l15-budget-inventory}})、
  [T-923] (今は決めず、投入経路の正例が通ってから実測付き再提示、全面 deny 維持)、
  [T-935] = (a) gitlink 前進は Git 操作の機械的代行と明文化し checker の実装面判定から除外、
  [T-934] = (a) 流用可の条件 (変更面の骨格同一の確認 + 再検査をレビューへ寄せる) を入口へ明記、
  [T-916] = (c) `DW-S01` 側へ置く (読み込み導線が合わなければ (a) を棚卸し wave 経由で再提示)、
  [T-316] R2-b-1 = (a) 干渉残余の明示記録を**先行確定** (返着パッケージに未見の新事実があれば
  wave は再提示してよい)。
- [T-934] と [T-916] の入口追記は docs 予算に触れるため、実施順は {{T:l15-budget-inventory}}
  との調整に従う (予算が塞いでいれば棚卸しが先)。
- **同 turn 中の追加是正 (authority: user):** (1) /rulings の「全件」は**ユーザー裁定待ちのみ** —
  AI 側の作業待ち・予告・未来予測は索引に載せない (rulings が第 7 回で B 群として出したのは
  誤り)。「返着」等の造語も不可 (平易な日本語)。`.claude/commands/rulings.md` の出力節を本 wave で
  この定義へ是正した — 直前の branch worktree-rulings5-20260812 (3fe1654b、未 land) は
  「AI 側の返着待ちも含める」と逆向きに書いており**不採用・本 wave が置き換える** (land しない。
  branch 削除はユーザー指示待ち)。(2) T-499 の凍結・承認手番 (oracle 仕様の承認 SHA 記入と
  freeze v2 の pointer 設置) は **AI へ委任された**。(3) perf の導入依頼は「今はやらない」と明言。
  (4) push はユーザーが実施中。
