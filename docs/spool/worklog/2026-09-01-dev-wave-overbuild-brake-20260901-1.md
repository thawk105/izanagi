  「土台側」という外形だけを述語にすると受理集合・事前登録の効力・oracle・正しさ gate に触れる項を
  巻き込むため D1261 に抵触する、と具体的 ID 付きで指摘された。親は採り、不採用に倒した。

  成立しない分類を常設観測にすると、正しさ側の作業が「土台のみ」と数えられる圧力を生む。
