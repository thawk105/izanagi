## {{D:env-coincidence-classification}}. 環境の偶然を assert する検査は 8 クラスへ分け、決定的な床の判定を hang guard より先に置く

**決定:** 守りたい性質でなく実行環境の偶然を assert している検査を、次の 8 クラスへ分ける。
判定は call の種別ではなく「その数値・順序・識別子を変えたときに期待結果が変わるか」で行う。

- H = hang guard、T = 時間が主題、C = 因果の代理観測、O = 順序、I = 識別子、
  A = 周囲状態、**F = 決定的な床**、D = 確定的。

**F の判定を H より先に置く。** 待つ対象が production 側の実 sleep / poll 間隔で下から
押さえられている site では、上限そのものが問題ではない。判定は次の 2 点で行う。

1. その site が呼ぶ production 側の関数に sleep / clock / poll 間隔の注入 seam があるか。
2. あるなら、この site はそれを渡しているか。渡していなければ F である。

同じ file 内で多数派と違う呼び方をしている site を grep で出すのは、**候補の並べ替えであって
判定ではない。** file 内の全 site が seam を素通ししていれば多数派が存在せず 0 件を返すので、
0 件を F 不在の根拠にしてはならない。

**F の処置は 3 段に分ける。**

- 呼び手 (テスト) に既存の seam を渡させて床を消す。これはテスト側だけの変更である。
  seam が無い場合だけ production の変更を検討する。後者は production 挙動を変える判断であり、
  裁定の重さが違う。
- watchdog の上限は残し、用途を「hang 回収であって合否の latency 予算ではない」と明記する。
  処置は上限を消すことではなく、**上限を判定から降ろす**ことである。
- 降格が回帰しないことを守る control を足す。注入した sleeper の呼出しと偽 clock の進みを
  観測する。**この control で実時間を測ってはならない。**

**理由:**
- 5 クラス案では実例が収まらなかった。「N 秒待って終わらないこと」で排他を代理観測する型と、
  テストが所有しない process 全体の状態を一致させる型が、既存のどのクラスにも入らない。
- 床がある site に「実負荷の artifact が無いから上限を変えない」と裁定しても何も直らない。
  実測は `-n 32` / `-n 48` で 10.015 / 10.014 / 10.015 秒、ばらつき 1 ミリ秒だった。
  余裕は 15 ミリ秒で、負荷は引き金にすぎない。
- 降格を守る control が無いと、seam の受け渡しを外して床が戻っても watchdog の内側なので
  性質の assertion が全部通る。**修理が黙って蒸発する。**

**却下した選択肢:**
- 5 クラスのまま境界事例を H へ寄せる — H は「実負荷の artifact があれば上限を広げてよい」
  クラスなので、寄せることは族全体に予算拡大の道を開くことと同じになる。
- 多数派 grep を判定器にする — 慣行が無い file で 0 件を返し、不在の証明にならない。
- F の処置として上限を消す — 真の hang を捕まえる手段が無くなる。

## {{D:env-coincidence-no-budget-change-without-load-artifact}}. 実負荷 artifact の無い待ち上限は、族の是正 wave でも 1 つも変えない

**決定:** 環境の偶然を assert する検査の族を是正する wave であっても、
実負荷で取った artifact を持たない待ち上限の値は 1 つも変えない。
是正するのは、値を変えずに環境依存を除去できるクラス (識別子・周囲状態・因果の代理観測) に限る。

**理由:**
- D249 の予算拡大禁止は hang guard にもかかる。上限の拡大は受理集合を実際に広げる。
  独立レンズが具体的な検出力低下を構成した — 20 秒の join を 60 秒へ広げると worker が
  30 秒かかる性能回帰が通り、1 秒の wait を 10 秒へ広げると sampler の観測が 5 秒後になる
  回帰が通り、60 秒の subprocess watchdog を 120 秒へ広げると probe が 90 秒停止してから
  同じ出力を返す回帰が通る。
- 既往の拡大例を適合例として引用できない。静穏な単独走の所要を定数倍した値は、
  D249 が名指しで却下した母集団外の外挿である。
- 値を変えない書き換え (識別子の関係を操作で強制する、周囲状態を所有する子 process 内で測る、
  実時間の負の待ちを因果 event へ置換する) は受理集合を広げないので、この禁止の外にある。

**却下した選択肢:**
- 族の是正 wave だから一律に緩めてよいとする — 是正の目的が「環境依存の除去」であって
  「緑にすること」ではない以上、緩和は目的そのものを裏切る。
- 実負荷 artifact を取るために飽和全走を反復する — site ごとの発火率を推定するには
  約 287 走を要し、それでも順位差の比較には足りない。絶対規律 4 に反する。
