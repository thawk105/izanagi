## {{D:d1984-rejection-reason-superseded-by-d1872}}. D1984 の却下欄「二読 fallback の択一は未裁定」は書かれた時点で既に事実に反していたので追記で訂正し、決定の効力は維持する

**決定 (ユーザー裁定、2026-09-17 /rulings 全件 第 20 回 = D2104 項 18 (a)、「推奨通りで」):** D1984
(2026-09-14) の却下欄 3 項目目「未配線 2 群のどちらかを期待値として固定する — 二読 fallback の択一は
未裁定であり、片方を機械的な期待値にすると変更コストの非対称が生まれる」のうち、「二読 fallback の択一は
未裁定」は書かれた時点で既に偽だった。当該の択一は 5 日前の D1872 (2026-09-09) が「`_gate_check_core` の
v2 fallback を廃し、exact な `LaunchValidatedFreeze` を必須にする」(択 (ii)) と裁定済みであり、実装は
2026-09-17 の worklog entry (1594) (`docs/archive/worklog-phase3-0917-1594.md`、設計判断は D2102) で main へ
着地した。**D1984 へ本項の追記でこの理由文を訂正し、D1984 の決定そのもの (caller 閉包メタテストを新設
しない、D1241 / D1313 の上限を解除しない、母集合の件数を AST 走査由来として記録する) は維持する。**
却下欄当該項の結論 (未配線 2 群のどちらかを機械的な期待値として固定しない) は主決定 (メタテストを新設
しない) に含意されるため、理由文が失効しても変わらない。D1984 の本文は書き換えない (絶対規律 7)。

**理由:**

- D1872 は D1984 に先行しており、D1984 の当該理由文は先行裁定を見落とした不整合である。D2102 (2026-09-17)
  も同じ不整合を認識したうえで D1872 を裁定済みとして扱い、D1984 が決めたメタテスト不採用は動かさなかった。
  本項はその扱いを台帳に固定する。
- 過去の判定は追記でのみ訂正する (絶対規律 7)。決定を書き換えて遡らせない。
- 訂正を記録だけに留める案は、次に D1984 だけを読む者が誤った逐語 (「未裁定」) を適用する余地を残す
  (D2104 項 18 の理由)。
- 先例: D2044 項 28 が同型 (D1772 の誤引用) を追記訂正で処理した。理由文の訂正と決定の効力維持を分ける型は
  D1694。

**却下した選択肢:**

- 記録だけ残し D の追記をしない (D2104 項 18 (b)) — 誤った逐語を適用する余地が残る。
- 二読 fallback の択一を再審議する — D1872 で決着し実装も着地済み。本項は既存裁定の訂正記録に限る。
- D1984 の本文を書き換える — 絶対規律 7 に反する。
- D1984 の決定文にある「未配線 2 群 (C06 予算群と二読 fallback) の扱いも変えない」も同時に訂正する —
  同文は D1984 自身が 2 群の扱いを変えないという宣言であり、2026-09-14 時点で偽ではない (裁定済みだが未実装)。
  訂正対象は D2104 項 18 (a) が名指した却下欄の逐語に限る。
