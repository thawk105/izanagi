## {{D:existing-j1-cannot-reach-high-band}}. 既存 J1 経路は高域の条件比較を実行できない

**決定:** T-2188 が記録した trace の上では、既存 J1 経路 (`_edge_observations` /
`_edge_counts` / `_fixed_edge_comparison` / `_j1_sign_instability`) を高域
(`Backoff_` > 50 µs) の条件比較に使えない。事前登録の閾値を下げても、辺の定義を保つ限り
どの対照からも共通台を作れない。**新しい走行か、辺の同一性の定義の改訂が要る。**

射程は **write-heavy / 48 スレッド / records 1,000,000 / extime 3 秒 / 1 rep / Pegasus**、
`headline_eligible = false` / `throughput_scope = diagnostic_only` に限る。
値は headline・formal B-10・floor・fitness・variant 採用に使えない。

**理由:**

- 事前登録の対照 (`nm-step1` × `nm-step1-u2560`) の広窓側は、全 1,170 event の
  `backoff_before` と `backoff_after` がどちらも**最大 12.0 µs** で、高域へ 1 度も入らない。
  主帯域の辺対は 0 で、実行可能性は `no_high_band_observation` である。
  **帰属先は記録された trace であって、共通辺の設計でも閾値 10 でもない。**
- J2 の時間加重 `P(Backoff_ > 50) = 0.0000` は丸め表示であり event 数 0 を意味しない。
  **生の最大値 12.0 が不到達を直接示す。** 丸め値に依らない確認をした。
- 刻み軸 5 セルの**全 10 組**について、両側に非ゼロ符号の観測を持つ高域共通辺は
  主帯域・感度帯域とも 0 本である。既存 J1 の比較は順序なし辺の完全一致を要求し、
  辺の幅は刻みが決めるためである。
- **ただし「辺を 1 本も共有しない」ではない。** `nm-step25` と `nm-step100` は上端の自己辺
  `(1000.0, 1000.0)` を共有する。その符号が両セルとも全てゼロなので、推定に使える共通辺として
  数えられないだけである。設計上の不可能性ではなく、**当該 trace での不成立**である。
- 無改変の `_j1_sign_instability` を呼んで 2026-09-10 の記録 (共通辺 12・重み 1,168・
  0.4984 / 0.4583・差 +0.0402・`direction_unstable`) を**完全に再現**した上でこれを測った。

**射程に含めないもの:**

- 高域の符号の記述統計は計算できる。本決定は「条件間の比較ができない」であって
  「高域の符号を測れない」ではない ({{D:high-band-sign-is-near-maximal-mixing}})。
- D1932 の滞在分布説を補強も否定もしない。**この決定は D1932 を動かさない。**
- 旧 J1 の判定 `not_supported` を遡って昇格・撤回しない (絶対規律 7)。

**却下した選択肢:**

- **`types.FunctionType` で `_j1_sign_instability.__code__` を借り、グローバルの
  `_edge_observations` だけを高域版へ差し替えて実行する** — 同じ `__code__` でも参照先が変われば
  実行される計算は別物であり、その結果を「既存経路の能力」へ帰属させられない。
  無改変の呼び出しに替えた。
- **刻み軸の対照で更新間隔軸の結論を代用する** — 刻み軸 5 セルは更新間隔 10 µs 固定であり、
  別の因子である。共通辺数だけを出し、比較値は出さなかった。

## {{D:high-band-sign-is-near-maximal-mixing}}. 高域の勾配符号はほぼ完全な五分五分である

**決定:** 高域へ入る 4 セルすべてで、辺別の符号混合度 `d = 2p(1-p)` は上限 0.5 の近傍にある。
これは**保持された隣接 event 対の、非ゼロ符号に条件づけた辺別混合度**の記述であり、
計数ノイズの寄与の同定でも、低域より不安定であることの証拠でもない。

射程と利用資格は {{D:existing-j1-cannot-reach-high-band}} と同じである。

**理由:**

- 辺重み平均 `d` は `nm-step1` 0.4944 / `nm-step2` 0.4970 / `nm-step25` 0.4991 /
  `nm-step100` 0.4971。少数標本の下方偏り `E[d] = 2q(1-q)(1-1/n)` を n > 1 の辺すべてへ
  補正すると 0.4979 / 0.4993 / 0.4997 / 0.4972 となり、**補正は 0.5 へ近づける向きにしか動かない。**
- 同じ補正を旧 J1 の 12 共通辺へ掛けても、差は 0.0402 → **0.0380** (n=1 の辺 1 本は補正不能なので
  未補正で残した場合) または **0.0376** (その辺を両側から除いた場合) にしか動かない。
  **支持条件 0.10 には遠く、旧判定は少数標本の偏りでは説明できない。**
- 保持された隣接対の範囲では、`Backoff_` が下端 0 と上端 1000 で動かなくなった直後の
  `gradient_sign` は**例外なく 0** である (対象 9,220 対、正 0・負 0・ゼロ 9,220)。

**主張しないこと:**

- 「計数ノイズが高域で符号を支配する / しない」。同じ辺でも歩行履歴と窓の状態で throughput 差は
  変わるため、計数ノイズが無くても符号は混ざる。
- 低域より不安定であること。条件間の対照が成立せず、同一セル内の低域との対比は帯域・歩行履歴・
  窓の状態が同時に違う。
- 全走行の性質。`nm-step0.5` は走行の 69.90% を取りこぼしており、保持分は末尾 slice である。
- 符号の**時間的な**反転率。`2p(1-p)` は辺内の正負の比率だけで決まり、順序を見ない。
- 上端 1000 µs での符号 0 が、物理的な飽和の証拠であること。表現上端である可能性と分離できない。

**却下した選択肢:**

- **感度帯域 (`max(edge) > 50`) の値で主定義の結論を救済する** — `nm-step100` だけが
  −0.0136 と実質的に下がるが、これは 0 から跳ね上がる境界横断辺 7,365 件によるものである。
  感度は感度として併記し、主定義の結論を動かさない。
