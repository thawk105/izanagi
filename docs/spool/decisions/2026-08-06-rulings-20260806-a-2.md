## {{D:branch-deletion-user-instruction}}. branch 削除はユーザー指示があるときのみ AI が実行してよい

**決定:** AI による branch 削除は、その削除を対象を特定して指示するユーザー発話 (裁定「削除で」を
含む) がある場合のみ実行してよい。指示なしの削除はしない。恒久的な自動許可 (permission rule の
常設) は追加しない。cleanup-branches の既存権限 (マージ済み branch の安全手順) は変更しない。

**理由:**
- 未 land commit を持つ branch の削除は権限分類器が拒否し、都度ユーザーの手作業になっていた。
  一回ごとの手作業と恒久自動許可の中間として、ユーザー提案の折衷 (2026-08-06 裁定) を採る。
- 「削除・push の権限境界は自己改善を理由に広げない」と整合する — 広げる根拠が
  ユーザー裁定そのものである。

**却下した選択肢:**
- permission rule の常設 — 「未 land 作業を消せる」権限の常設は事故面が広い。
- 全削除をユーザーの手作業のまま — 掃除のたびに摩擦が残り、裁定済みの掃除が滞留する。
