## {{D:t2850-trial-prereg}}. 探索の独立反復の試走は Silo の backoff 値空間の write-heavy / read-heavy で各 cell 3 系列とし、評価数の族と経過時間の族を分け、本比較の系列数は手法対の対差 SD の計画値から 2 段の計画半幅で決める

**決定 (事前登録の作成のみ、計算投入・実装はしない):** VLDB 差分分析 P3 の試走と本比較の規模の規則を `docs/search-repetition-trial-preregistration.md` (v1) に固定する。
起草の経緯は `output/insights/2026-09-23/t2850-trial-prereg/README.md`。要点は次のとおり。

1. **試走の規模。** Silo の S1 (backoff 値 1..1000 µs) × write-heavy / read-heavy × 5 手法 (D2220 の random・sweep・BO・進化・K0 LLM、情報構成は R0 だけ) × 各 cell 3 系列 = 30 系列、
   探索の評価 300 件、論理 600 session。一次資料の案 (2 protocol × 2 課題) から縮めた。MOCC (S2) は /rulings 第 32 回項 1 で pin 候補が承認され更新 wave を起こす段階で、
   差し込みと動作点の較正の前、S3 は段階 D の前だからである。空間は、その空間の最初の生成より前の追補で足し、その空間の予算・分散はその空間の試走から決める。
2. **予算。** B = 10、A = 30、初期点 k = 2 (静的 5 → 10 µs)、N_eval = 5 を、S1 の試走と本比較で同じにする。本比較で変えるのは課題の集合と系列数だけ。
   試走で調整する手法の定数は無く、本書が値を書かない実装の定数 (BO の超パラメータの格子・jitter など) も発効束で固定する。
3. **2 族の分離。** 評価数を揃えた族 E_B (B = 10 時点の endpoint) と、経過時間を揃えた族 E_T (B ≤ 10・A ≤ 30 の探索を、非 LLM の手法が B を終える時刻の試走での中央値 T_c で切った時点)
   を分け、それぞれ family-wise 5% の同時区間にする。E_T は追加の評価をせず、試走では T_c を決めるだけで再計測しない。T_c の時点で走っている途中の候補は機械故障の未解決と扱わない。
4. **比較の族と分類。** 課題ごとに 5 手法の全 10 対。同じ block の系列の対差の平均と Bonferroni の t 同時区間、同等幅 δ = ln 1.03 (転移登録と同じ) で 4 分類。
   予定した対に score 欠測が 1 つでもあれば判定不能。試走は記述だけで分類しない。
5. **本比較の規模。** 計画の対差 SD = 試走の cell ごとの標本 SD から作る √(s_m² + s_m′²) の全課題・全対の最大値。計画半幅 h(n) ≤ δ/2 を満たす最小 n (下限 5) が上限内ならそれ、
   超えれば h(n) ≤ ln 1.05 の最小 n、それも超える・分散が算出できない・試走が未完なら n を縮めずユーザーへ返す。入力に手法間の差と曲線を使わず、課題の選択も費用・分散・実行可能性だけで行う。
6. **費用。** 試走の試算 128.7〜145.4 node 時間 (単価は B-5 試走の実測と B-5 発効束の試算)、試走の上限は job Elapse の総和 200 node 時間。本比較の上限は計算確認でユーザーが決め、
   提案値は一次資料の 510 node 時間。S1 の 3 workload の計画用 C(5) は 417.8〜485.7 node 時間である。
7. **B-5・転移登録との関係。** B-5 とは標本・判定規則・block stock を共有しない。学習条件は転移登録の錨の部分集合で、留保条件は生成・選択に使わず、docs への到達可能性を cell ごとに記録する。

**理由:**
- 依頼は試走の規模・2 つの比較の分離・記録項目・B・A・系列数・費用上限・比較の族・本比較の規模の規則を求め、gate・検査・台帳・一般化の追加を scope 外とした。D2220 と基盤設計 §5.6 はこれらの値を本書へ残した。
- pool した分散は、最も不安定な手法対の精度を支えない (腕ごとの SD が (0.10, 0.10, 0, 0, 0) なら pool は 0.063 で、最初の 2 腕の対差 SD 0.141 を下回る。段 3 相談 A の反例)。
  cell の自由度は 2 なので χ² の上側限界は係数約 3.1 になり規模を決める情報にならない。本比較の区間は本比較の標本から作るので、計画値の誤りは誤分類の率ではなく達成精度に効く。
- 試走の系列が終わるまで T_c は決まらず、先に終わった系列の job の中で E_T を再計測できない (段 3 相談 B の must-fix 1)。
- 段 3 の Codex 相談 2 本 (統計設計・公平性・情報の漏れ / 実行可能性・費用の算術・既存規則との整合と過剰) の 27 件、段 6 の read-only レビューの 7 件を、いずれも real と判定して反映した。

**却下した選択肢:**
- 一次資料どおりの 2 protocol の試走 — 起草時点で S1 以外は走らせられない。
- wh・bal の組 — 探索差を見る機会は多いが、本比較の費用の最大の不確かさである rh の検証費を実測できない。
- 試走で E_T を再計測する (別 job) — 手順と費用が増え、本比較の規模は E_B の分散で足りる。E_T の計画精度は約束しない。
- 非 LLM の手法に B を超えて評価させる時間の比較 — 費用が大きく、採るなら本比較の前に別に登録する。
- 5 手法を pool した分散の上側限界で規模を決める — 上記。
- LLM を含む 4 対だけの族 — 本研究の問いは空間の構造によってどの探索法が効くかで、非 LLM どうしの対も含む。
- 試走の手法間の差を見て本比較の課題を選ぶ — 課題の選択を通じて規模 (M・費用・n) に手法差が入る。
