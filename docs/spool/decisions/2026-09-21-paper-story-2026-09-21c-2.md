## {{D:fig3c-arc-status-generator-minimal-fix}}. 状態図の生成器は同日版の接尾辞 1 字だけを受理し、2026-09-19 版以外では項目の状態に依存しない固定キャプションを使う。状態 JSON は docs 配下に置く

**決定:** 論文ストーリーの状態図 (`tools/plotting/plot_arc_status.py`) を 2026-09-21c 版から作るため、生成器を次の 2 点だけ最小修正した
(実装は Codex author、統合 commit `76b60f6e1`)。

1. **受理集合の追加:** `load_states` は `story_version` に限り、`YYYY-MM-DD` の後ろに英小文字 1 字の接尾辞を受理する (`^\d{4}-\d{2}-\d{2}[a-z]?$`)。
   暦日検査は先頭 10 字 (日付部分) に掛け、`story_path == docs/paper-story/<story_version>.md` の照合は接尾辞込みのまま変えない。`figure_created` は
   接尾辞の無い日付だけを受理する (不変)。大文字・複数字・不正暦日・`figure_created` への接尾辞・path 不一致は拒否のまま。
2. **キャプション:** `_caption` は `story_version == "2026-09-19"` のときだけ既存の `CAPTION` (2026-09-19 版の項目の状態を述べる文を含む) を 1 文字も
   変えずに返し、それ以外の版では項目の状態に依存しない固定 caption `GENERIC_CAPTION` を返す。JSON の key・schema・脚注・描画・`DEFAULT_STATES` は変えない。

境界テストは同じ変更単位で足した (既定 caption の全文 literal、接尾辞版と固定 caption の正例、暦日・大文字・複数字・作成日・path 不一致の異常系)。
変異 M1〜M8 は KILLED 8/8 (期待 node 完全一致)、対照 M0 は SURVIVED。

**状態 JSON の置き場:** 2026-09-21c 版の状態 JSON は `docs/paper-story/figures/arc_status_story_2026-09-21c.json` に置く。`tools/` 配下の非 Markdown は
D95 の機械判定で実装面になり Codex author を要するが、状態 JSON は人が版の本文から写すデータであって実行物ではない (生成器は `--states` で任意の
repo 内 path を読む)。前回 (fig3b) の JSON `tools/plotting/arc_status_story_2026-09-19.json` の位置と bytes は変えない。

**理由:**
- 生成器は `story_version` を日付だけに限っていたので、同日 3 版目 `2026-09-21c.md` を参照できなかった (依頼の「21c 版を参照できない場合に限って最小修正」に当たる)。
  同日の版 file 名の先例 (`2026-09-20b.md` / `2026-09-21b.md`) はすべて英小文字 1 字で、複数字・大文字の実例は無い。
- 既存 `CAPTION` の「A-4 is adopted by ruling but inactive pending human action」は 2026-09-21b 版自身が「A-4 は発効済み」と書くので、後継の版の図では偽になる。
  項目固有の判定語・限定は各項目の副ラベルが担い、正本は本文 §8 である。
- 既定 JSON (fig3b の再現入力) に対する表示内容 (drawn_items と caption の全文) は不変なので、fig3b の再現対象 (状態と表示内容) を壊さない。
  fig3b の provenance の `generator.sha256` は当時の生成器の記録として残し、書き換えない (規律 7)。

**却下した選択肢:**
- JSON に任意 key `caption_notes` を足し、状態依存の文を JSON から差し込む — 段 3 の相談が、任意 key・自由文の検査経路・異常系を増やし最小ではないと指摘した。
- 既存 `CAPTION` を全版で使い、figures README に注記する — 新しい provenance に偽の caption が残る。
- 版 file 名を接尾辞なしにする — 同日の既存版と衝突し、依頼の「21c 版」と両立しない。
- 状態 JSON を `tools/plotting/` に置く — 実装面になり Codex author を要するが、この wave の後半は Codex が利用上限で使えなかった。

**研究状態への影響:** なし。生成器は判定・値・認証を再計算しない。certified 選択・レポート値・台帳・proof chain は変わらない。
