## {{D:b4-floor-aggregate-rule}}. B-4 床値の集約は、期待 spec 列を呼び出し側から受け、窓ちょうど 2 までを機械検査し、標本数と窓分離は人手の採用責任に残す

**決定:** D1936 項 7 が採った D1855 案 B の「下流に規則が無い」を、次の形で閉じる。

1. **事前登録への追補は §5.1 の floor 項目に置く。** §11 は自身を「未裁定の案であり規範ではない」と
   書いているので、新しい規範の権威にしない。追補は D1936 項 7 を根拠とし、D1641 決定 3 と D1695 の
   確定値を継承する。置く位置は §5.1.0 より前とする — §5.1.1 の生バイト hash の範囲は
   「その見出しから次の level 4 以下の見出しまで」であり、§5.1 の末尾に足すと凍結バイトが変わる。
2. **集約する spec の path と sha256 の列は、呼び出し側から明示的に受け取り、入力 summary から
   導出しない。** 導出すると、欠けた入力を期待集合からも消せる循環検査になる。期待列から導いた
   窓・層・セル・標本の閉包と、入力 summary が報告した閉包の exact 一致を要求し、
   欠落・重複・余剰・不一致は集約全体を拒否する。正常な入力だけに間引いて続行しない。
3. **機械検査は「各 spec が宣言する窓はちょうど 2」までとする。** これは D1641 決定 3 の
   「凍結したセル集合 × 2 時間窓の全部」の逐語である。**1 campaign・1 セルあたり n = 62 と
   24 時間以上の分離は機械検査しない。** 対照対 driver もこの 2 つを検査していない
   (窓の解析は非重複と標本数 1 以上だけを要求する)。§11.1 手順 8 が証拠確認者の責任として
   残しているものを、実装が肩代わりしたように見せない。
4. **集約は別 schema 版の別経路として足し、単一 summary の経路は 1 文字も変えない。** 既存の
   「v1 本文の schema だけを v2 と名乗らせると拒否される」テストは、集約版が必須欄の欠落で
   拒否すればそのまま通る。既存テストの期待値を変えない。
5. **CLI の新規オプションは既存の省略形と接頭辞を共有しない名前にする。** `--summaries` は
   `--summary` の既存省略形を曖昧にして受理集合を縮める。
6. **機械検査が証明しないことを追補に書く。** 期待列が結果を見る前に選ばれたこと、
   期待列が本書の対象集合と意味的に一致すること、標本数と窓分離が満たされていること。
   この 3 点を機械保証として表示しない。

**理由:**

- 案 B は現行コードのまま表現できるが、3 成果物の保守側最大を 1 件へ集約する規則が下流に無い、
  というのが D1855 の残した唯一の穴だった。集約器と規則だけでそこは閉じる。
- 期待列を入力から導くと閉包検査が恒真になる。導出できる経路が 1 つでも残れば循環する。
- 窓数の要求を機械検査に入れたのは、それが「2 時間窓の全部」の逐語だからである。標本数と窓分離を
  足さなかったのは、追補が扱うのは集約であって spec の妥当性ではなく、既裁定が人手へ割り当てた
  責任を実装へ移すことになるためである。
- 変異検査は、窓数の要求に対応する負例が 1 つも無いことを実測で出した。規範として書いた条件には
  到達する負例を置く。

**却下した選択肢:**

- **期待 spec 列を入力 summary から導出する** — 欠けた入力を期待集合からも消せる循環になる。
- **n = 62 と 24 時間分離を集約器で検査する** — 既裁定が人手へ割り当てた責任を実装が肩代わりする。
  対照対 driver も検査しておらず、集約器だけが検査する非対称も生む。
- **集約でも v1 を使い、任意の複数入力欄を足す** — 既存 v1 成果物と単一 source の fixture を壊し、
  exact な欄集合の契約を曖昧にする。
- **既存の「v2 は拒否される」テストを未対応版 (`v999`) へ書き換える** — 既存テストは拒否の理由を
  固定していないので、書き換えは不要である。既存期待値を変えない方を採る。
- **最大値を与えた入力だけを出所として保存する** — 非最大入力の欠落・差替え・非保証削除を
  検査できなくなる。
- **spec をまたぐ出力先の非共有を要求する** — 追補に無い受理条件であり、契約より狭い。
- **平均・中央値・最小、上限 1 以上の切り詰め** — 保守側最大と値域の既裁定に反する。
