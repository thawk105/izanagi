## {{D:overbuild-brake-already-landed}}. 過剰実装抑制の規則は追加しない — 同一依頼は既に実施済みで、純増はゼロである

**決定:** 「論文を早く進めるため、過剰実装・過剰ガードレールへの傾斜を避ける施策を入れる」という
依頼に対し、**新しい規則・機械 gate・スコア・観測機構・台帳をいずれも追加しない。**
同一のユーザー指示は 2026-08-29 の wave (branch `worktree-dev-wave-avoid-overengineering`) で
既に next-tasks・dev-wave・rulings の 3 経路へ統合済みであり、そのとき意図的に
「checker・スコア・台帳・新しい G 節・文書予算を増やさない」形が選ばれている。本決定はその選択を
追認し、**同型の依頼が再度来たときに規則を重ねない**ことを定める。

現行の被覆は 4 層である。D205 (研究前進最優先・防御的堅牢化は既定で見送り)、D1261 (抑制軸は
防御的堅牢化にだけ適用し、規律 2 / 3 と実験計画の健全性には適用しない)、タスク選定側の
常設前提と「過剰追加を候補にしない」規則、dev-wave の右寸法化 gate 群である。

**理由:**

- 段 2 プラン子と段 3 の独立 2 レンズが、いずれも「規則本文の純増は不要」で一致した。
- 却下した観測案は、提案者自身が「docs のみ / code + docs という外形では研究前進を分類できない」と
  認めている。**成立しない分類を常設の観測にすると、正しさ側の作業が「土台のみ」と数えられる
  Goodhart 圧力が生まれる。**これは D1261 が禁じた拡大解釈の方向である。
- 未処理項の一括見送りも却下した。優先度ラベルや「土台側」という外形だけを述語にすると、
  受理集合・事前登録の効力・oracle・正しさ gate に触れる項を巻き込む。個別 ID の承認がある場合に
  既存の見送り遷移を使うことは妨げない。
- 「直近の wave に実装差分ゼロが続く」ことを過剰ガードレールの証拠として使わない。着手前実測で
  前提が覆り**正しく実装せずに止まった** wave が複数含まれており、これは起動時の前提検査が
  設計どおり働いた結果である。実装比率を過剰性の代理変数にしない。

**却下した選択肢:**

- 抑制規則をもう 1 本足す — 同一依頼への二重規定になり、入口の予算も満杯である。
- 直近 N wave の前進 / 土台比率を選定時に常設表示する — 分類が成立せず、Goodhart 圧力を生む。
- 未処理項をラベルで一括見送りする — D1261 の保護対象を巻き込む。

## {{D:cross-protocol-residue-is-implementation}}. 段 7 cross-protocol に残るのは裁定ではなく実装である

**決定:** cross-protocol 選定の成立方法は **2026-08-11 のユーザー裁定で決着している** (S1 設計択一
Q1〜Q3 全問 (a) = trace v2 化を単独 wave で先行、初手は mocc、stock 専用計測経路は偵察としても
解禁しない)。したがって以後、この論点を「未裁定の設計択一」として再提示しない。残っているのは
実装であり、その残余を phase doc の該当箇所と本決定で名指しする。

**stock 専用計測経路は certified な cross-protocol 比較を成立させない。** 得られるのは正しさ未検証の
性能観測であり、公式 report・selector・比較表・順位・headline のいずれにも入れない。これは速度を
理由に緩めてよい種類の制約ではなく、規律 2 そのものである。

**理由:**

- 現役の phase doc が、成立方法を「trace-hook 移植」と「stock 専用計測経路」の**並列の選択肢**として
  提示したままだった。裁定済みの論点が未裁定に見え、かつ「速い代替」として無効な経路を選べる
  文面になっていた。段 3 の 2 レンズが独立にこれを最重要所見として挙げた。
- 実装残余は実測で確認した。genome 空間の登録は silo 1 件だけであり、between-run floor の baseline も
  silo 固定、層 3 の floor 照合キーに protocol の軸が無い。
- 依頼者の目的は「早く実現する」ことであり、その状況でこそ無効な近道を選べる文面を残す害が大きい。

**却下した選択肢:**

- 文面を据え置き、着手時に読み手が気づくことに任せる — 同じ調査を次の担当が繰り返す。
- stock 専用経路を「速い暫定」として条件付きで復活させる — 規律 2 違反であり、既裁定の逆転にあたる。
