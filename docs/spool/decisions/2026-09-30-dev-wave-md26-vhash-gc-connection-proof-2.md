## {{D:vhash-gc-connection-proof}}. VHash の構成 E (前進を GC の回収境界へつなぐ) の一般論証は、floor だけで既読版を守る抽象仕様についての「論理的な GC 安全」と直列化の定理とし、開始時の floor の 3 条件・公開の規則・floor を上げる前進の確認を始めた後は読まない条件 (RA) を前提に置く。物理的な非接触と Cicada 実装の安全は主張しない

**決定:**

1. 一次資料 `output/insights/2026-09-30/vhash-gc-connection-proof/README.md` の定理は、md_10 の SP 形 (D2290) に途中入場と古い境界での回収を足した抽象仕様 E についての主張とする。前進先 t′ は一意で現在の候補時刻より大きいことだけを使い、E-max (D2315) にも E-now にも及ぶ。
2. 主経路は Cicada 型の「floor だけで既読版を守る」経路 F とし、不変条件 (I0) 境界 ≤ floor、(I1) floor ≤ 候補時刻、(I2) 既読版の他 tx の確定後続版は floor より上、の保存で示す。md_10 のモデルの refs で守る経路 R は別の十分条件として並べる。
3. Cicada で既読版を守る暗黙の不変条件 (「tx 開始時の下限を tx の間変えない」、D2295) を、開始 floor の条件 FS-c (登録後に他 tx が設置する版の wts は開始 floor より大きい) と公開の規則 PUB (floor を上げるのは成功した確認・確定の後に確定時刻以下へだけ) に分けて明示する。仮裁定 P5 は PUB を崩して (I2) を破る反例として表に置く。開始 floor にはさらに FS-a (≤ 開始時刻) と FS-b (≥ それまでに読まれた境界、途中入場用) を置く。
4. 経路 F には条件 RA「floor を上げる前進について、その確認を始めた後は外部 read をしない」を置く。公開の後の読み (列 X1) も、確認の成功と公開の間の読み (列 X2) も、その確認に覆われず floor だけでは守れない。Cicada の構成 E (待機型の長い tx) は全 read の後に待機して確認し、待機の直後に commit するので RA を満たす (patch のコード読解)。
5. 定理は「必要な版として選ばれない」(論理的な保持) までを言い、走査中の pointer の寿命・再利用 (物理的な非接触) は未主張とする。md_13 (D2292) の仮定 A9 の役目は、回収された版を除いた列でも md_13 の補題 1・2 の結論が保たれるという補題 A が引き継ぐ。
6. Cicada 実装が FS-a/b/c・RA・W* を満たすかは後で確かめる項目とし、主張しない。とくに leader が ThreadWtsArray と ThreadRtsArray を別々に読むため、FS-b の導出が崩れる列をコード上で構成できる (害の完成列は無い)。W* の非原子的な走査では、走査が通り過ぎた位置へ後から確定した版を根拠に、止まる予定の版が回収されうる。

**理由:**
- 段 2 の起草・親・段 3 の相談 A が独立に列 X1 を得て、段 6 レビュー A が列 X2 を作った。どちらも md_10 のモデルでは refs が守るので探索に現れず、Cicada には refs が無い。条件を置かずに floor だけの定理を書くと偽になる。
- md_14 の P5 と md_21 の壊し (既読不一致を無視した前進) は、判定器の巡回 0 のまま保持版の変化だけが出た (D2300 の盲点)。この型の失敗を (I2) の破れとして名指しすると、PUB と RA がそれを除くことを論文で説明できる。
- 定理の主語を抽象仕様に固定すると、Cicada の未確認事項 (時刻の単調性・非原子的な集計・W*・記憶順序) を定理から切り離して列挙できる (段 3 相談 B)。

**却下した選択肢:**
- floor だけで守る定理を RA なしで書く — 列 X1・X2 で偽。
- RA を「公開の後に読まない」とする — 段 6 レビュー A の列 X2 (確認の成功と公開の間の読み) を除かない。
- md_10 のモデルの floor = 開始時刻を Cicada の floor と同一視する — モデルは FS-c を満たさず refs に依存する。
- 物理的な非接触まで定理に含める — モデルは回収を印で表し、Cicada の走査中の pointer の寿命は論理から出ない。前提 E8 として置くだけでは恒真な主張になる。
- 途中入場を範囲外にする — 依頼の GC 安全は「その時点以降に始まる tx」を含む。
