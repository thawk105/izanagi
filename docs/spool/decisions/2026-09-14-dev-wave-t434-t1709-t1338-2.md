## {{D:retire-floor-derived-admission-gates}}. 8b oracle の受入経路から床値由来の 3 述語を撤去する

**決定:** D501 決定 8 が名指した 3 述語を production から外す。撤去の授権は「D496 の下で
不要になったこと」であり、「別述語が同じ入力を拒否すること」ではない。完全代替の存在を撤去の
条件にしない。

1. `s8b_oracle_manifest` の per-pair 床値対表 exact 検査と、その専用 helper。
2. 同 module の `floor_budget_snapshot_sha256` — key 集合・生成・照合の 3 箇所を一体で外す。
3. `s8b_oracle_driver` が過去床値 campaign の admission receipt から `expected_perf_sha256` を
   供給する経路と、そのための `perf_sha_by_cell`。

**残すものを同時に確定する。** admission receipt の検査一式、store 実体 sha256 と receipt の
照合、freeze byte hash の比較、schedule の holdout 集合と cell product、top-level key 集合の
exact 比較、floor/budget の null 拒否と外形・budget 値・共有性の検査。`pipeline` の generic な
`expected_perf_sha256` 引数も残す — D501 決定 8 は名指していない。

**受理集合は広がる。** floor の pairs 欠落・余分・stock 混入、pair の 0 / 負値、`scalar_alt` の
max 不一致、null 相関違反、床値が scalar 形の freeze は受理される。過去 campaign と別 binary での
oracle 測定も測定前 abort を受けない。射程は公式 candidate 入口にも及ぶ。逆に
`floor_budget_snapshot_sha256` を持つ旧形の文書は拒否されるようになる (受理形の変更)。
互換層は作らない。

**撤去対象の同定を訂正する。** D501 決定 8 の「driver の測定 binary bytes 照合」は
`floor_pair_driver` の build receipt 検査ではない。同 module は B-4 床値の測定側であり、
その検査は spec 指定 binary と receipt の対応を見るだけで、過去 campaign 由来であることを
要求していない (導入裁定は D1453)。決定 8 の性質に一致するのは oracle driver の供給経路である。

**理由:**

- D496 決定 1 が凍結した過去値を比較の基礎にしないと定めている。床値由来の受理条件を残すと、
  宣言と実装が食い違ったまま official 系列が動く。
- per-pair 対表の内部整合と floor/budget の部分 hash は、床値が比較の基礎でなくなった以上、
  受理条件として意味を持たない。`s8b_verdict` は schema v3 で条件 3・per-pair floor・scale gate を
  判定基盤から外しており、床値を判定へ運ぶ経路は既にない。
- 測定 binary の照合は「今回測る binary が過去 campaign の binary と同じか」を要求しており、
  D496 決定 1 と正面から衝突する。同一性は「変わったか」しか言えず「効いたか」を言えない。

**却下した選択肢:**

- **述語だけ外して key を残す** — 恒真な意味 field が残る。生成側も同時に外さないと生成物自身が
  exact key 検査に落ちる。
- **完全代替を撤去の条件にする** — D501 決定 8 の逐語は完全代替を主張していない。この条件を
  課すと撤去できる述語がゼロになり、裁定が実行不能になる。
- **store 実体 sha256 と receipt の照合も外す** — floor store の内部整合であって「今回測る
  binary が過去と同じか」ではない。決定 8 の射程外であり、外すと承認外の受理拡大になる。
- **`pipeline` の generic gate も外す** — 決定 8 は名指していない。供給元を失うことは記録するが、
  本 wave で直す欠陥ではない。
- **旧形の文書を受ける互換層を足す** — 受理形を二重にすると検査の抜け道が増える。
