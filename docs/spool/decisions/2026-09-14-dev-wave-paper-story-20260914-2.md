## {{D:a2-a6-release}}. A-2 / A-6 の新 attempt は D1645 の解除条件を満たし、但し書き 2 は限定 4 つ付きで外れる

**決定:** 論文ストーリーの版において、次のとおり扱う。

1. **D1645 が定めた「正しい identity で取り直した attempt が出るまで A-2 の結論を論文素材から
   外す」の解除条件は、attempt `t2364-20260907b` が満たす。** 同 attempt は D1644 の
   pin + patch 束縛 `src_token` で cell の identity を計算する driver で走り、4 cell すべてが
   `source_binding_status=bound`、stock は `src_token=stock`、adopted は非 `stock` である。
   **A-2 の結論を論文素材として使ってよい。**
2. **A-6 の attempt `a6-20260908b` も同じ基準で扱う。** 2 cell とも `bound` で correctness
   `certified` である。**性能の判定が `reject` であることは、正しさ証拠の欠落ではない。**
3. **「性能を測った workload そのものでの採用静的 backoff の certification が無い」という
   但し書きは、3 workload とも外れる。** ただし限定が 4 つ残り、版はこれを毎回添える —
   (i) L01 の point-key trace、(ii) D1257 の correctness argv の独立記録の不在
   (束縛は campaign lock と pipeline constructor による)、(iii) 成果物自身が宣言する
   「artifact hash 単独では compile-out の証明にならない」、(iv) 条件関門について保存されているのは
   admission record と `record_ids` までで supply / meaning record の本体は残らないこと。
4. **この certification は旧 `linux-baremetal` の 3 値へは遡らない。**
5. **旧 attempt `t2022-20260828c` の判定は取り消さない** (絶対規律 7)。支持する命題は
   「CCBench 内蔵の適応 backoff の有効/無効」である。**旧 fig5 の用途制限は D1936 項21 のとおり
   期限なしで残る。** 「旧判定を歴史記録として説明すること」と「旧図を採用静的 backoff の結論・
   図として使うこと」は別であり、禁じられているのは後者である。
6. **A-2 / A-6 / balanced stock-inline 対の 3 走行を 1 つの横断実験として集計しない。**
   protocol も事前登録も attempt も別であり、A-1 が定める横断実験の代わりにならない。
   **符号が旧環境と 3 workload とも一致したことは記述的な照合であって、再現判定ではない。**

**理由:**

- D1645 の逐語の解除条件は「正しい identity で取り直した attempt が出るまで」であって、
  追加のユーザー裁定を要求していない。新 attempt の権威 bytes がその条件の充足を示している。
- `docs/paper-story/README.md` の「本節はまだその結果を評価していない」は、腐らない入口の
  編集作業が未了であることを述べたものであり、証拠の不成立を定める裁定ではない。
  同 README の results 系列の表は、当該統制稿を既に登録している。
- 但し書き 2 は「性能 workload そのものでの certification の不在」を述べる文である。
  A-2 の 4 cell と A-6 の 2 cell は、`source_binding_status=bound` の下で legacy 1 回 +
  performance 5 回の correctness を通っており、不在ではなくなった。
- 4 つの限定を残すのは、成果物自身が `independent_observation_limits` と
  `compile_out_evidence_scope` で自らの証明力の上限を宣言しており、条件関門の記録も
  ID までしか保存していないためである。**限定を落とすと成果物が言っていないことを言う。**
- 旧値へ遡らせないのは、旧 3 値が別環境・別 CCBench 版・別測定契約の記述的結果だからである。
- 3 走行を集計しないのは、A-2 の outer status が 2 workload の論理積として定義されており、
  A-6 と `t1998` はそれぞれ別の事前登録と判定式を持つためである。

**却下した選択肢:**

- **A-2 を A 群の残件のまま据え置く** — D1645 が定めていない追加条件を発明することになる。
  親の段 1 の暫定裁定はこれだったが、段 2 の plan と段 3 の 2 レンズが一致して不同意を返し、
  親が一次資料で確認して撤回した。
- **但し書き 2 を無条件に外す** — 成果物自身が宣言している限定を落とす。
- **新 attempt の値をもって旧 attempt の判定を訂正・撤回する** — 絶対規律 7 に反する。
  両者は別の条件を測った別の事実である。
- **符号の一致を「再現した」と書く** — 環境・CCBench の版・測定契約が違い、どちらの protocol も
  有意差判定を持たない。
