## {{D:reference-tps-domain-narrowing-adopted}}. `reference_tps` の受理値域は周辺実測を根拠に狭める

**決定:** B-4 registry の `reference_tps` 受理値域を有限十進有理数へ狭める実装へ進む。
根拠は D1344 の指定条件の充足ではなく、D1424 が確定させた周辺実測 (production 44 万件・
封印済み registry 2,010 値のいずれにも非有限十進が存在しない) である。**本決定は D1424 決定 2 の
「狭めるか待つかはユーザーが決める」に対する上書き裁定であり、D1344 充足の宣言ではない。**
D1424 決定 4 の拘束 (述語の定義、置く層の択一の明示、事前登録 §5.1.1 の不変、共有変換権威へ
述語を置かない、既存変異検査を registry 拒否へ単純移設しない) はすべてそのまま効く。

**理由:**
- D1424 決定 2 は、条件が求めた scheduled input の列挙は母集合が空であり充足と数えられないと
  明記している。α を「条件充足」と記録すると、満たされていない前提を満たしたことにする。
- 母集合が空である理由は producer の不在であり、その producer を待つ間も受理値域は開いたままになる。
- 周辺実測は 2 軸 (key 非指定の上位集合、読める filesystem 全域) と封印済み registry の
  恒真でない列挙で取られており、狭める側の証拠として十分である。

**却下した選択肢:**
- 上流を束縛する producer の実装まで待つ — 受理値域が開いたまま残る期間が producer の
  実装工数だけ延びる。
- D1344 充足として記録する — D1424 決定 2 と正面から矛盾する。
- 丸めて受理する — D1344 が絶対規律 2 違反として却下済み。

**決定:** OpenAlex の条件 1 を `oqo` の順序非依存な比較へ改める。新しい amendment・新しい epoch・

**却下した選択肢:**
- 現行条件を維持する — 軸 1 は永久に完走できない。
- amendment なしで比較だけ差し替える — 凍結物の所定手続きを迂回する。

## {{D:readonly-source-binding-design-choices}}. 読み取り専用束縛は build のみ隔離し型で受け渡す

**決定:** 読み取り専用の source 束縛は次の 4 点で実装する。(a) build だけを fork した子で隔離し、
user namespace の残留を許さない。(b) 対象 file の所有が空いた後に、段 3 が挙げた修正条件を
織り込んで実装へ進めてよい。(c) 実 CMake の qualification は毎回の受入から外し、計算ノードでの
一度きりの artifact とする。(d) 保護種別は型 (exact capability) で受け渡す。

**理由:**
- 固定 literal による保護種別の受け渡しは恒真であり、発火しない保証になる。
- 実 CMake qualification を毎回の受入に置くと受入時間を押し上げる一方、得られる情報は
  一度きりの実測と変わらない。
- 単純な read-only bind は同一 uid の別 namespace から下層 inode を書けるため不足であり、
  build のみの隔離が最小の十分条件である。

**却下した選択肢:**
- user namespace の残留を許す — 束縛が build 後に外れる。
- 固定 literal で保護種別を渡す — 恒真な保証になる。

## {{D:rulings-collection-two-missing-forms}}. rulings の収集は「裁定済み → ユーザー手番」と「〜を決める」の 2 形式も拾う

**決定:** rulings の収集規則へ、次の 2 形式を明示的に含める。(1) 見出しが「裁定済み」で始まりながら
本文がユーザー手番・未裁定の値を残す項。(2) 「〜かを決める」「〜かを判断する」のように
決定型語尾だけを持ち「裁定」の語を含まない項。

**理由:**
- 2026-09-02 の全件棚卸しで、この 2 形式により 3 件が索引から落ちた実測がある。
  1 件は「裁定済み (既存 D) → ユーザー手番のまま」で、裁定済みの語を除外条件にすると落ちる。
  2 件は「決める」で終わり「裁定」の語を含まないため、決定型語の列挙から漏れた。
- 既存の収集規則は「定型句 grep は変種を落とす」と警告しているが、落ちる変種の具体形を
  挙げていなかったため、同じ穴を再び踏んだ。

**却下した選択肢:**
- 警告文のままにする — 具体形がないと同じ穴を踏む。
- 全項の全文を毎回人手で読む — 索引規模に対して成立しない。
