## {{D:t2869-planner-axis-fixed}}. K0 planner の axis 名の書き違いは、巡 tool の planner prompt に固定値を明示して直す。検査・役割定義・本比較の固定 commit は変えず、本比較には適用しない

**決定:**

1. **直し方。** `tools/t2849_llm_round.py` の `prompt()` で、planner-v4 向けの prompt にだけ「`proposal.axis` は必ず `silo-backoff-magnitude`。この固定名は共通 header の hole marker 名であり、protocol 名を示さない」の 1 文を足す。
   両 protocol に同じ文を使い、`protocol` 引数は足さない。`cmd_coder` の完全一致検査・拒否時の A 消費・coder / critic prompt・`planner-input.json` の bytes は変えない。
2. **採らなかった直し方。** 検査を緩めて別名を受理する案は依頼で除外した。入力 JSON に axis を載せる案は役割定義の入力契約に無い key を足す。拒否理由を `t2849_prior_observations` で返す案は閉じた契約を広げ、最初の拒否を防げない。
   役割定義 (`.claude/agents/planner-v4.md`) の出力例を固定値と明記する案は、役割本文の改訂がユーザー承認事項 (D2256 項 7 の先例) なので本決定では行わない。
3. **生死確認。** 記録済みの拒否 13 入力 (MOCC 疎通 7・silo 試走 v2 6) について、修正前の module で作り直した prompt は記録と 13 / 13 が byte 一致した。同じ model (`claude-opus-5`) の planner-v4 を修正前・修正後の prompt で 1 回ずつ呼び直すと、
   巡 tool の検査を通った出力は修正前 1 / 13、修正後 13 / 13。拒否例だけを選んだ標本での効き目の兆候で、一般の拒否率の推定ではない。
4. **本比較 ([T-2850]) には適用しない。追補は置かない。** 拒否と A 消費は基盤設計 §2.5・§3.4・§5.1 と D2261 項 7 どおりで、役割定義の出力例が固定値を文で明示しない点は要確認にとどまる。
   本登録 §3.1 に基づいて本比較へ修正を適用するための具体的な食い違いは確定できない。prompt は発効束上「固定 commit の巡 tool が組む」手法の一部で、未発効であることは追補 3 §5 の固定値を変える理由にならない。
5. **本比較の報告で開示するもの。** 系列・cell ごとの A 消費・B 到達・有効候補率 (A 基準と B 基準)・投入前拒否の分類と件数。K0 の `role-output` のうち axis 名の不一致を識別できる形で示し、試走 v2 の 6 / 36 は先例として別記する。本決定の記録は最終報告での開示を代替しない。
6. **再提示の択一 (D2272 項 2 の再提示に並べる)。** A (推奨) = 固定済み prompt のまま本比較、再試走なし。B = 修正 prompt を適用、生成の前に事後改訂の追補を置き、LLM 系列を試走し直して規模と計算確認を再提示
   (試走 v2 の LLM 3 job の実績 12.41 node 時間 + LLM の直列時間。T_c(wh) は非 LLM 系列から作るので流用の根拠を書ける。s_{wh,llm}・c(wh,llm)・ℓ(wh) は取り直し)。表は `output/insights/2026-09-27/t2869-planner-axis-name/README.md` §5。

**理由:**
- 固定値は planner の出力契約の一部で、値でも機序でもない。prompt に書けば役割定義の禁止 (値・機序を出さない) と K0 の境界 (外部の実験知識を足さない) に触れずに、観測された書き違いに直接効く。
- 検査を緩めると受理集合が変わり、B-5 と同じ厳密さで比べてきた比較の前提が崩れる。
- 本比較への適用は、試走の結果を見た後に 1 手法の構成を変えることになる。本登録 §3.1 は具体的な食い違いがある場合にだけ追補でそれを認めており、今回はその条件を示せない。

**却下した選択肢:**
- 本比較の発効前だから修正を自由に入れる — 追補 3 §5 が固定 commit を本比較の固定値にしており、未発効は変更の自由を意味しない。
- K2 / B-5 の 15 / 15 一致を根拠に「原因は K0 prompt の明示不足だけ」と書く — 構成・入力・prompt が違い、帰属の根拠にならない。
