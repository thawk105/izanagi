## {{D:b5-contrast-design-stays-non-binding}}. B-5 対照の設計は非拘束の設計メモに留め、正本化は発火 commit まで行わない

**決定:** B-5「LLM の因果的必要性」3 アーム同一予算対照の設計は
`output/insights/2026-08-26_b5-llm-necessity-contrast-design.md` に
`authority: none` / `default_effect: no-state-change` で置く。
`docs/phase3-main-experiment.md` への拘束力ある追記は行わない。
D52 が定めた対照 3/4 の休眠、および `docs/phase3.md` の段 6 前提タスク (a)〜(e) の休眠は、
本決定によって解除されない。正本化するのは、発火条件が実際に満たされ、
ユーザー承認を伴う日付付き発火 commit の時点である。

**理由:**
- 追記しても certified 選択、材料レポートの値、試行台帳、論文素材 §8 の B-5 欄は
  一件も変わらない。`DW-G05` が求める成果物影響を書けない。
- 発火条件を満たす既存 artifact path も計測 ID も書けない。`DW-G04` は
  この場合に設計メモへ留めることを規定している。
- 段 1 実測で、走らせられる適格軸が 1 本も実体化していないことを確認した。
  backoff は軸適格性違反、sort は D46 で地形なし、trigger-gating は D52 の (c') 事前自認、
  データ構造水準の軸は 2026-07-28 に択 (c) で廃止済みである。
- 実行機構も大半が不在である。ランダム変異生成器、Tier0、3 アーム共通 driver、
  共通予算台帳、report / 統計 consumer のいずれも実装がない。
  既存の LLM 側入口は承認世代数の上限が対照設計の予算より小さく、軸もハードコードされている。
- 拘束力ある正本へ未実装・未成立の規約を足すと、将来の consumer が
  発効していない契約を参照する危険が増える。

**独立した敵対相談 2 本が到達した設計上の核心 (逐語 =
`output/insights/2026-08-26_b5-contrast-review-verbatim/`):** ランダム変異アームを有限の
型付き変異契約に閉じ、LLM アームを閉じないと、比較は「広い空間 vs 有限の部分空間」になる。
LLM も同じ契約に閉じると完全列挙器が構成でき、休眠解除条件の「非列挙軸」と衝突する。
この三すくみは実装を足しても消えない識別上の問題であり、
主張範囲をユーザーが決めるまで対照の正本化は保留する。

**却下した選択肢:**
- 設計を `docs/phase3-main-experiment.md` へ日付付き追記として正本化する —
  成果物影響ゼロで、未実装の規約への参照だけが増える。
- 走らせられる軸が無いまま休眠を解除する — 対象のない解除であり、
  承認済みユーザー裁定を親の判断で覆すことになる。
- 適格でないと既に裁定された軸 (backoff / sort / trigger-gating) で対照を走らせる —
  失敗条件が構造的に発火する設計であり、規律 2 への攻撃面を自ら作る。
