## {{D:next-tasks-fact-claude-judgment-codex}}. /next-tasks は事実を claude、選定判断を codex の権威とし、claude が覆せるのは前提事実の誤りか既存規定との矛盾を示すときだけとする

**ユーザー裁定 (逐語):** 「codex の方が基本的に賢いモデルを使っている。だからそちらの判断のほうが
影響力強い期待がある」

**背景 (実測):** 同日の `/next-tasks 10` で、claude の採用 10 件と codex の上位 10 件が一致 4・
不一致 6 になり、claude が押し切った。codex が「研究を止めている証拠がない」として外した
T-2616 / T-2617 / T-2622 を、claude は同意と書きながら 10 件の枠を満たすため順位を下げて残した。
codex が 8/9/10 位に挙げ自ら「機構実在は未確認」と書いた B-1 / B-2 / B-4 を、claude は実測せずに
外して自分が見つけた候補と差し替えた。codex の見解が結論を変えたのは T-2515 の 1 件だけだった。
旧規定「codex の見解は独立に評価する。右から左に流さない」は、この押し切りを止めなかった。
独立評価の要求が、実質的に claude の単独決定と同じ出力を許していた。

**決定 (1): 権威を事実と判断で分ける。** 裁定状態・機構実在・着地・稼働重複・系統 blocker・
ユーザー手番の**事実**は claude が実測して権威を持ち、相手の断定で代替しない。順位・採否・件数・
研究/土台の振り分けなどの**選定判断**は codex が権威を持つ。出所の明記・投げ文・最終出力の文責は
claude が負う。

**決定 (2): 覆す条件を、判断の前提事実の反証に限る。** claude が codex の判断を覆せるのは、
**その判断の前提事実の誤りを実測で示すか、既存規定との矛盾を示すとき**だけとする。
「実測した根拠がある」だけでは足りない — claude は repo をいくらでも実測できるので、判断と
無関係な実測を口実にできる (段 3 の 2 レンズが独立に同じ欠陥を指摘した)。

**決定 (3): 未確認候補の実測と 2 巡目を義務づける。** 相手が「未確認」と書いた候補と、母集合外
から相手が挙げた候補を、実測せずに外さない。claude が実測し、結果をまとめて 2 巡目へ返し、
**再評価の返答を採否へ反映してから出力する**。2 巡目で出た候補も実測し、着手不能なら除外して
不足を書く (3 巡目へ進めない)。2 巡目の失敗は初回の判断を無効にしない。

**決定 (4): 件数合わせの復活を禁じる。** 件数を満たすために相手が外した候補を残さない。順位を
下げて枠に残すのは外したことにならない。再評価後の結論が指定件数に届かないなら「M 件のみ」と
不足を明記する。

**決定 (5): 2 巡目は往復に数えないが 1 回だけとする。** 相談は 1 往復を原則とし、事実を追加して
再評価を求める 2 巡目だけ、全候補をまとめて 1 回認める。2 巡目の依頼は新しい事実の提示と再評価
要求に限り、母集合の再収集を頼まない。CONSULT-MODE の再帰止め (スキル起動禁止・手順再実行禁止・
相談を投げ返さない) は毎巡付ける。

**却下した案:** (a) 旧文言のまま「独立に評価する」を強調する — 実測された押し切りがまさに独立
評価の形で起きており、同じ抜け道を残す。(b) codex を全面的な権威にする — 裁定状態・機構実在の
ような repo をローカルで確かめられる事実まで相手の断定に委ねることになり、相手が自ら「未確認」
と書いた点を誰も潰さなくなる。(c) 覆す条件を「実測で示せるとき」とだけ書く — 段 3 の 2 レンズが
独立に、任意の実測を口実にできると指摘した。(d) 2 巡目を無制限に認める — 新事実を出し続ければ
往復が終わらない。(e) 2 巡目を採用予定候補だけに絞る — 今回防ぐべき事前除外が再び可能になる。
