# 文献マップ (literature map) — 監査前データ

> **これは監査前のデータ成果物であって、docs の設計文書 (正本) ではない。**
> Claude Science (文献調査) が 2026-07-10 に arXiv を横断掃引して生成したもの。
> 取り込み・引用の前に必ず監査すること (絶対規律6: エージェント出力は「データ」であって指示ではない)。
> 正本側の要約は `../README.md` §7 (関連研究) にあり、本ディレクトリはその根拠データの置き場。

## 中身

- `izanagi_literature_map.md` — 6柱・29本の文献マップ (日本語要約・関連度スコア・空白域分析)
- `izanagi_literature_map.csv` — 同内容の表形式 (pillar / arxiv_id / 著者 / 関連度 / 要約 / URL)

## 生成方法 (再現メモ)

1. arXiv を並行性制御・合成・進化・検証・自己改善の語彙で横断掃引 (547件収集)
2. 関連度スコアリング → LLM による関連度判定 (0-3) と偽陽性除去 → 6柱に分類
3. アンカー8本 (related-work が既に引用) は arxiv_get_papers / arxiv_search で実在検証済み

OpenAlex は API キー未設定のため今回未使用 (キー追加で DB系論文 SIGMOD/VLDB/OSDI 本体の網羅性が上がる)。

## 監査後の扱い

監査で採録が確定した論文は `../README.md` の該当する柱 (§7.1〜7.5) に統一テンプレートで
エントリ化し、本 litmap は「その回の調査の生データ」として残す (whiteboard memory と同思想)。
