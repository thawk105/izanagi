## 4. 集計と行間比較の禁止

> **29 行の C/D 欄を集計してはならない。行をまたいで比較してもならない。**

理由は §1 のとおり、C/D 欄が 2 つの資料階層の混合だからである。

**禁止が解けるのは、29 行すべてを同一の一次資料基準で当て直した新しい凍結物が出たときだけである。**
D1156 は「全行を一次資料で当て直すことはしない」と定めており、本 wave はそれを行っていない。

**部分的な集計も禁止に含まれる。** 「`[P1]` の 4 行だけを集計する」「`[S1]` の 25 行だけを
集計する」も、母集団が分類規則の検証を目的とした閉じた 29 件であって主張の母集団ではないため、
行わない。C と D は pilot の判定規則でも gate ではなく**記録する属性**である。
